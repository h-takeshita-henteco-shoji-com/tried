# 訪問介護のステークホルダー別の業務一覧

作成日: 2026年11月8日

## この資料の結論

- 訪問介護に絞ると、ステークホルダーは12になる。
- 業務の軸は、毎月の「提供票 → 訪問 → 記録 → 実績 → 請求」の流れ。
- 書類の受け渡しは、サービス提供責任者と請求事務に集まる。

## 訪問介護に絞った理由

福岡県・佐賀県で、1サービスに絞るために選んだ。

- 指定と指導をする自治体が少ない。福岡県は県・福岡市・北九州市・久留米市、佐賀県は県だけ
- 全国で最も事業所が多いサービス(37,264、2024年)
- 計画・記録・請求の担い手が分かれ、食い違いが運営指導でよく指摘される

## 対象のステークホルダー

`02-ステークホルダー一覧.md` の16から、訪問介護にいない立場を除いた。

- 除いた立場: 生活相談員、看護職員、機能訓練指導員、管理栄養士・栄養士、施設のケアマネジャー
- 残した立場: 下の12

## 業務の頻度

- **契約時:** 利用を始めるとき
- **日次:** 毎日
- **月次:** 毎月。請求の締め切り(10日)が軸
- **定期:** 3か月ごと、半年ごと、年1回など
- **随時:** 状態の変化、改定、運営指導など

## 経営と管理

### 経営者

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 事業の方針と予算を決める | 年1回 | 事業計画、予算書 |
| 取る加算と体制を決める(特定事業所加算など) | 改定時・随時 | 体制届 |
| 収支と報酬の入金を確かめる | 月次 | 月次の収支報告 |
| 処遇改善加算の配分方針を決める | 年1回 | 処遇改善計画書 |
| 職員の採用と配置を決める | 随時 | 採用計画 |

### 管理者

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 勤務表を組み、人員基準を保つ | 月次 | 勤務形態一覧表 |
| サービス提供責任者の配置数を保つ | 月次 | 利用者数の集計、勤務表 |
| 委員会を開き、議事録を残す | 定期 | 虐待防止・身体拘束・感染対策の議事録 |
| 研修を計画し、実施する | 年1回・定期 | 研修計画、研修記録 |
| 指針とBCPを作り、訓練する | 年1回 | 各種指針、BCP、訓練記録 |
| 苦情と事故に対応する | 随時 | 苦情記録、事故報告書 |
| 運営指導に対応する | 随時 | 自己点検シート、確認文書一式 |
| 加算・体制の変更を届け出る | 随時 | 体制届 |

人員基準の目安: サービス提供責任者は利用者40人ごとに1人以上。訪問介護員は常勤換算で2.5人以上。

## 現場

### サービス提供責任者

書類の受け渡しの中心にいる立場。

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 利用者を評価し、訪問介護計画を作る | 契約時・見直し時 | アセスメント、訪問介護計画書 |
| 計画を説明し、同意を得て交付する | 契約時・見直し時 | 訪問介護計画書(同意欄) |
| 手順書を作り、ヘルパーに指示する | 契約時・随時 | 手順書、指示の記録 |
| ヘルパーの訪問予定を組む | 月次・日次 | 訪問スケジュール |
| 初回や状態変化のときに同行する | 随時 | 同行訪問の記録 |
| 記録を確かめ、実施状況を見る | 月次 | サービス提供記録、モニタリング記録 |
| 状態の変化をケアマネに伝える | 随時 | 連絡記録 |
| サービス担当者会議に出る | 随時 | 会議の記録 |
| ヘルパーの会議と研修を開く | 定期 | 会議の記録、研修記録 |
| 急な欠員と緊急の訪問を調整する | 随時 | 変更の記録 |

### 訪問介護員(ヘルパー)

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 利用者の家を訪ね、計画に沿ってケアをする | 日次 | 手順書 |
| 提供した時刻・内容・様子を記録する | 日次 | サービス提供記録 |
| 利用者から記録の確認をもらう | 日次 | サービス提供記録(確認欄) |
| サービス提供責任者に報告する | 日次・随時 | 報告の記録 |
| 研修と会議に出る | 定期 | 研修記録 |

直行直帰の働き方が多い。移動時間や待機時間の扱いが、勤怠と賃金の論点になる。

## 事務

### 請求事務

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| ヘルパーの記録から実績を集計する | 月次(1〜3日頃) | サービス提供記録、実績表 |
| 提供票と実績を突き合わせる | 月次(1〜5日頃) | サービス提供票、実績表 |
| 算定ルールを確かめる(2時間ルール、同一建物減算など) | 月次 | 実績表 |
| 実績をケアマネに送る | 月次 | 提供票の実績 |
| 国保連に請求する | 月次(10日締め) | 介護給付費請求書、明細書 |
| 利用者に負担分を請求する | 月次 | 利用者への請求書、領収書 |
| 返戻と審査の結果に対応する | 月次 | 返戻の通知、審査決定の通知 |

2時間ルール＝前回の訪問から2時間空けずに訪ねた場合、2回を1回として算定する決まり。
同一建物減算＝事業所と同じ建物や敷地に住む利用者に提供した場合の減算。

### 経理

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 報酬と利用料の入金を消し込む | 月次 | 入金の明細 |
| 給与を計算する(移動時間を含む) | 月次 | 給与台帳 |
| 処遇改善加算の賃金改善額を計算する | 年1回 | 処遇改善の実績報告書 |
| 決算をし、経営情報を報告する | 年1回 | 決算書、経営情報の報告 |

### 総務・人事

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| ヘルパーを採用し、資格証を確かめる | 随時 | 雇用契約書、資格証の写し |
| 勤怠を管理する | 日次・月次 | 出勤簿、訪問実績 |
| 健康診断と研修の記録を管理する | 定期 | 健診記録、研修記録 |
| 規程と処遇改善の要件を整える | 年1回 | 就業規則、賃金規程、キャリアパス |
| 指定の更新を届け出る | 6年ごと | 指定更新の申請書 |

## 事業所の外

### 利用者

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 契約し、計画に同意する | 契約時・見直し時 | 契約書、訪問介護計画書 |
| サービスを受け、記録を確かめる | 日次 | サービス提供記録 |
| 利用料を払う | 月次 | 請求書、領収書 |

### 家族

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 契約に立ち会い、代わりに署名する | 契約時 | 契約書、同意書 |
| 事業所・ケアマネと連絡をとる | 随時 | 連絡ノート |
| 利用料を払う | 月次 | 請求書 |

### 居宅のケアマネジャー

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 利用者を評価し、ケアプランを作る | 契約時・見直し時 | アセスメント、ケアプラン |
| サービス担当者会議を開く | 随時 | 会議の記録 |
| 事業所に提供票を送る | 月次(月末) | サービス提供票、別表 |
| 毎月訪ね、実施状況を確かめる | 月次 | モニタリング記録 |
| 実績を受け、給付管理票を国保連に出す | 月次(10日締め) | 給付管理票 |

### 主治医

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 要介護認定の意見書を書く | 認定・更新時 | 主治医意見書 |
| 医療上の注意を伝える | 随時 | 診療情報提供書 |

### 地域包括支援センター

| 業務 | 頻度 | 関わる書類 |
|---|---|---|
| 要支援者の介護予防プランを作る | 契約時・見直し時 | 介護予防サービス計画 |
| 総合事業の訪問型サービスを調整する | 随時 | 介護予防サービス計画 |

要支援者向けの訪問(総合事業)は、市町村ごとに単価や基準が違う。
