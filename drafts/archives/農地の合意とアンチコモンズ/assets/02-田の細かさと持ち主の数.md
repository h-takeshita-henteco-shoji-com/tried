# 田の細かさと持ち主の数（糸島市）

調べた日: 2026-11-18
前の調べもの: `01-制度と糸島の状況.md`（重なる内容は書かない）

## 結論

1. 糸島市の田の区画は20,675枚、合計3,300haある。中央値は11.3aで、45%の区画が10a未満である（2022年公開の筆ポリゴン、筆者の計算）。
2. 10a未満の区画は、枚数では45%を占めるが、面積では14%にとどまる。面積の82%は10a〜1ha未満の区画にある（筆者の計算）。
3. 2015年の土地持ち非農家（農地を持つが農業をしない世帯）は1,907戸だった。総農家2,145戸とほぼ同じ数である。2010年は2,065戸だった。
4. 2015年の土地持ち非農家は913haの耕地を持ち、うち896ha（98%）を貸している。耕作放棄地は215haあった。
5. 見立て: 「田が細かく、持ち主が多い」というアンチコモンズの前提は、糸島に当てはまりそうである。ただし、1つの区画を何人で共有しているかは公開データで確かめられない。

## 1. 田1枚ごとの広さの分布

### 答え
- 筆ポリゴンには糸島市の分がある。
- 農林水産省の公式配布は、市区町村ごとのGeoJSON（地図の形を表す文字形式）を圧縮したzipである。
- 各区画には田・畑の区別の属性がある。広さの属性はない。広さは形から計算する必要がある。

### 筆ポリゴンの区画は何を表すか
- 筆ポリゴンは、衛星画像などを目で見て、田畑1枚ごとの形をなぞって手作業で作ったものである。
- 公式の説明は「農地の位置や形状を示すものであり、土地の権利関係等を示すものではありません」としている。
- したがって、筆ポリゴンの1区画は、登記上の1筆（持ち主の単位）と同じではない。畦（あぜ）で区切られた見た目の1枚に近い。
- 登記上は複数の筆が1枚の田になっている場合も、1筆が複数枚に分かれている場合もありうる（推測）。
- 出典: 農林水産省「農地の区画情報（筆ポリゴン）について」 https://www.maff.go.jp/j/tokei/porigon/attach/pdf/index-38.pdf
- 出典: 農林水産省「農地の区画情報（筆ポリゴン）のデータ提供・利用」 https://www.maff.go.jp/j/tokei/porigon/index.html

### 属性
- 属性は次のとおり（2022年4月以降の公開サイト版）。
  - polygon_uuid: 区画のID。毎年付け直される。
  - land_type: 耕地の種類。100が田、200が畑。衛星画像などの目視判読で決める。
  - issue_year（公開年度）、edit_year（作成・更新した年度）、history（前年との関係）。
  - local_government_cd: 市区町村コード。区画の重心がある市区町村を機械的に付ける。糸島市は402303。
  - point_lng / point_lat: 区画の重心の経度・緯度。
- 面積の属性はない。
- 出典: 農林水産省「筆ポリゴンデータの仕様変更（ID等の属性情報、座標系等）について」（2022年4月14日） https://www.maff.go.jp/j/tokei/porigon/attach/pdf/index-36.pdf

### 糸島市の田の区画（2022年公開データ）
- 区画の数: 20,675枚
- 合計面積: 3,300.5ha
- 中央値: 11.3a（第1四分位5.2a、第3四分位22.7a）
- 平均: 16.0a

| 区画の広さ | 区画の数 | 数の割合 | 面積 | 面積の割合 |
|---|---|---|---|---|
| 10a未満 | 9,397 | 45.5% | 461.5ha | 14.0% |
| 10〜30a未満 | 8,354 | 40.4% | 1,536.7ha | 46.6% |
| 30a〜1ha未満 | 2,817 | 13.6% | 1,178.3ha | 35.7% |
| 1ha以上 | 107 | 0.5% | 123.9ha | 3.8% |

- 上の数字はすべて筆者の計算である。
- 参考として、畑の区画は12,910枚、798.1ha、中央値3.6aだった（筆者の計算）。
- 合計3,300haは、前の調べもので出した地域計画14地区の田の合計3,306haとほぼ一致する。
- 計算の方法:
  - local_government_cd が402303、land_type が100の区画を選んだ。
  - 経緯度の形を平面直角座標系II系（EPSG:6670、福岡県の地図座標）に変換して面積を出した。
  - Python の pyogrio、shapely、pyproj を使った。
- 使ったデータ: 農研機構「Fudepoly47」が、農林水産省の2022年度公開の筆ポリゴンを県ごとにまとめたFlatGeobuf形式のファイル（fude_2022_40.fgb、福岡県、約424MB）。
  - https://habs.rad.naro.go.jp/spatial_data/fudepoly47/
  - https://habs.rad.naro.go.jp/spatial_data/fudepoly47/fude_2022_40.fgb
  - 元データは農林水産省の筆ポリゴン（2022年公開）である。農研機構は形式を変えて県単位にまとめただけである。

### 最新の版を使わなかった理由と取得の手順
- 公式の配布サイトには、2026年度公開までの糸島市の分がある。
- ただし、配布ファイルを置くサーバー（opendata.fude.maff.go.jp）が、この作業環境からの取得を403エラーで拒んだ。
- そのため、取得できた2022年公開分で計算した。4年の差で数字が少し変わる可能性がある。
- 最新版を取得する手順は次のとおり。
  1. https://download.fude.maff.go.jp/ をブラウザで開く。
  2. 公開年度（例: 2026）、都道府県（福岡県）、市区町村（糸島市）を選ぶ。
  3. ダウンロードを押すと、`2026_402303.zip` の期限付きリンクが出る。
  4. zipを展開するとGeoJSONが入っている。上と同じ方法で面積を計算する。
- 2021年7月以前の古い版（シェープファイル形式）は、別ページで市町村ごとに配っている。糸島市は2019年版と2021年版がある。
  - https://www.maff.go.jp/j/tokei/porigon/hudeporidl.html

## 2. 農地を持つだけの非農家（土地持ち非農家）の数

### 用語
- 土地持ち非農家: 農家ではない世帯で、耕地と耕作放棄地を合わせて5a以上持つ世帯。
- 耕作放棄地: 過去1年以上作付けしておらず、数年のうちに再び作付けする考えのない土地。持ち主の申告による。

### 答え（2015年）
- 糸島市の土地持ち非農家は1,907戸である。
  - うち、農業をする組織に参加・従事している世帯は18戸。
  - 同じ年の総農家は2,145戸である。
- 耕地を持つ土地持ち非農家は1,707戸で、持つ耕地は913haである。
- そのうち、耕地を貸している世帯は1,601戸で、貸している耕地は896haである。
- 耕作放棄地を持つ土地持ち非農家は655戸で、耕作放棄地の面積は215haである。
- 出典: 2015年農林業センサス 確報 第1巻 都道府県別統計書 40 福岡県 Ⅴ総農家等（e-Stat）
  - 一覧: https://www.e-stat.go.jp/stat-search/files?tclass=000001081360&cycle=0&layout=datalist
  - 表5-1「総農家数及び土地持ち非農家数」 https://www.e-stat.go.jp/stat-search/file-download?statInfId=000031514660&fileKind=0
  - 表5-2(4)「土地持ち非農家の所有耕地及び貸付耕地」 https://www.e-stat.go.jp/stat-search/file-download?statInfId=000031514664&fileKind=0
  - 表5-3(1)「耕作放棄地のある農家(世帯)数」 https://www.e-stat.go.jp/stat-search/file-download?statInfId=000031514665&fileKind=0

### 2020年以降に市町村の数字がない理由
- 土地持ち非農家の把握そのものは、2020年もなくなっていない。
  - 2020年センサスの第2巻には、都道府県別の土地持ち非農家の表がある。
  - 出典: 2020年農林業センサス 第2巻 Ⅵ総農家等 表4「土地持ち非農家の所有耕地及び貸付耕地」 https://www.e-stat.go.jp/stat-search/file-download?statInfId=000032101970&fileKind=0
- 一方、2020年の第1巻（福岡県）の総農家等の表は4つで、土地持ち非農家の表がない。
  - 4つは、総農家数、経営耕地、貸付耕地、林家数である。
  - 出典: 2020年農林業センサス 第1巻 福岡県 Ⅵ総農家等 表1〜4 https://www.e-stat.go.jp/stat-search/file-download?statInfId=000032150510&fileKind=0 （表2〜4は statInfId=000032150511〜000032150513）
- 市町村別の表をやめた理由について、公式の説明は見つからなかった（未確認）。
- 2020年に変わった点で、公式の説明が見つかったものは次の2つである。
  - 土地持ち非農家は調査票を配らない対象で、調査員が作る名簿（客体候補名簿）で把握している。
  - 2020年は、この名簿から「耕作を放棄している面積」の項目を削った。
  - 削った理由は、耕作放棄地面積が農家の申告による主観の数字だからである。2008年から農業委員会が荒廃農地を客観的に把握していることも理由に挙げている。
  - 「貸している耕地」の項目も削る案があった。しかし、農地の貸し手として重要なため、残した。
- 出典:
  - 総務省 統計委員会 産業統計部会 資料「第79回産業統計部会の審議において整理、報告等が求められた事項に対する回答」 https://www.soumu.go.jp/main_content/000558707.pdf
  - 総務省 統計委員会 審査メモ（2025年農林業センサス） https://www.soumu.go.jp/main_content/000884070.pdf
  - 農林水産省「2020年農林業センサス結果の概要（概数値）」（2021年1月12日） http://www.nohken.or.jp/kikaku-iinkai/3-1-12-maff-kikaku6.pdf
