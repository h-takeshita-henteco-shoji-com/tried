# 田の地代と、区画をまとめたときのコスト（糸島市・九州）

調べた日: 2026-11-18
前の調べもの: `01-制度と糸島の状況.md`、`02-田の細かさと持ち主の数.md`（重なる内容は書かない）

## 結論

1. 糸島市の田の地代（持ち主が貸して受け取る額）は、10aあたり平均約1.4万円である（2024年、731筆、筆者の計算）。地区ごとの平均は1.05万〜1.86万円で、ゼロに近い水準ではない。
2. 一方、持ち主1人の受け取りは小さい。中央値の11.3aの田を1枚貸しても、年に約1.6万円にとどまる（筆者の計算）。
3. 区画を30aから1ha以上にすると、担い手の労働時間は10aあたり25.0時間から12.9時間に減る（国の調査、2010年）。お金に直すと年に約2万円/10aで、地代を上回る（筆者の計算）。
4. 九州の米の生産費は10aあたり12.2万円で、うち支払地代は6,301円（5.2%）である（2024年産）。15ha以上の経営体は8.0万円で、平均より34%安い。
5. 見立て（推測）: 地代は相場の幅に収まり、1人の取り分は年1〜2万円と小さい。このため「高い地代を求めて粘る」より「得が小さく、決めない・答えない」に近そうである。

### 数字を読むときの注意
- 2024年の値は、令和6年6月と11月に利用権設定（農業委員会を通した貸し借りの手続き）をした契約だけを集めている。
- お金で払う契約だけを集計している。米で払う物納と、無償の使用貸借は含まない。
- 市の注記によると、田の金額には施設や露地の賃料が含まれる。最高額の12万円や6.25万円は、ハウスなどの施設の分と考えられる（推測）。
- このため、平均は田だけの地代より高めに出ている可能性がある（推測）。
- 地区によって筆数が少なく、年ごとに平均が大きく動く（例: 長糸は9,374円から18,571円）。

### 持ち主1人が受け取る額
- 前の調べもので、糸島市の田1枚の広さの中央値は11.3aだった。
- 11.3aを約1.4万円/10aで貸すと、年に約1.6万円になる（筆者の計算）。
- 10a未満の田（枚数の45%）なら、年に1.4万円未満である（筆者の計算）。

## 2. 区画の広さとコストの関係

### 答え
- 区画が大きいほど、担い手の10aあたりの労働時間は減る。
- 30a区画から1ha以上の区画にすると、労働時間は48%減る。
- 整備の前後で、米の生産コストは60kgあたり約2割下がる（国の23地区の平均）。

### 区画の広さ別の労働時間（2010年、担い手、10aあたり）

| 区画 | 労働時間 |
|---|---:|
| 整備前 10a区画以下 | 34.0時間 |
| 整備前 30a区画 | 25.0時間 |
| 整備後 30〜50a区画 | 25.5時間 |
| 整備後 50a〜1ha区画 | 17.4時間（30a比 ▲30%） |
| 整備後 1ha区画以上 | 12.9時間（30a比 ▲48%） |

- 2009年度（平成21年度）に圃場整備を終えた73地区・371経営体の担い手へのアンケートである。
- 出典: 農林水産省 食料・農業・農村政策審議会 農村振興分科会 資料1-2-2-1「第2章 収益性の向上や競争力強化を目指した『産業政策』」（平成25年）p.14「ほ場の区画規模と労働時間（平成22年）」 https://www.maff.go.jp/j/council/seisaku/nousin/bukai/h25_4/pdf/siryou1_2_2_1.pdf
- 同じ資料に、北海道の中篠津南地区の例がある。0.5ha区画を1.2ha区画にして、労働時間が23.6時間から8.4時間に減った（▲64%）。
- 同じ資料によると、減るのは耕起・田植え・刈取りの時間である。水管理と畦畔（あぜ）の草刈りは、あまり減らない。

### 圃場整備の前後の米の生産コスト（60kgあたり）

| 項目 | 整備前 | 整備後 |
|---|---:|---:|
| 労働費 | 4,397円 | 2,663円 |

  - https://www.maff.go.jp/j/nousin/keiiku/noutiseibi/attach/pdf/index-162.pdf

### 担い手の得を地代と比べる（筆者の計算）
- 労働1時間の値を、2025年産の全国の労働費÷労働時間で置く。35,786円÷21.20時間で、約1,690円/時間になる。
- 30a区画を1ha以上にすると、12.1時間/10a減る。お金に直すと約2.0万円/10a/年である。
- 30a区画を50a〜1haにすると、7.6時間/10a減る。お金に直すと約1.3万円/10a/年である。
- 整備前後の23地区の差（3,291円/60kg）を、全国の収量510kg/10a（8.5俵）に掛けると、約2.8万円/10a/年である。
- どの見方でも、まとめたときの担い手の得は、糸島市の地代（約1.4万円/10a）と同じか、それ以上である。
- ただし、整備には工事費と地元負担がかかる。上の計算はそれを引いていない。

### 九州の田の区画（米の生産費統計の調査対象）
- 九州の調査対象の経営体は、1経営体あたり9.8枚の田を耕している。1ha以上の区画はほぼない（0.2a）。
- 面積の内訳は次のとおりである（筆者の計算、合計140.6a）。
  - 10a未満・未整理 18%、10〜20a 33%、20〜30a 27%、30〜50a 16%、50a〜1ha 6%、1ha以上 0.1%
- 全国では、1ha以上の区画が面積の6%ある（筆者の計算）。
- 出典: 農林水産省「令和6年産農産物生産費（個別経営体）」表2 調査対象経営体の生産概要・経営概況（e-Stat、2026-03-30公開） https://www.e-stat.go.jp/stat-search/files?page=1&layout=datalist&lid=000001480360
