# 農地の合意の制度と、糸島市の状況

作成日: 2026年11月18日
目的: アンチコモンズ（持ち主が多く、全員の同意が取れず、土地がまとまらない問題）をシミュレーションで扱うため、比べる「制度」と「持ち主の種類」の材料を集める。
範囲: 公開資料だけを使う。シミュレーションの設計と、人間の実験の論文は扱わない。

---

## 結論

1. 比べる制度の候補は3つある。①区画整理は持ち主側の3分の2の同意で始まり、残りも従う（土地改良法）。②全部の田を農地バンクに15年以上貸せば、同意も費用もなしで県や市が整備する（実質は全員が貸すことが条件）。③共有の田は持分の過半で貸せ、不明な相続人がいても公示2か月で最長40年貸せる。
2. 持ち主向けのお金は個人でなく「地域」に払われる。地域の農地の80%超が農地バンクに入ることが条件で、閾値（しきいち＝決まった割合を超えたときだけ成立する線）つきの公共財の形をしている。
3. 持ち主の種類の手がかり（2025年センサス）は次のとおり。経営耕地10ha以上の担い手は62経営体（5%）。1ha未満の小さな経営体は516（45%）。基幹的農業従事者の59%が65歳以上。借りて耕す田は経営耕地の田の65%に当たり、貸すだけの持ち主が多い。
4. 担い手への集積率は、14地区で38%〜88%と差が大きい。面積で重みをつけた平均は約55%（筆者の計算）。市の目標は2034年度（令和16年度）に80%。
5. 整備されていない田は、整備を「地元で検討中」の地区（引津の小富士、福吉の吉井下、加布里の神在など）に集まっている。どの地区でも、地元の費用負担への配慮が繰り返し書かれている。

## 問い1 圃場整備と、持ち主の同意の割合

### 答え
- 区画整理などの土地改良事業は、原則として「3条資格者」の3分の2以上の同意で始められる。
- 3条資格者とは、事業に参加する資格を持つ人である。田を貸している場合は、原則として借りて耕している人が資格者になる。
- 3分の2が同意すると、地区内の資格者は全員が土地改良区（工事と管理を行う団体）の組合員になる。反対した人も費用を負担する。
- 計画の重要な部分を変えるときも、3条資格者の3分の2以上の同意が要る。
- 出典: 土地改良法（e-Gov） https://laws.e-gov.go.jp/law/324AC0000000195
- 出典: 農林水産省「土地改良法の改正について（令和7年5月）」 https://www.maff.go.jp/j/nousin/attach/pdf/totikai_r7kaisei_setumeikai-8.pdf

### 同意なしで進められる場合
- 2017年（平成29年）の改正で「農地中間管理機構関連事業」ができた。
- この事業では、農地バンクが借りている田を、県が整備する。農業者の申請、費用負担、同意は要らない。
- 条件は3つある。①区域の田の全部に農地バンクの権利があること。②受益面積が10ha以上（中山間地域は5ha以上）。③農地バンクが借りる期間が、計画の公告から15年以上あること。
- 費用は国50%、県27.5%、市町村10%、さらに国が12.5%を上乗せする。農家の負担は0%である。
- 2022年（令和4年）の改正で、用排水施設や暗渠排水（あんきょはいすい＝地下に埋めた排水管）も対象になった。
- 2025年（令和7年）の改正で、市町村も実施主体になった。市町村営は5ha以上で使える。農地バンクが所有する田も対象に加わった。
- 同じ2017年の改正で、共有の土地は共有者を合わせて1人の資格者とみなし、代表者を1人選ぶ仕組みもできた。
- 出典: 上の農林水産省資料（p.8、p.16）

### 2025年改正のほかの点（短く）
- 計画を変えるとき、転用された土地の持ち主を同意集めの対象から外す。
- 事業の利益を受けないと申し出た人を、同意集めの対象から外す。
- 農業者の同意を省いて始めた施設更新は、計画変更でも同意を省ける。
- これらは主に水路などの施設の更新向けで、区画整理の同意の割合は変わっていない。
- 出典: 上の農林水産省資料（p.8、9章）

### シミュレーションでの意味（推測）
- 3分の2ルールは、少数の反対者が止められない仕組みである。アンチコモンズを弱める。
- 機構関連事業は、同意は要らない。ただし区域の全部を農地バンクに貸すことが前提である。このため、実際には「全員が貸す」という全員一致の壁が残る。

## 問い2 農地中間管理機構（農地バンク）の仕組み

### 流れ
- 持ち主が田を農地バンクに貸す。農地バンクは借りた田を、まとめて担い手に貸し出す（転貸）。
- 2023年4月の改正後は、農地バンクが「農用地利用集積等促進計画」を作り、貸し借りを一括で決める。以前の市町村の集積計画と、農地バンクの配分計画を一本にした。
- 農業委員会は、地域計画の達成に向けて、持ち主に農地バンクへの貸付けを働きかける。
- 市町村は、必要なときに、持ち主へ「農地バンクと協議すべき」と勧告できる。
- 出典: 農林水産省「農業経営基盤強化促進法等の一部を改正する法律について」 https://www.maff.go.jp/j/keiei/koukai/attach/pdf/chiiki_keikaku-50.pdf

### 持ち主向けのお金（令和8年度「農地集約化促進事業」、旧機構集積協力金）
- お金は地域に払われる。使い道は地域の話合いで決める。
- 対象は、全域が同じ地域計画に入っている地域である。
- 地域集約化実現タイプ（旧地域集積協力金）は、その年に農地バンクへ貸した面積に応じて払われる。
  - 条件1: 目標地図内の田のうち、1ha以上の団地（隣り合ってまとまった田）が5割以上。
  - 条件2: 地域の田のうち、農地バンクに貸した割合（活用率）が80%超（中山間地域は60%超）。
  - 単価: 2.0万円/10a。中山間地域で80%超なら2.6万円/10a。
- 集約化加速タイプ（旧集約化奨励金）は、1ha以上の団地の割合が5年で増えると払われる。
  - 10ポイント増で1.0万円/10a、20ポイント増で3.0万円/10a。
  - 15ha以上の経営者が5ha以上の団地を作ると、5万円/10a。
  - 受け手が決まっていない田で4ha以上の団地を作り、新しい受け手を呼ぶと、5万円/10a。
- 出典: 農林水産省「農地集約化促進事業」 https://www.maff.go.jp/j/keiei/koukai/kikou/attach/pdf/nouchibank-169.pdf
- 参考: 令和7年度までの地域集積協力金は2.8万〜3.4万円/10aだった。 https://www.maff.go.jp/j/keiei/koukai/kikou/attach/pdf/nouchibank-133.pdf
- 未確認: 離農する個人に払う「経営転換協力金」が今も続いているか。

## 問い3 連絡がつかない持ち主・相続登記されていない農地

### 答え
- 相続登記がされないと、田は相続人全員の共有になる。相続が重なると、共有者が「ねずみ算式に」増える。
- 2024年4月1日から、相続登記の申請は義務になった。
- 共有の田を貸すには、持分の過半の同意で足りる（全員の同意は要らない）。
- 持分の過半を持つ人が分からないときは、次の手順で農地バンクに貸せる。
  1. 農業委員会が探す。探す範囲は、登記名義人の配偶者と子までである。
  2. 農業委員会が2か月公示する。
  3. 異議がなければ、同意したとみなす（農地中間管理事業法）。または知事が裁定する（農地法）。
  4. 農地バンクに最長40年の利用権が設定される。
- 2023年4月の改正で、期間の上限は20年から40年に延びた。公示期間は6か月から2か月に縮んだ。
- 出典: 農林水産省「所有者不明農地制度の活用について（令和8年9月改訂版）」 https://www.maff.go.jp/j/keiei/koukai/attach/pdf/souzokumitouki-44.pdf
- 出典: 農林水産省 所有者不明農地の資料 https://www.maff.go.jp/j/keiei/koukai/attach/pdf/240628-1.pdf
- 未確認: 糸島市でこの公示が使われた件数。

## 問い4 地域計画の決まりと期限

### 答え
- 地域計画は、集落などの区域ごとに、10年後に誰がどの田を耕すかを決める計画である。以前の「人・農地プラン」を法律上の計画にした。
- 根拠は、2022年（令和4年）に改正された農業経営基盤強化促進法である。
- 市町村は、農業者・農業委員会・農地バンク・JA・土地改良区などの「協議の場」を開いてから計画を作る。
- 計画には「目標地図」を付ける。目標地図は、田1枚ごとに将来の耕し手を示した地図である。素案は農業委員会が作る。
- 策定の期限は、施行日（2023年4月1日）から2年以内、つまり2025年3月末だった。その後も随時変えられる。
- 全国では2025年4月末時点で18,894地区が策定した。区域内の農用地等は422万haである。そのうち134万ha（約3割）は、将来の受け手が決まっていない。
- 出典: 農林水産省「農業経営基盤強化促進法等の一部を改正する法律について」 https://www.maff.go.jp/j/keiei/koukai/attach/pdf/chiiki_keikaku-50.pdf
- 出典: 農林水産省「地域計画の策定状況（令和7年4月末時点）」 https://www.maff.go.jp/j/keiei/koukai/attach/pdf/chiiki_keikaku-165.pdf

## 問い8 糸島市の地域計画の策定状況と、地区ごとの書きぶり

- 最初の策定は2025年3月31日である。2026年3月19日に第2回の更新をした。目標年度は2034年度（令和16年度）である。
- 協議の場の結果は、市のページに「現在公表中のものはない」とある。
- 出典: 糸島市「地域計画（地域農業経営基盤強化促進計画）」 https://www.city.itoshima.lg.jp/s024/001/chikikeikaku.html
- 各地区のPDFは同じページから開ける（例: 長糸地区 https://www.city.itoshima.lg.jp/s024/001/04_shin_nagaito.pdf ）。

### 数字に出ている傾向（14地区の合計、筆者の計算）

### 書きぶりの例（短く要約）
- 全地区の共通方針: 「担い手への集積・集約化を基本とし、農地バンクへの貸付けを進める」。
- 整備について、多くの地区が「地元負担を考慮しつつ」補修や改修を検討すると書く。
- 波多江地区: 担い手が表作と裏作で田を互いに使っているため、田の交換による集約は「かなりの調整が必要」。
- 怡土地区: 集積が進むと、担い手が面積の小さい田を担うのが難しくなると予想している。
- 可也地区: 担い手がいない集落では、新規就農者の受け入れや、畦（あぜ）を取り除く工事に協力する考えがある。
- 一貴山地区: 波呂集落は、集落の担い手に集約することについて地元の了解を得ている。

## 問い9 実際に出ている困りごと

- 小さな未整備田は、頼まれても引き受けにくい（JAcom、既存メモにあり）。
- 耕作者から「小作料を払うより、管理費をもらいたい」という声がある（JAcom、既存メモにあり）。地代がゼロ以下になる田があることを示す。
- 担い手が1経営体しかいない集落がある（加布里の神在、雷山の篠原）。借り手の競争がなく、借り手の都合で決まりやすい（推測）。
- 担い手が表作と裏作で田を共有していて、田の交換の調整が難しい（波多江）。
- 水路の掃除や畦の草刈りに出す人手が足りない。お金だけでなく労働力の支援が求められている（波多江、雷山）。
- 整備から数十年たち、水路の水漏れや排水不良が出ている（雷山、可也、一貴山など）。
- イノシシが水路を埋め、稲作をやめる意向の集落がある（可也の親山）。
- 集落営農法人の構成員が高齢化している（福吉）。
- 福岡市からの入作（地区外の人が来て耕すこと）がある（雷山、可也、桜井）。

## シミュレーションに使えそうな点

- 制度の比較軸として、同意のルールを4段階に並べられる。全員一致（任意の貸借）、3分の2（土地改良法）、過半（共有地の貸借）、公示によるみなし同意（不明者）。
- 機構関連事業は「同意は不要だが、全員が農地バンクに貸すことが条件」という形で、全員一致と同じ壁を持つ。これを3分の2ルールと比べると、アンチコモンズの効き方が見える。
- 協力金は地域に払われ、活用率80%超で成立する。これは閾値つき公共財ゲームの形で、ただ乗り（他人が貸すのを待つ）が起きやすい。
- 持ち主の種類の候補と、割合の手がかりは次のとおり。
  - 大規模な担い手: 10ha以上の経営体が約5%。
  - 小規模・高齢の自作農: 1ha未満の経営体が約45%。基幹的農業従事者の約59%が65歳以上。
  - 貸すだけの持ち主（土地持ち非農家や市外の人）: 借りて耕す田が田全体の約65%。数そのものは未確認。
  - 後継者のいない高齢の持ち主: 地域計画の区域で約6%の面積。
  - 相続で共有になった田、持ち主不明の田: 割合は未確認。
- 地区による差が大きい。集積率38%の長糸・福吉と、88%の深江を比べる舞台にできる。
- 整備を「地元で検討中」の小富士、吉井下、神在は、合意形成の舞台の候補になる。
- 地代がゼロ以下になる田があることは、持ち主が「貸す」より「預けて管理費を払う」立場になる条件として使える。
