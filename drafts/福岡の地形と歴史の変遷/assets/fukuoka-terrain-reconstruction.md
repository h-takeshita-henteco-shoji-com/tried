# 福岡市の地形変化を再現する手順（推定版）

## 1. 結論

福岡市の地形の移り変わりは、推定を含めれば再現できます。
現代の地形から「後の時代に加わったもの」を順に取り除く方法をとります。
新しい時代ほど根拠が確かなため、過去へさかのぼると破綻しにくくなります。

## 2. 時代ごとの再現精度の目安

| 時代 | 精度の目安 | 主な根拠 |
|---|---|---|
| 現代 | 数m単位 | 国の標高データ、3D都市モデル |
| 明治〜昭和 | 十数m単位 | 当時の地形図、航空写真 |
| 江戸時代 | 数十m単位 | 古地図（位置の補正が必要） |
| 中世〜古代 | 推定が中心 | 発掘調査、地層の調査記録 |

## 3. 時代をさかのぼる順番と主な変化

### 3-1. 現代 → 昭和前期
なぜ: 最も記録が多く、変化の量も大きいためです。
何をする: 埋め立て地を取り除きます（百道浜・地行浜、アイランドシティ、港の埠頭など）。

### 3-2. 昭和 → 明治
なぜ: 近代の港づくりで海岸の形が変わったためです。
何をする: 港湾整備や川の付け替えを元に戻します。

### 3-3. 明治 → 江戸
なぜ: 城下町づくりの前の地形に近づけるためです。
何をする: 大濠公園を、海につながる入り江（草ヶ江）に戻します。
補足: 福岡城の堀は、この入り江を利用して造られました。

### 3-4. 江戸 → 中世
なぜ: 中世の博多は、今とは陸地の形が大きく違ったためです。
何をする: 博多を二つの砂丘（博多浜と息浜）に分け、間に入り江を置きます。

### 3-5. 中世 → 古代
なぜ: 古代は海岸線が今より内陸側にあったと考えられるためです。
何をする: 海岸線を内陸側に下げます。
補足: 鴻臚館（古代の外交施設）は海辺にあったと考えられています。

### 3-6. 古代 → 縄文時代
なぜ: 当時は海面が今より高かったためです（縄文海進＝気候の温暖化で海面が上がった現象）。
何をする: 福岡平野の奥まで海を広げます。

## 4. 作り方の流れ

### 4-1. 現代の標高データを用意する
なぜ: すべての時代の土台になるためです。
何をする: 国土地理院の標高データ（DEM＝地面の高さを細かい格子で記録したデータ）を入手します。

### 4-2. 地図ソフトに取り込む
なぜ: 古地図や海岸線を同じ位置に重ねて比べるためです。
何をする: QGIS（無料の地図作成ソフト）に標高データを読み込みます。

### 4-3. 古地図を現代の位置に合わせる
なぜ: 古地図は縮尺や方位がずれているためです。
何をする: 寺社や川の合流点など、今も残る目印で位置を補正します。

### 4-4. 時代ごとの海岸線をなぞる
なぜ: 陸と海の境目が、地形変化の中心だからです。
何をする: 古地図・発掘成果・地層の記録をもとに、海岸線を線で描きます。

### 4-5. 海の部分の標高を下げる
なぜ: 線だけでは立体的な地形にならないためです。
何をする: 海岸線の外側を「海」として、標高を海面より下にします。

### 4-6. 立体化して切り替えて見せる
なぜ: 時代の違いを直感的に伝えるためです。
何をする: Blender（無料の3D制作ソフト）などで立体化し、時代ごとに切り替えます。

## 5. 参考になる資料

- 国土地理院の標高データ（基盤地図情報）
- 地理院地図（土地の成り立ちを示す地図も見られます）
- 今昔マップ（明治以降の新旧地図を並べて見られるサイト）
- 福岡市の埋蔵文化財の発掘調査報告書
- 福岡市博物館などの古地図資料

## 6. 注意点

- 昔の標高は、ほとんど記録が残っていません。
- 中世以前は確定した正解がなく、「有力な説に基づく復元」になります。
- 説が分かれる部分は、根拠と一緒に示すと信頼性が上がります。

## 7. 最初の一歩のおすすめ

まずは「明治と現代の比較」から始めます。
根拠となる地図がそろっていて、変化も目で見て大きいからです。
