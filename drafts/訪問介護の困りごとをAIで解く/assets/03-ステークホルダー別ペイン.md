# 訪問介護のステークホルダー別ペイン

作成日: 2026年11月8日(訪問介護の現場のペインに広げて書き直した)

## この資料の結論

- **ペインは2つの層に分かれる。** 根にある「現場のペイン」(H1〜H6)と、その結果として運営指導で見つかる「行政指導から見たペイン」(P1〜P8)。
- **根にあるのは人材(H1)。** 人が足りない → シフトが崩れる → 予定を急に変える → 計画の直し忘れや記録の雑さにつながる。
- **行政指導から見たペインの本体は「書類どうしの整合」。** 食い違いは、組織・媒体・時間の3つの境界で起きる。
- **ペインが最も多く集まる立場は、サービス提供責任者とヘルパー。** 現場のペインと書類のペインの両方を受ける。

この資料は、もとの `03`(サービスを問わない整理)と、旧 `09-ペインの再考察.md`(統合して削除)と、行政指導以外のペインの考察を統合したもの。

---

## 対象と範囲

- **サービス:** 訪問介護。地域は福岡県・佐賀県を想定
- **ステークホルダー:** `06-訪問介護の業務一覧.md` の12の立場。行政と外部支援者は除く
- **ペインの範囲:** 訪問介護の現場のペイン。介護報酬のルールに関わるものに限らない

ペインと業務の場所の対応は、フロー図(`07-訪問介護のバリューチェーン.md`)の赤と橙の枠にある。

---

## ペインの全体像

### 2つの層

```
【現場のペイン(根)】
H1 人が採れない ──→ H2 シフトが崩れる ──→ H6 売上が読めない
   ↑                   │
   │(離職の一因)       ↓
H3 移動・待機が報われない   予定を急に変える
H4 ハラスメント            │
H5 育成・情報共有が難しい    ↓
                    【行政指導から見たペイン(症状)】
                    P1 計画の直し忘れ   P2 記録が雑になる
                    P3 突き合わせの誤り P4 勤務表が合わない
                    → 運営指導で見つかり、返還になる
```

- H3とH4は離職の理由になり、H1をさらに悪くする
- H4の原因で最も多いのは「サービスの範囲が伝わっていない」。報酬ルールの線引き(介護保険でできること・できないこと)の伝わり方の問題でもある
- P5〜P8は、人材とは別に、制度の側から来るペイン

### 書類のペインを生む3つの境界

1. **組織の境界(事業所とケアマネ)。** ケアプランと提供票はケアマネ、計画と実績は事業所が作る。ケアプランデータ連携の導入率は28%で、残りはFAX
2. **媒体の境界(紙・FAX、介護ソフト、Excel)。** 訪問系の介護ソフト導入率は65.7%。勤務表・研修・委員会・指針は介護ソフトの外にある
3. **時間の境界(日々の記録と、年1回の点検)。** 誤りは何年もたって見つかる。返還はさかのぼるため、遅いほど額が大きい。この境界が、ペインを「痛み」にしている根本

## ステークホルダー別のペイン

### 経営と管理

#### 経営者

人と収支の両方の責任を負う。

| ペイン | 場面 | ID |
|---|---|---|
| 求人を出しても応募がない | 採用の計画を立てるとき | H1 |
| 移動やキャンセルで、売上が読めない | 毎月の収支を見るとき | H6 |
| 加算を取るべきか、判断する材料がない | 体制を決めるとき | P8 |
| 処遇改善加算の配分と要件が毎年変わる | 計画書を出すとき | P6 |
| 改定で収入がどう変わるか読めない | 3年ごとの改定、臨時の改定 | P7 |

#### 管理者

基準を日々守らせ、ハラスメントや運営指導の窓口にも立つ。

| ペイン | 場面 | ID |
|---|---|---|
| 欠員で人員基準を割りそうになる | 退職や長期の休みが出たとき | H1、P4 |
| 勤務表と実際のシフトが合わない | 運営指導の準備 | P4 |
| 委員会・研修・指針・BCPの期限を忘れる | 年1回・半年ごとの義務 | P5 |
| ハラスメントの相談に、手を打てない | ヘルパーから報告が来たとき | H4 |
| 改定や自治体の通知に気づくのが遅れる | 改定時、集団指導のとき | P7 |

### 現場

#### サービス提供責任者

現場のペインと書類のペインの両方が集まる。最もペインが多い立場。

| ペイン | 場面 | ID |
|---|---|---|
| キャンセルや欠勤のたびに、代わりを探して連絡し直す | 毎日 | H2 |
| 予定を変えたのに、計画を直し忘れる | 急な変更のあと | P1 |
| ケアプランの変更を、計画と手順書に反映する | ケアマネから変更が来たとき | P1 |
| 新人に教える機会が、同行訪問しかない | 新人が入ったとき | H5 |
| ヘルパーの報告が遅れ、状態の変化をケアマネに伝えられない | 訪問のあと | H5 |
| ヘルパーの記録が要件を満たすか、確かめきれない | 月末の実績の締め | P2 |

#### 訪問介護員(ヘルパー)

1人で家に入り、直行直帰で働く。

| ペイン | 場面 | ID |
|---|---|---|
| 暴言・暴力・セクハラを受けても、その場で助けを呼べない | 訪問中 | H4 |
| 介護保険でできないことを頼まれ、断りにくい | 訪問中 | H4 |
| 移動や待機の時間に、賃金が払われないことがある | 訪問と訪問の間 | H3 |
| キャンセルや入院で、月の収入が急に減る | 毎月 | H3 |
| 訪問の合間に記録を書く。書いた記録が要件を満たすか分からない | 訪問のあと | P2 |
| 困ったときに、相談できる相手がそばにいない | 訪問中、訪問のあと | H5 |

## 各ペインの詳しい中身

### 現場のペイン(H)

#### H1. 人が採れず、ヘルパーの高齢化が進む

| 項目 | 内容 |
|---|---|
| 何が起きるか | 求人を出しても応募がない。いるヘルパーも高齢で、何年か先には辞めていく |
| なぜ起きるか | 賃金・収入の不安定さ・移動・ハラスメントなど、働き方の負担が重い(H3、H4) |
| 今の対処 | 求人媒体、紹介会社、知人の紹介 |
| 根拠 | 強い。訪問介護職員の有効求人倍率は15.53倍(2022年度、全業種平均は1.28倍)。訪問介護員の60歳以上は25.7%、30歳未満は6.1%。介護事業者の「人手不足」倒産は2025年に29件で過去最多 |

#### H2. シフトが毎日崩れ、サ責が調整に追われる

| 項目 | 内容 |
|---|---|
| 何が起きるか | キャンセルや欠勤で、予定が毎日変わる。代わりを探して連絡し、変更を伝える作業が続く。連絡ミスで訪問が抜けることもある |
| なぜ起きるか | 利用者の体調や入院は読めない。登録ヘルパーの空き時間もばらばら |
| 今の対処 | 電話、チャット、介護ソフトのスケジュール機能、Excel、ホワイトボード |
| 根拠 | 中。サ責の勤務は訪問3〜4時間と事務3〜4時間が一般的とされる。シフトの連絡をICT化して、サ責の連絡調整を月23時間減らした事例がある |

#### H3. 移動・待機時間が報われない

| 項目 | 内容 |
|---|---|
| 何が起きるか | 移動や待機の時間に、賃金が払われない。キャンセルや入院で、月の収入が急に減る |
| なぜ起きるか | 移動時間は介護報酬の対象外で、事業所の持ち出しになる |
| 今の対処 | 移動手当、訪問の詰め込み、直行直帰 |
| 根拠 | 強い。2020年に厚労省が「移動時間は原則として労働時間」とする通知を出した。無給の扱いが「未だに指摘されている」ためだった |

#### H4. 利用者や家族からハラスメントを受ける

| 項目 | 内容 |
|---|---|
| 何が起きるか | 暴言、暴力、セクハラを受ける。1人で家に入るので、その場で助けを呼べない |
| なぜ起きるか | 最も多い原因は「利用者・家族がサービスの範囲を理解していない」(43%) |
| 今の対処 | 契約時の説明、2人での訪問、契約の見直し |
| 根拠 | 強い。厚労省の調査(平成30年度)で、訪問介護職員の50%が利用者本人から受けたと答えた。相談窓口がない訪問介護員は43.2%(令和4年度、介護労働安定センター) |

#### H5. 直行直帰で、育成と情報共有が難しい

| 項目 | 内容 |
|---|---|
| 何が起きるか | 新人に教える機会が同行訪問しかない。利用者の状態の変化が、サ責やケアマネに届くのが遅れる |
| なぜ起きるか | ヘルパーが事業所に寄らずに働く |
| 今の対処 | 同行訪問、チャット、記録アプリ |
| 根拠 | 弱い(業界で一般に言われる話) |

#### H6. 移動とキャンセルで、売上が読めない

| 項目 | 内容 |
|---|---|
| 何が起きるか | 移動が長いほど訪問の件数が減る。キャンセルが出ると、その分の売上が消える |
| なぜ起きるか | 報酬は訪問した分だけ。令和6年度の改定で基本報酬が下がった |
| 今の対処 | 訪問先を近くにまとめる、サ高住の併設 |
| 根拠 | 強い。訪問介護の倒産は2025年に91件で、3年連続の過去最多。8割超が「売上不振」 |

### 行政指導から見たペイン(P)

#### P1. 計画の連鎖がずれる

| 項目 | 内容 |
|---|---|
| 何が起きるか | ケアプラン・訪問介護計画・手順書・実際の提供が食い違う。同意の日付が提供開始より後になる |
| なぜ起きるか | 組織と媒体の境界。急な変更(H2)が、計画と手順書に伝わらない |
| 今の対処 | ケアプランを手で転記し、サ責が直す |
| 根拠 | 強い。松山市の運営指導の資料に「サービスの内容や日程を変更しているにもかかわらず、計画が変更されていない」とある |

#### P2. 記録が要件を満たさない

| 項目 | 内容 |
|---|---|
| 何が起きるか | 時刻・内容・様子が足りない記録が残る。身体介護と生活援助の区分が記録と合わない |
| なぜ起きるか | 直行直帰で、書いたその場では誰も確かめない。訪問の合間に急いで書く |
| 今の対処 | 紙(複写式)か記録アプリ。サ責が後で目を通す |
| 根拠 | 強い。2026年2月、記録の捏造と同一建物減算の放置で、鹿児島県の訪問介護事業所が指定取消しになった |

#### P3. 月初の突き合わせが重く、誤りが残る

| 項目 | 内容 |
|---|---|
| 何が起きるか | 提供票・実績・給付管理票が合わず、返戻になる。2時間ルールや同一建物減算の誤りが残る |
| なぜ起きるか | 3つの境界がすべて重なる。毎月10日の締め切りで時間もない |
| 今の対処 | FAXとソフトの画面を見比べ、手で直す |
| 根拠 | 強い。同一建物減算の放置で指定取消し(鹿児島県、2026年)。減算逃れの不正事例(大阪府)。令和6年度に新区分ができ、松山市が指摘資料で取り上げた |

#### P4. 人員基準の証跡が合わない

| 項目 | 内容 |
|---|---|
| 何が起きるか | 勤務形態一覧表と、実際のシフトや出勤簿が合わない。サ責の配置数や常勤換算を示せない |
| なぜ起きるか | 勤務表はExcel、訪問の実績は介護ソフトにある。登録ヘルパーが多く、兼務と移動時間の扱いも複雑 |
| 今の対処 | 自治体の様式(Excel)に手で写す |
| 根拠 | 中(運営指導の指摘でよく挙がる) |

#### P5. ソフトの外の義務を忘れる

| 項目 | 内容 |
|---|---|
| 何が起きるか | 研修・委員会・指針・BCPの訓練が抜け、減算になる |
| なぜ起きるか | 年1回や半年ごとの義務で、日々の業務に組み込まれていない |
| 今の対処 | ひな形を写して作る。期限は管理者の記憶頼み |
| 根拠 | 中。令和6年度に、高齢者虐待防止措置の未実施減算と、業務継続計画の未策定減算ができた。実際に減算になった数は未確認 |

#### P6. 処遇改善加算の書類が重く、要件が毎年変わる

| 項目 | 内容 |
|---|---|
| 何が起きるか | 計画書と実績報告、賃金の実績が合わず返還になる |
| なぜ起きるか | 賃金データ(給与ソフト)と報告の様式(Excel)が分かれ、要件も毎年変わる |
| 今の対処 | 厚労省のExcel様式に手で入力する。社労士に頼むことも多い |
| 根拠 | 中〜強い。2026年6月の臨時改定で、訪問介護に最大28.7%の新区分ができた。2026年度は、ケアプランデータ連携への加入が特例の要件に入った |

#### P7. ルールの変更に追いつけない

| 項目 | 内容 |
|---|---|
| 何が起きるか | 改定・Q&A・ローカルルール・届出の電子化に気づくのが遅れる |
| なぜ起きるか | 資料が告示・通知・Q&A・自治体の通知に分散し、改定のたびに増える |
| 今の対処 | 市販本、ソフト会社の案内、集団指導の資料 |
| 根拠 | 弱い(業界で言われる話) |

#### P8. 加算と収支の判断材料がない

| 項目 | 内容 |
|---|---|
| 何が起きるか | 特定事業所加算などを取るべきか判断できない。収支の見通しが立たない |
| なぜ起きるか | 要件を満たす手間と、増える収入を並べた材料がない |
| 今の対処 | コンサルや同業者に聞く |
| 根拠 | 弱い。倒産の多さ(H6)は確かだが、判断材料のなさが原因という根拠はない |

## 最初の整理から変わった点

- **範囲を「訪問介護の現場のペイン」に広げた。** 行政指導から見たペインは、現場のペインの結果として起きる面がある
- **「調べる手間」(P7)は主役から外れた。** 返還の原因は、要件を知らないことより、証跡が合わないこと
- **「必要な証跡の一覧」は作らなくてよい。** 行政の確認文書と自己点検シートが、すでにその役を果たしている
- **LIFEと機能訓練指導員の論点は消えた。** 訪問介護は、LIFE関連の加算の対象外
- **新しく見えたペインがある。** シフトの崩れ(H2)、移動・待機(H3)、ハラスメント(H4)
