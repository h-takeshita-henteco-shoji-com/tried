# AI Mayor MCP のインターフェース設計

AI市長(Claude)が Cities: Skylines の街を見て、市長として操作するための道具の一覧。
Mod(`code/ai-mayor/src/`)が 127.0.0.1:8781 で HTTP の窓口を開き、MCPサーバー(`code/ai-mayor/mcp/server.py`)がそれを呼ぶ。

## 共通の決まり

- 座標はゲーム上のメートル。x が東、z が北。地図の中心が (0, 0)、端が ±8640。福岡のマップでは、ゲーム上の1m = 実寸2m
- 応答はJSON。成功は `ok: true`、失敗は `ok: false` と `error`
- ゲームの中身を読む処理はメインスレッド、作る・変える処理は計算スレッド(シミュレーション)で行う
- 建てるものは、ゲームの道具と同じく建設費を予算から払う(`pay=true` が既定)。人が置く骨格だけ `pay=false`
- 区画は最初から全81区画を持つ(#70 で決定)
- 解放の節目(マイルストーン)は確かめない。実際の市長には「人口が増えるまで建てられない施設」という制約がないため。区画と同じ考え方

## 道具の一覧

### 見る

| 道具 | 窓口 | 内容 |
|---|---|---|
| `city_info` | GET `/info` | 街の数字(人口、幸福度、所持金、週の収支、需要、日付、速度) |
| `screenshot` | GET `/screenshot` | 画面写真 |
| `move_camera` | GET `/camera` | カメラを動かす。実際の値も返す |
| `height_at` | GET `/height` | 地点の地面と水面の高さ |
| `economy` | GET `/economy` | 税率(区画の種類ごと)と予算(サービスごと) |
| `services` | GET `/services` | サービスの充足状況(電気、水、下水、ごみ、消防、警察、医療、教育など)の不足と余り |
| `zones_at` | GET `/zone/cells` | 指定した範囲の区画マスの指定の種類(確認用) |
| `buildings_near` | GET `/buildings` | 指定した範囲にある建物の一覧(種類、位置、状態) |
| `events` | GET `/events` | 前回から起きた出来事(つぶやき、節目、災害の警報など)。判断のきっかけに使う |

### 市民の声

実際の市長が数字だけでなく市民の声を聞いて判断するのと同じ材料を渡す。

| 道具 | 窓口 | 内容 |
|---|---|---|
| `citizens_summary` | GET `/citizens/summary` | 市民の内訳(年齢層、学歴、豊かさ、就業・失業、健康と幸福度の平均、電気や水が来ない市民の数) |
| `citizen_voices` | GET `/citizens/sample` | 無作為に選んだ市民の姿(属性、仕事、住まい、困りごと)。市民の立場から考える材料 |
| `complaints` | GET `/complaints` | 建物の困りごとの印を種類ごとに数え、多い場所を返す。苦情の地図 |
| `events` | GET `/events` | つぶやき(市民の声)。上の「見る」と同じ |

### 調べる

| 道具 | 窓口 | 内容 |
|---|---|---|
| `latlon_to_game` | (Modを呼ばない) | 緯度経度をゲームの座標に直す |
| `list_net_types` | GET `/net/prefabs` | 引ける線の種類(道路、線路、水道管、送電線など) |
| `list_building_types` | GET `/building/prefabs` | 置ける建物の種類(サービス、大きさ、建設費、維持費) |
| `list_policies` | GET `/policies` | 政策の一覧と、今かかっているか |

### 作る・消す

| 道具 | 窓口 | 内容 |
|---|---|---|
| `unlock_all_areas` | GET `/areas/unlock_all` | 全区画を無料で解放する |
| `build_line` | POST `/net/build` | 座標の並びに沿って線を引く(道路、線路、高速道路、水道管、送電線など)。端点は近くの点につなぎ、点がなければ既存の区間を途中で分けて交差点を作る。コマ撮りGIFも撮れる |
| `place_building` | GET `/building/place` | 建物(サービス施設、駅、空港など)を、位置と向きを指定して置く |
| `zone_area` | GET `/zone/area` | 円の中の区画マスを、住宅地・商業地・工業地・オフィスなどに指定する。解除もできる |
| `remove_line` | POST `/net/remove` | 線に沿った区間を消す |
| `bulldoze` | GET `/bulldoze` | 円の中の道路・線路と建物を取り壊す |

### 市政

| 道具 | 窓口 | 内容 |
|---|---|---|
| `set_tax` | GET `/economy/tax` | 区画の種類ごとの税率を変える(1〜29%) |
| `set_budget` | GET `/economy/budget` | サービスごとの予算を変える(50〜150%) |
| `set_policy` | GET `/policies/set` | 街全体の政策をかける・外す |

### 時間

| 道具 | 窓口 | 内容 |
|---|---|---|
| `set_time` | GET `/time` | 一時停止、再開、速度(1〜3) |
| `advance` | (MCPが組み合わせる) | 指定した日数だけ時間を進めて止める。判断の単位(1か月)を作る |

## 判断の単位との関係

判断の型は `code/ai-mayor/mayor/protocol.md`(#72)に書いた。月例(30日)、見回り(10日)、臨時の3種類。

## まだ入れないもの

- 地区(ディストリクト)の線引きと、地区ごとの政策。線引きの塗り方を設計してから入れる
- 公共交通の路線(バスや電車の停留所と路線の設定)
- 保存と読み込み。人が行う
- 取り壊しの払い戻し
