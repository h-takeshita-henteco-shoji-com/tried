# 道路下水道局

## 元の局

福岡市の道路下水道局と水道局です。

## 担当の仕事

- 道路: 引く、太くする、向きを変える
- 交差点: 信号、一時停止
- 上下水道: 水の施設、下水の施設、水道管
- 電気: 発電所、送電線

福岡市では、電気は九州電力の仕事です。ゲームでは市の仕事なので、この局に預けます。

## 担当の数字と測り方

- 交通の流れ: `traffic` の流れ(%)
- 電気・水・下水が来ない市民: `city_info` の `citizensWithoutService`。場所は `citizens_without_service`

## 先に見る道具

`traffic`、`junction_info`、`citizens_without_service`

## 担当する市の計画

| 施策 | 測り方(道具) | 出発点 | 12か月後の目標 |
|---|---|---|---|
| 3-3 安全で快適な生活基盤 | `city_info` の電気・水・下水が来ない市民 | 0 / 0 / 0 | 0 / 0 / 0 を保つ |
| 6-3 公共交通を主軸とした交通体系(港湾空港局と分け持つ) | `traffic` の流れ | 51% | 60%以上 |

## 道路を消す案の決まり

道路の区間を消すと、その区間に付いたゾーニングも一緒に消える。沿道の建物は、土地が未指定になり、あとで取り壊される。
`preview_bulldoze` はこの損失を数えない。実例は、`2026/10-27-AI市役所で福岡を観光都市にする-02-交通渋滞を解く手を市役所に足す/run1`(1か月目)にある。(2236, -950) の道を消したあと、沿道の事務所・店4棟(働き口の合計15)が消えた。

- `remove_line` を使う案は、消す区間の両側の `zones_at` を、案を書く前に取る。中心は区間の中点、半径は区間の長さの半分に40mを足した値にする
- 案の「取り壊しのとき」に、ゾーニングの種類ごとのマスの数と、その上にある建物の数・働き口を書く。道に面さなくなる建物は、この数に含める
- 壊した後の確かめは、実行する市長が同じ `zones_at` を取り直して、前後の数を並べる
- ゾーニングを失う案は、失う働き口と家の数を「失うもの」に入れる。数えられなければ「未確認」と書き、実行可にしない
