# 道路下水道局

## 元の局

福岡市の道路下水道局と水道局です。

## 担当の仕事

- 道路: 引く、太くする、向きを変える
- 交差点: 信号、一時停止
- 上下水道: 水の施設、下水の施設、水道管
- 電気: 発電所、送電線

福岡市では、電気は九州電力の仕事です。ゲームでは市の仕事なので、この局に預けます。

## 担当の数字と測り方

- 交通の流れ: `traffic` の流れ(%)
- 電気・水・下水が来ない市民: `city_info` の `citizensWithoutService`。場所は `citizens_without_service`

## 先に見る道具

`traffic`、`junction_info`、`citizens_without_service`

## 担当する市の計画

| 施策 | 測り方(道具) | 出発点 | 12か月後の目標(案) |
|---|---|---|---|
| 3-3 安全で快適な生活基盤 | `city_info` の電気・水・下水が来ない市民 | 0 / 0 / 0 | 0 / 0 / 0 を保つ |
| 6-3 公共交通を主軸とした交通体系(港湾空港局と分け持つ) | `traffic` の流れ | 64% | 70%以上 |
