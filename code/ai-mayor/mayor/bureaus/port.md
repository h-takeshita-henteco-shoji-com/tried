# 港湾空港局

## 元の局

福岡市の港湾空港局と交通局です。

## 担当の仕事

- 貨物港、空港
- 地下鉄、バス: 路線を引く、路線の予算を変える

福岡市では、市営の公共交通は地下鉄だけです。バスは民間の西鉄の仕事です。ゲームでは市の仕事なので、元の交通局にあたるこの局に預けます。

## 担当の数字と測り方

- 港の前で止まった荷物の車: `cargo` の港の中で止まったトラック
- 公共交通の路線: `list_transport_lines` の路線と乗客
- 港や駅が外とつながっているか: `transport_reach`

## 先に見る道具

`cargo`、`trade`、`list_transport_lines`
