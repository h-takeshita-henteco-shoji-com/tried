# マップの地形

市役所と議会のハーネスで、すべての役が読む地形の資料です。任期中は変わらないものだけを書きます。
建物の空きは毎月変わるので、ここには書きません。見る段で毎月、道具で確かめます。

- 範囲は、x と z が -8,640〜+8,640 の17.28km四方。1m は実寸2m
- 測り方は、`code/ai-mayor/tools/scan_map.py` で、144m間隔の格子(121×121点)の地面と水面の高さを測った。地面が水面以上なら陸地
- 図は `city-map.png`。赤い点は道路、緑は陸地、青は海と川
- 測った街は `fukuoka-tourism-m12-end`(2050-12-28)。地形は任期中ほぼ変わらない

## 図の読み方

街(道路のある範囲)は、中央の x -3,000〜4,000、z -2,200〜1,500 にあります。
北は海(博多湾から玄界灘)、南と東は丘と山です。東の端の細い赤い線は、高速道路です。

## 局への使い方(案)

- 観光の名所を置く場所を探すとき、街の中だけでなく、島と空き地も候補に入れる
- 島に置くには、橋か道路、電気、水、下水が要る。本土までの海の幅(約720〜775m)を渡る手が確かめられていない。`test_build_line` で橋が架かるかを試す
- ここにない場所は、局が見つけたら、市政ノートに書く
