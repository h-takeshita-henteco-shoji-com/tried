# へんロボの解説動画の作り方

記事の内容を、へんロボ1人が説明する動画にする手順です。
#132 で初めて作りました。台本、声、立ち絵の動き、組み立てまでを、このフォルダのスクリプトで行います。

動画は記事を書き終えてから作ります。台本の事実を、記事と記録にそろえるためです。
動画と声のファイルは大きいので、リポジトリに置きません(`~/henrobo-video/<Issue番号>/` と `.gitignore`)。

## 流れ

1. 台本を書く
2. 声を作る
3. 読みを確かめる
4. 1場面だけ試しに作る
5. 全体を作り、コマを並べて確かめる
6. タイトル画面とサムネイルを作る
7. YouTube に上げる

## 1. 台本を書く

分かりやすい解説動画の型にならうため、構成を決めています。
台本は、その日のフォルダの `henrobo-script.md` に書きます。

- 構成: ハイライト → 決まり文句 → 3つの目次 → 3つの解説 → まとめ
- 3つ目の目次には、へんロボ(書き手)の見立てを置く
- 目次の言葉は、各章の始めとまとめで、同じ言葉をそのまま使う
- 決まり文句: 冒頭は「へんロボです。中小企業のAI導入の現場から、試したことをそのままお伝えします。」締めは「へんロボでした。それでは、また。」
- 字幕は1行で出す。そのため、台詞は1行1文、30字までにする
- 事実は、記事と記録にあるものだけを使う
- 台詞の頭に `(間)` と書くと、その前に間があく。`(キラリ)` と書くと、その台詞の後に眼鏡が光る
- へんロボを大きく出す場面は作らない。右下にいつもいるので、2人に見えるため

## 2. 声を作る

声は、Qwen3-TTS で作った声の見本(`B_en_calm_1.wav`)を元に、1行ずつ複製します。

```bash
~/.venvs/tried-audio/bin/python code/henrobo/voice_lines.py <台本.md> <voice フォルダ> <tts-readings.tsv>
```

- 読み違える語は、読みの表(`tts-readings.tsv`)でかなに置き換える。字幕は台本の漢字のまま
- 数と単位、熟語は特に読み違える(「10のAI」「込み入った」「標準詳細図」など)
- 作り直す行は、wav を消してから流し直す。残っている wav は飛ばす

## 3. 読みを確かめる

音声合成は、熟語や数字をよく読み違えます。耳で全部を聞く前に、音声認識で候補を絞ります。

```bash
~/.venvs/tried-asr/bin/python code/henrobo/listen_check.py <voice フォルダ>
```

- Whisper にひらがなで書き起こさせ、台本の読みと比べる。結果は `listen-check.tsv`
- 似ている割合が低い行から聞き直す
- 漢字のまま書き起こされた語は、実際の読みが分からない。「聞き取り」の列を人が見る
- 読みの表の値そのものが正しいかも、ここで確かめる。#132 では、表に誤って「とお」と書いていた

## 4. 1場面だけ試しに作る

全体を作ると時間がかかるため、先に1場面で見た目を確かめます。

```bash
~/.venvs/tried-audio/bin/python code/henrobo/build_video.py <その日のフォルダ> 8
```

出力は `preview-8.mp4` です。画面の割り付け、字幕、口パク、キラリを確かめてもらってから、全体に進みます。

## 5. 全体を作り、確かめる

```bash
~/.venvs/tried-audio/bin/python code/henrobo/build_video.py <その日のフォルダ>
```

- 場面ごとの図とカードは、その日のフォルダの `henrobo_scenes.py` の `SCENES` に書く。書き方は #132 と #138 の `henrobo_scenes.py` を見る
- 録画も場面に使える（#136）。`clip("~/henrobo-video/<番号>/録画.mp4", 始め秒, 終わり秒)` と書く。録画は、声で決まる場面の長さに合わせて速さを変えて流す。1つの場面に図と録画を混ぜると、項目ごとに同じ長さを割り当てる
- 場面の長さは、声の長さで決まる
- できたら、いくつかの時刻のコマを ffmpeg で抜き出して並べ、重なりや文字の小ささを確かめる

## 6. タイトル画面とサムネイルを作る

同じ絵を、動画の先頭3秒と YouTube のサムネイルに使います。

```bash
~/.venvs/tried-audio/bin/python code/henrobo/thumbnail.py <その日のフォルダ>
```

- 題の文言と背景の図面は、`henrobo_scenes.py` の `THUMB` に書く
- サムネイルは `assets/thumbnail.jpg`(1280x720)。動画の先頭には、`build_video.py` が同じ絵を入れる

## 7. YouTube に上げる

手順は、リポジトリの README の「YouTubeの公開手順」です。

- 文面は、その日のフォルダの `youtube.md` に書く
- チャプターの時刻は、場面の始まりにタイトル画面の3秒を足して出す
- API で上げるなら `youtube_upload.py`。許可のしるしの期限が切れていたら、先に取り直す

## 新しい回で用意するもの

スクリプトは、その日のフォルダを引数で受け取ります（#138 で直した）。新しい回では、その日のフォルダに次を置きます。

- `henrobo-script.md`: 台本
- `tts-readings.tsv`: 読みの表。前の回の表を写し、台本に合わせて足す
- `henrobo_scenes.py`: 場面の図とカード（`SCENES`）と、タイトル画面の文言（`THUMB`）
- `youtube.md`: 投稿の文面

声の見本とへんロボの立ち絵は、#132 のフォルダのものをどの回でも使います。
`youtube_upload.py` だけは、まだ #132 のフォルダを直接指しています。
