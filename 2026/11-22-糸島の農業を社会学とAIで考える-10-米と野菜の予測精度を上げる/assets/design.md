# 予測精度を上げる設計(#186)

#184 の予測に材料を足し、精度が上がるかを段ごとに比べる。
問いは「値段の推移だけでは足りないのか。足すなら何が効くのか」。統計のモデルと Claude の両方で確かめる。

## 1. 出発点(#184 の結果)

- 米: 2026年産の9〜10月の平均は21,364円。どの方法も高すぎた(誤差+33〜99%)。先物だけが実績に近かった
- 野菜(福岡12品目、6月末から7〜9月を予測): 最良は ETS の誤差13.3%。4つの統計モデルの平均は12.5%

## 2. 精度が低かった原因(なぜなぜ分析の推察)

精度に影響する要因を、データと手法のほかに4つ立てた。詳しくは log.md。

| 要因 | 米 | 野菜 |
|---|---|---|
| 1. 予測する問題の決め方 | 主な原因。市場の見通し(概算金・先物)を材料にしなかった | 学習(確報)と答え(日別の集計)で作り方が違う。影響は小さいと推察(未確認) |
| 2. 予測した時点のあとの出来事 | 小さい | 主な原因。誤差の分散の78%が全モデルに共通。外れた年は7〜8月に九州で大雨・猛暑 |
| 3. 値段の決まり方の変化 | 主な原因。2026年産の-37.8%は、過去の最大の下げ(-16.5%)の外 | 見えない |
| 4. 答え合わせの仕方 | 2026年は1問だけ | 2026年の誤差14.1%は過去10年の平均14.3%と同じ。手法の差は偶然の幅 |

ここから、次の見込みを置く。

- 野菜は、手法を替えて減らせる誤差は2割ほど。天候で決まる部分の大きさを測ることを優先する
- 米は、在庫率の回帰では2026年産を当てられない見込み。市場の見通しを材料にする段を設ける

## 3. 米の段

米は年に1問しか答えがない。そのため、過去の年産を1年ずつ予測する試験を主にする。

| 段 | 方法 | 足す材料 |
|---|---|---|
| R0 | 前年産の平均(#184 の素朴な予想) | なし |
| R1 | 年産平均を在庫率で回帰する | 6月末の民間在庫 ÷ 需要量 |
| R2 | R1 に生産の見込みを足す | 作付意向、または収穫量 |
| R3 | 概算金から年産平均を回帰する | JA の概算金(新潟コシヒカリなど) |
| R4 | Claude に過去の年の需給・概算金・値段の表を渡す | R2・R3 と同じ材料を、過去の年の分も |

- 先物は比べる相手に置く。上場が2024年8月なので、学習には使えない。先物の値をそのまま答えにはしない
- 試験: 2016〜2026年産の11問。毎年、その年の8月末までに出ていた数字だけで予測する
- 予測する時点を、8月末と9月半ばの2つにして比べる(概算金が出そろう前と後)
- 回帰の変数は1〜2個まで(年が17しかないため)
- 学習の期間を変えて比べる(2018年の生産調整の廃止より前を含めるか。2024年以降をどう扱うか)
- 事前登録: R1・R2 は2026年産を当てられない(誤差+20%より大きい)と予想する

## 4. 野菜の段

| 段 | 方法 | 足す材料 |
|---|---|---|
| V0 | #184 の ETS、4つの統計モデルの平均 | なし |
| V1 | 複数のモデルを組み合わせる(平均、品目ごとに過去の成績で選ぶ) | なし |
| V2 | 入荷量を足す | 6月までの入荷量 |
| V3 | 天候を足す | 6月までの気温・降水量・日照 |
| V3+ | 天候の上限の目安 | 7〜9月の実際の天候(予測ではない) |
| V4 | 12品目をまとめて1つのモデルで学ぶ(LightGBM) | V2・V3 と同じ |
| V5 | Claude に入荷量と天候の表を足す | V2・V3 と同じ |

- 予測の時点では、7〜9月の入荷量と天候はまだ分からない。V2〜V5 は6月までの値だけを使う
- V3+ は「天候が分かれば、どこまで当たるか」の目安。天候で決まる部分の大きさを測るために置く
- 入荷量は値段と同時に決まるので、7〜9月の実際の入荷量は渡さない
- 天候の地点: 福岡市場の主な産地を、品目ごとに1〜2か所選ぶ
- 試験: #184 と同じ。過去10年の6月末から7〜9月を予測する試験と、2026年の試験。2026年10月の実績が取れたら、9月末から10月の予測も足す

### 価格の作り方の確認

- 2026年について、福岡の日別データから、産地の割合を固定した価格を作る。平均価格との差で、産地の割合が変わった分を測る
- 取れれば、2026年の確報と日別の集計を比べ、作り方の違いによるずれを測る
- 産地の割合の影響が大きいときだけ、東京都中央卸売市場の日報(2004年から。高値・中値・安値)を取りに行く。等級ごとの価格はどの統計にもない

## 5. 答え合わせの決まり

- 精度の差には、ブートストラップで95%の幅を付ける
- 品目ごとに、減らせない誤差の目安(V3+ の誤差)を出す
- 精度が上がらなかった段も、そのまま結果として残す

## 6. 答えを見たあとの調整を防ぐ

#184 と同じ決まりで行う。

- Claude を回す前に、指示文・入力ファイル・ハッシュを log.md に書く
- Claude は、リポジトリを読めない新しい会話で呼ぶ
- 統計のモデルは、2026年の結果を見る前に、過去10年の成績だけで設定を決める

## 11. 追加: 専門家の見通しを材料にする(V6、2026-11-28)

米では、市場の見通し(概算金)を足すと当たった。野菜で同じ役を果たす材料として、農林水産省「野菜の生育状況及び価格見通し」を使う。

- 資料: 毎月末に、翌月の東京都中央卸売市場の出荷数量と価格を、品目ごとに「平年並み」「やや上回る」などで見通す。2011年8月分から公開
- 数値への直し方: 上回る +2、やや上回る +1、平年並み 0、やや下回る -1、下回る -2。前半と後半に分かれる月は平均する
- 対象: 12品目のうち、見通しに載る品目(こまつなは載らない)
- V6a(6月末の予測): 7月の見通しで、#184 の7月の予測を直す。8・9月にも同じ点を当てた場合も見る
- V6b(1か月先の予測): 2016〜2026年の各月末から翌月を、#184 の5つのモデルで予測する。その月の見通しで直す
- 直し方: log(実績 ÷ 予測)を見通しの点で回帰する(12品目まとめて)。その年より前の年だけで学ぶ。2019〜2026年を1年ずつ試す
- 診断: 見通しの点が、東京の価格の平年との比をどれだけ言い当てているか

## 12. 追加: 野菜の改善の実行計画(2026-11-28)

外れの多くは、予測のあとに全国で同時に起きる値動きである。大きな改善は見込みにくいので、段ごとに続けるかを決める。

- 段0(上限): 答えに近い材料で直したら、5モデル平均の誤差がどこまで下がるかを測る。O1 同じ月の東京の値動き、O2 同じ月の東京の産地の割合、O3 東京の産地の割合で重みをつけた、同じ月の実際の天候。東京の値動きでも10%を切らなければ、段1は小さくする
- 段1(6月末に分かる材料): 1a 6月の東京と福岡の値段の差、1b 6月に東京へ入った次の産地の量、1c 産地に合わせた6月の天候(7月だけ直す)。採用は、誤差が0.5ポイント以上減り、95%の幅が0をまたがないとき
- 段2(Claude の確かめ): V5 を、年と品目名を伏せて2019〜2025年で回す。先に2026年で、伏せても結果が変わらないかを見る
- 段3(問題の決め方): 3a 毎月の見直し(1か月先の予測をつなぐ)、3b 80%の幅の当たり具合
- 共通: 2019〜2026年を1年ずつ試す。直し方は log(実績 ÷ 予測) を材料で回帰(12品目まとめて、その年より前で学ぶ)。各段の前に log.md に事前登録する
