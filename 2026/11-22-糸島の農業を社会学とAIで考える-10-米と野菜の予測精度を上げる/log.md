## 試したこと

#184 の予測に説明の材料を足し、精度が上がるかを比べる。米は民間在庫・作付意向・JAの概算金(設計の段4・段5)、野菜は入荷量と天候を足す。2026年10月までの実績で答え合わせもやり直す。

## 精度が低かった原因の分析(#184 の結果から)

要因を「データ」「手法」のほかに4つ立て、それぞれなぜなぜ分析をした。数字は #184 の結果から計算した。

- 野菜では、誤差の分散の78%が5つの統計モデルに共通だった。品目×月の73〜100%で、モデルが同じ向きに外れた。手法を替えて減らせるのは2割ほどと見られる
- 野菜の年ごとの平均絶対誤差は11.9〜20.5%。2026年は14.1%で平年並み。大きい年は2020年(20.5%)、2021年(20.0%)、2017年(19.5%)、2018年(18.4%)。いずれも7〜8月に九州で大雨や猛暑があった年(気象データでは未確認)
- 米の年産平均の変化は、2010〜2023年産で最大-16.5%(2014年産)。2026年産は-37.8%で、過去の幅の外だった。Claude の最良の予測28,500円は前年産比-17%で、過去の最大の下げとほぼ同じ
- 先物は8月末に実績とほぼ同じ値だった。新米の値段の情報は、予測した時点に市場にあった

推察: 米は「値段の決まり方の変化」と「問題の決め方(市場の見通しを材料にしなかった)」が主な原因。野菜は「予測した時点のあとの出来事(主に天候)」が主な原因。

## #186 の結果を受けたなぜなぜ分析

確認済みの事実と推察を分けて書く。(推察)と書いたものは、まだ確かめていない。

### 米1: 在庫率の回帰(R1)は、学習期間で誤差が-22%〜+12%まで変わった

1. なぜ変わったか: 2024・2025年産を学習に入れるかどうかで、傾きが変わるため
2. なぜ傾きが変わるか: 2024・2025年産は、過去の関係から大きく外れた(R1の誤差は-26%と-23%)
3. なぜ外れたか: 在庫が少ない年に、値段が過去の傾きより大きく上がった。値段が上がると備蓄米が放出されて在庫が増える、逆向きの関係もある(推察)
4. 原因: 値段の決まり方が変わった(要因3)。17年分では、この曲がった関係を推定できない

### 米2: 概算金を足すと当たった(R3 -1.0%、Claude +3.9%)

1. なぜ当たったか: 2026年産の概算金は2026年8月18日に決まり、すでに下がった相場を映していた
2. なぜ相場を映すか: JA は、売れる値段から逆算して概算金を決める(推察)
3. つまり、8月末の予測は「市場の見通しを読む」問題だった。統計の工夫で足せる分は小さい
4. 原因: 問題の決め方(要因1)。#184 では、市場の見通しを材料にしていなかった

### 米3: 概算金を使っても、2024・2025年産は外れた(R3 -28.8%、+78.5%)

1. なぜ外れたか: 2024年産は値段が概算金の1.41倍になった。2025年産は回帰の傾きが1.80まで上がった
2. なぜそうなるか: 概算金は、相場が急に変わる年には後から追いかける形で決まる(推察)
3. 原因: 値段の決まり方の変化(要因3)。概算金は、相場が落ち着いた年か、相場の向きが変わったあとにだけ効く

### 米4: Claude は在庫の表だけでは+32%だった(r4a)

1. なぜ高く出たか: 8月の31,556円を出発点にし、過去の8月→9月の下げ幅(4〜13%)を当てはめた(理由の文で確認)
2. なぜ下げ幅を当てはめたか: 表の数字から式を作らず、似た年を探して当てはめる推論をした
3. なぜ似た年で外れたか: 2026年の在庫率は過去最高で、似た年がない。似た年の最大の下げ幅では、実際の-32%に届かない
4. 原因: Claude の推論の型(手法)と、過去にない値(要因3)が重なった。概算金という水準の目安があれば当たった

### 野菜1: 統計のモデルに入荷量・天候を足しても、精度は上がらなかった(V2・V3)

1. なぜ上がらないか: 外れの59%は、東京でも同時に起きた値段のずれ(全国で共通)だった
2. なぜ6月までの材料で読めないか: 6月までの福岡の入荷量は、外れをほとんど説明しない(R²0.07)
3. なぜ説明しないか: 7〜9月の主な産地は北海道・高原などで、その出来は7〜8月の天候で決まる(要因2)
4. 実際の7〜9月の天候を渡しても、上がらなかった(V3+)。品目ごとに1地点では産地を代表できないか、天候の効き方が直線でない(推察)

### 野菜2: Claude に入荷量・天候の表を足すと、少しだけ上がった(V5 14.4%→12.8%)

1. どこが上がったか: キャベツ・はくさい・きゅうり。どれも低めに外れていた予測を、上に直した
2. なぜ上に直したか: Claude は「6月の大雨で7月の供給が減る」と読んだ(理由の文で確認)
3. なぜその読みが効いたか: 対応する地点の軽井沢と佐賀は、2026年6月の降水量が18年で最も多かった
4. なぜ統計では効かなかったか: 統計のモデルは、平年に近い年が多い中で、直線の関係を学ぶ。極端な年だけに強く効く関係は、拾いにくい(推察)
5. 原因の推察: 天候は、極端なときだけ値段に強く効く。ただし、同じ軽井沢のレタスは直らなかった。答えは2026年の1回だけで、偶然を消せない

### 野菜3: V5 でも、大きな外れは残った(にんじん8月+65%、ばれいしょ7月-44%、レタス9月-32%)

1. どんな品目か: 季節で産地が入れ替わる品目
2. なぜ外れるか: 東京では、にんじんの外れの50%が、産地の割合が平年と違ったことによる
3. なぜ6月に読めないか: 次の産地の出来は、6月の時点ではまだ見えない
4. 原因: 問題の決め方(要因1。平均価格は産地の割合で変わる)と、予測のあとの出来事(要因2)

## 結果

### 米 R1: 在庫率の回帰(2026-11-23)

- データ: data/supply_annual.csv。6月末民間在庫(基本指針ベース、生産者在庫を含む)と需要実績。2008〜2023年は農水省「米をめぐる状況について」(令和5年8月)のグラフの数字、2024〜2026年は基本指針。2026年6月末243万t・需要683万tは2026-07-28公表(8月末に既知)
  - 注意: 2009〜2023年の需要は、グラフの数字の読み取り。表で確かめていない
- 値段: 年産平均(9月〜翌8月)、消費税を抜いた値。2009年産は公表の年産平均14,470円。2026年産は9〜10月の平均
- モデル: 年産平均の対数の前年差 = a + b × 在庫率(在庫÷需要)の対数の前年差。2010年から前年までで学習し、毎年1年先を予測
- 事前の予想(design.md、実行前に記入): 2026年産は当てられない(誤差+20%より大きい)。**外れた**
- 結果(誤差は予測÷実績−1)
  - 2026年産: 学習を全期間にすると19,113円(-3.4%)、80%の幅14,851〜24,599円。2023年までだと22,169円(+12.1%)。2018年からだと15,470円(-21.8%)。どれも幅の中に実績が入った
  - 2016〜2023年産: 誤差-7.7〜+7.1%。平均絶対誤差4.4%。前年産のままは7.0%
  - 2024年産 -26.0%、2025年産 -22.8%。値上がりは在庫率では説明できなかった(2025年は在庫率がほぼ同じなのに+33%)
- 読み: 2026年の値下がりは、7月末に出ていた在庫の増え方(155→243万t)でかなり説明できた。#184 で外れたのは、価格の系列だけを使い、需給の表もその年の分しか渡さなかったため。一方で、値上がりの局面(2024・2025年)は在庫では説明できず、学習の期間で2026年の予測が-22%〜+12%と大きく変わる

### 野菜 V3・V3+ の事前登録(実行前に記入、2026-11-23)

- 天候: data/weather_monthly.csv(気象庁、月ごと)。地点は7〜9月の主な産地(2026年の福岡の日別データで数量1位)に合わせる: キャベツ・はくさい・レタス=軽井沢、こまつな・なす=福岡、トマト=熊本、きゅうり=佐賀、ブロッコリー・にんじん・ばれいしょ=帯広、たまねぎ=網走、ねぎ=大分
- 平年からの差: 地点・月ごとに、予測する年の前年までの平均との差。降水量は比の対数
- 方法: #184 の予測(指数平滑法、5つの統計モデルの平均)の外れ log(実績/予測) を、天候の差で回帰して直す。12品目で1本の式(品目ごとに式を作るには点が足りない)
  - V3(予測として使える): 4〜6月の気温・降水量・日照の差
  - V3+(上限の目安): 予測する月とその前の月の、気温・降水量・日照の差
- 試験: 2019〜2026年。毎年、その前の年までの外れで式を作る(2016年からの3年以上)
- 予想: V3 は誤差をほとんど減らさない(1ポイント未満)。V3+ は2〜4ポイント減らす

### 野菜 V3・V3+ の結果

- 事前の予想は外れた。V3+(実際の天候を渡す版)でも、誤差は減らなかった
- 2019〜2026年の平均絶対誤差(元 → 直したあと)
  - 5モデル平均: V3 13.71 → 14.61(差+0.9、95%の幅 +0.24〜+1.6)。V3+ 13.71 → 13.83(+0.12、-0.52〜+0.76)
  - 指数平滑法: V3 15.31 → 16.78(+1.47、+0.79〜+2.17)。V3+ 15.31 → 15.74(+0.43、-0.08〜+0.98)
- 12品目で1本の式では、降水量だけが効いた(雨が多いと値段が予測より高い。標準化した係数0.039、p=0.002)。気温と日照は効かなかった
- 探索(事前登録なし): 品目ごとに実際の天候で式を作ると、当てはまったのは地元の産地が主の品目だけだった。こまつな(福岡、R²=0.39)、ねぎ(大分、0.32)、なす(福岡、0.25)。1年ずつ抜いて試すと、こまつな16.3→14.6%、ねぎ10.3→9.4%。ほかの9品目は悪くなった
- 読み: 「外れの多くは天候」という推察は、1地点の月の天候では支えられなかった。キャベツやたまねぎの値段は、全国の産地の出来で決まる。1地点の天候では、その全体を表せない。外れが全モデルに共通である(78%)ことは変わらないので、原因は全国の出荷量など、ほかの材料にある可能性が高い

### 野菜 V2 の事前登録(実行前に記入)

- 入荷量: 福岡市場の品目ごとの月の数量(data/fukuoka_monthly.csv、2026年は日別の集計)。平年からの差は、前年までの同じ月の平均との比の対数
- V2(予測として使える): 4〜6月の入荷量の差。V3 と同じく、外れ log(実績/予測) を12品目で1本の式で直す。試験は2019〜2026年
- 診断(予測ではない): 予測する月の実際の入荷量の差で、外れがどこまで説明できるかを見る。入荷量は値段と同時に決まるので、予測には使えない
- 予想: V2 は誤差を1ポイント未満しか減らさない。診断では外れの3割以上を説明する(R²>0.3)

### 野菜 V2 の結果と、外れの出どころの診断

- V2(4〜6月の福岡の入荷量): 誤差は減らなかった。指数平滑法 15.31→15.85%(差の95%の幅 +0.27〜+0.81)、5モデル平均 13.71→13.88%(-0.16〜+0.53)
- 診断: 予測する月の福岡の実際の入荷量でも、外れの7%しか説明できなかった(R²=0.07)。事前の予想(R²>0.3)は外れた
- 追加の診断(事前登録なし): 東京都中央卸売市場の明細データから、11品目の月の数量と価格を作った(data/tokyo12_monthly.csv。ばれいしょは品目名が合わず除いた)
  - 福岡の外れの59%は、同じ月の東京の「平年と違う値動き」で説明できた(R²=0.59)。品目ごとの相関は0.53〜0.93。たまねぎ0.93、レタス0.90、にんじん0.89、キャベツとトマト0.86
  - 東京の入荷量では14%(直近3年との差で測った場合。前年までの全平均との差では6%)。入荷量が多いと、予測より安い(向きは予想どおり)
  - V2b(4〜6月の東京の入荷量で直す): 14.08→14.32%で、減らなかった
- 読み: 外れの多くは、福岡だけでなく東京でも同時に起きた、全国に共通の値動きだった。ただし、その値動きは市場の入荷量でも1地点の天候でも、あまり説明できない。予測の時点(6月末)で手に入る材料では、取り除ける見込みが小さい

### 米 R3 の事前登録(実行前に記入)

- 概算金: data/gaisankin.csv(サブエージェントが報道から収集。新潟一般コシヒカリ1等の当初額)。値があるのは2010・2013・2014・2018〜2026年。2018・2019・2013年は前年比からの逆算
- 決定日は2021年以降8月16〜19日。8月末の予測で使える
- モデル: 年産平均(税抜)の対数 = a + b × 概算金の対数。前年までの値がある年で学習し、2019〜2026年を1年ずつ予測
- 予想: 2026年産の誤差は±10%以内

### 米 R3 の結果

- 事前の予想(±10%以内)どおり。2026年産は19,576円(-1.0%)、80%の幅16,608〜23,075円
- 2019〜2023年産: 誤差-5.8〜+4.1%
- 2024年産 -28.8%: 概算金(17,000円)が決まったあと、集荷の競争で値段が上がった(追加払いで18,500円)。実績/概算金の比は、ほかの年の0.93〜1.07に対し1.41
- 2025年産 +78.5%: 2024年の外れ値で傾きが1.80まで急になり、30,000円の概算金から過大に予測した。「値段 ≒ 概算金」とするだけなら-5.7%
- 参考: 「値段 ≒ 概算金」だけで2026年産は-6.5%
- 注意: 学習の点が4〜11しかない。2018・2019・2013年は逆算値。概算金の税込み・税抜きは年で揃っていない(2020年以降は税込み)

## 学び

- 米の8月末の予測は「市場の見通しを読む」問題だった。概算金という水準の目安を渡すと、統計のモデルも Claude も当たった。ただし2024・2025年産のように相場が急に変わる年は、概算金でも外れる
- 野菜の外れの大部分は、予測のあとに全国で同時に起きる値動きだった。同じ月の東京の値動きが分かれば誤差は約4ポイント下がるが、6月末の材料(入荷量、天候、産地、見通し)では、その動きを捉えられなかった
- 天候と値段の相関はある(前の月の雨が多いと高い、r≈0.3)。しかし、気象台を増やして産地で重みをつけても、予測の外れはほとんど説明できなかった
- Claude が統計のモデルに勝ったのは、品目名と地点名から産地を知り、天候を当てはめたときだけだった。名前を伏せると、統計のモデルと同じ水準に戻った。名前を出すと過去の年の答え合わせが汚れ、伏せると知識が使えない。この2つを同時に満たす試験は、まだ作れていない
- Claude は、渡された専門家の見通しを強く信じる。見通しが外れた2026年7月は、予測が悪くなった(V7)。統計のモデルは、過去の当たり具合から見通しの重みを小さくした
- 事前登録したので、外れた予想(R2、V2、V3、V7、段1、段2の2026年)も消さずに残せた。外れた予想が、次に何を確かめるかを決める材料になった
