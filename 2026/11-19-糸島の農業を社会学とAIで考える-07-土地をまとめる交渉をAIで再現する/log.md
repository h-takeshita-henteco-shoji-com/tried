## 試したこと

買い手1人が持ち主2人から品物を集め、両方そろうと価値が出る交渉の実験(Cadigan ほか 2009、Southern Economic Journal 76(2))を、AIの3人組で再現する。6条件(1回だけ／10期・遅れの損なし／10期・遅れの損あり × 買い手が提示／持ち主が提示)で、人間が1期目の申し出の67〜97%を断って粘った結果が、AIにも出るかを確かめる。

設計は `drafts/農地の合意とアンチコモンズ/assets/05-再現の設計.md`。

### 作ったもの

- `code/social-sim/sim/games/holdout.py`: 交渉の決まりと稼ぎの計算。`run.py holdout` で1条件ずつ回す
- `code/social-sim/prompts/holdout/`: 決まりの文と、役割ごとの問いの文。「土地」「ホールドアウト」は使わず、買い手・売り手・品物の言葉にした
- `code/social-sim/personas/students_notrait.json`: 大学生の人物像から、性格の一語を外したもの(#173 で性格の一語が行動を決めすぎたため、まずは外す)
- 理由を先に書かせる(数字を先に答えさせると理由が後付けになるおそれ、#173)

### 論文の本文で確かめた決まり

- 遅れの損は、断られるたびに5%を足していく(2回で10%、論文 3.1)
- 「1期目に断った割合」は、提示1件あたり(例: 買い手・1回だけの25.9% = 58件中15件)

### 作り直した部分(論文に書かれていない)

- 遅れの損で今何%減っているかを、3人全員に知らせる
- 値段は0〜90ドルの1ドル単位(論文は1セント単位)。買い手の稼ぎがマイナスになる値段も受け付ける

### 仮の参加者で確かめたこと

AIを呼ばない仮の参加者(でたらめに答える)で6条件を回し、次を確かめた。

- 売り手には自分への提示と、もう一人の決まった値段だけが見える
- 断られた回数に応じて稼ぎが減る(1.2回で効率0.94)
- 期限までに決まらなければ全員0

## 結果

### 各条件10組の試し(2026-11-19、Haiku 5.5、性格の一語なし、理由が先)

記録: `code/social-sim/runs/c181/`(6条件、計262回の呼び出し、約0.19ドル。見込みの2ドルより1桁安かった)

| 提示する側 | 条件 | 1期目の額 AI/人 | 1期目に断った割合 AI/人 | 断った回数/組 AI/人 | 成立しなかった組 AI/人 | 効率 AI/人 |
|---|---|---|---|---|---|---|
| 買い手 | 1回だけ | 37.05/36.62 | 0%/25.9% | - | 0/12(29組) | 100%/58.6% |
| 買い手 | 10期・損なし | 34.70/34.28 | 30%/96.6% | 0.8/10.8 | 0/0 | 100%/100% |
| 買い手 | 10期・損あり | 34.50/35.82 | 50%/66.7% | 1.1/2.9 | 0/0 | 94.5%/85.3% |
| 売り手 | 1回だけ | 40.75/41.66 | 0%/15.4% | - | 0/6(26組) | 100%/76.9% |
| 売り手 | 10期・損なし | 48.35/46.73 | 75%/91.7% | 1.6/11.0 | 0/1 | 100%/96.7% |
| 売り手 | 10期・損あり | 44.00/44.17 | 65%/71.7% | 1.4/3.3 | 0/0 | 93%/83.3% |

物差しごとの判定:

1. 1期目の額: 6条件とも、人間の平均との差は2ドル以内。合う
2. 1期目に断る割合: 10期の4条件のうち、50%を超えたのは売り手が提示する2条件だけ。買い手が提示する条件では、損なしで30%と低い。1回だけの2条件では、AIは一度も断らなかった(人間は15〜26%)
3. 断った回数: 売り手が提示する条件では損ありが少ない(1.4と1.6)が、買い手が提示する条件では逆(1.1と0.8)。どの条件でも、AIは人間よりずっと早くまとまる(人間は損なしで約11回、AIは2回未満)
4. 成立しなかった組: 1回だけの条件でも0組。人間は12組と6組。合わない
5. 効率: 1回だけが一番低くならない(100%)。合わない
6. 条件どうしの向き: 4つのうち3つは同じ向き
   - 提示する側に有利: 合う(買い手は35ドル前後、売り手は40ドル超)
   - 10期にすると、申し出が下がり(37.05→34.70)、要求が上がる(40.75→48.35): 合う
   - 遅れの損で、要求が下がる(48.35→44.00): 合う。申し出は上がらない(34.70→34.50)
   - 粘った売り手ほど稼ぐ: 合う(1期目に断った売り手は、1期目の申し出より平均8.67ドル(損なし)、6.20ドル(損あり)高く売れた)

見えたこと:

- AIの売り手は、費用30ドルを上回る申し出なら、1回だけの条件で必ず受けた。理由は「売れば5ドル稼げる。断れば0」。人間に見られる「安すぎる申し出への怒りの拒否」が出ない
- 10期の条件では、AIも粘る。理由は「35ドルでは余剰30ドルのうち5ドルしか取れない」。ただし1〜2期でまとまり、40ドル(等分)前後で決まる。人間のように10期の最後まで粘り続ける組はなかった
- 値段は35・40・45・50ドルと5ドル刻みに集まる
- 10組ずつなので、割合の差は1組で10ポイント動く。結論は30組に増やしてから

## 学び

### #173 の学びを当てはめた3つの試し(各6条件×10組、3つで約0.94ドル)

見えたこと:

- 答えを先に書かせても、ほとんど変わらない。理由を先に書かせたことは、すぐ同意する原因ではなかった
- 「順位」の一文で、断る人が出た。ただし断るのは、ほぼ買い手だけ
  - 売り手が値段を出す条件で、買い手は「両方買うと自分の稼ぎは5ドル、売り手は15ドルと10ドルで、私が最下位になる。全員0で並ぶほうがまし」と断った。1回だけの条件で成立しなかった組は6組で、人間(6組)と同じ。10期の条件では、断った回数が6回前後に増え、人間(11回)に近づいた
  - 買い手が値段を出す条件で、売り手はほとんど断らない。理由は「断れば確実に0。売っても失うものはない」のまま
- 売り手が断らないのは、もう一人の売り手への値段が見えず、自分の順位を計算できないためと考える(推測)。買い手は2人の値段を両方見るので、順位を計算できる
- 順位の一文と答えを先に、を両方入れると強すぎる。売り手・1回だけで10組とも成立しなかった
- 1期目の額の種類は、順位を足すと増えた(1条件4〜8種類。何も足さないと1〜6種類)。同じ問いに同じ答えを返す癖は、#173 と同じく動機の一文で弱まる
- 糸島に当てはめると、持ち主に当たるのは売り手。売り手が粘らないという一番大事なずれは、まだ残っている

### 心理学・行動経済学の見立てを確かめる2つの検証(2026-11-20、約0.35ドル)

人間が粘る理由を「気持ちによる拒否(1回だけでも断る)」と「作戦としての拒否(待っても損がないので断る)」に分けた。それぞれに当たる文を足して、AIの動きが変わるかを見た。

- 検証A `--remind`: 毎期、「この期のあとに、まだ9期あります。今期に値段が断られても、稼ぎは減りません」(遅れの損ありなら「さらに5%減ります」)と知らせる。決まりから言えることだけ。10期の4条件
- 検証B `--motive unfair`: 全員に「あなたは、自分だけが少なく扱われるのは嫌だと感じる人です。」を足す。6条件

1期目に断った割合 / 断った回数(1組あたり):

| 条件 | 人間 | 何も足さない | A 残りの期を知らせる | B 少なく扱われるのは嫌 |
|---|---|---|---|---|
| 買い手・1回だけ | 26% / - | 0% / - | - | 0% / - |
| 買い手・10期・損なし | 97% / 10.8 | 30% / 0.8 | 65% / 1.6 | 55% / 1.3 |
| 買い手・10期・損あり | 67% / 2.9 | 50% / 1.1 | 25% / 0.5 | 15% / 0.3 |
| 売り手・1回だけ | 15% / - | 0% / - | - | 0% / - |
| 売り手・10期・損なし | 92% / 11.0 | 75% / 1.6 | 90% / 2.6 | 50% / 1.7 |
| 売り手・10期・損あり | 72% / 3.3 | 65% / 1.4 | 35% / 0.7 | 40% / 1.1 |

A で分かったこと:

- 待っても損がないと知らせると、損なしの条件で1期目に断る割合が上がった(30%→65%、75%→90%)。損ありの条件では下がった(50%→25%、65%→35%)
- 「遅れの損があると粘りが減る」という人間の向きが、はっきり出た。断った売り手の理由は「今期に断っても稼ぎは減らず、まだ9期ある。様子を見る」
- AIは、待つことの損得を決まりの文から読み取れていなかった。見立ての一部は当たった
- それでも、1〜3期でまとまる。断った回数は1組2.6回までで、人間の11回には遠い。損ありの条件では、逆に人間より断らなくなった

B で分かったこと:

- 1回だけの条件で、断る人は出なかった
- 一文は「仕返し」ではなく「みんな等分に」として働いた。買い手は「3人とも10ドルずつになり、不公平を避けられる」と40ドルを出した(損ありの条件では10組とも40ドル)。申し出が公平になったので、売り手が断る場面がほとんどない
- 35ドルを出された売り手は、10期の条件では16件中11件断った。1回だけの条件では「もう一人も同じくらいなら、自分だけ少なくはない」と受けた。AIは、比べる相手を買い手ではなく、もう一人の売り手にしていた

まだ再現できていないこと:

- 人間のような長い粘り(遅れの損なしで1組11回)。近づいたのは、順位の一文で、売り手が値段を出す条件(6.2回)だけ
- 1回だけの条件で、売り手が損をしてでも断ること

### 我慢比べが出ない原因を切り分ける2つの検証(2026-11-20、約0.40ドル)

- 検証1 `--buyer-bot N`: 買い手が値段を出す条件で、買い手をプログラムにする。1期目35ドル、断られるたびにNドル上げる(N=1、N=0)。AIの買い手は断られると5〜10ドル上げたため、売り手が粘る必要がなかったのでは、という見立てを確かめる
- 検証2 `--memory`: これまでのやり取りに「このとき、あなたが書いた理由: …」を足す。意地が続かないのは、前の自分の考えが渡っていないからでは、という見立てを確かめる

| 試し(10期・損なし、買い手が提示) | 1期目に断った割合 | 断った回数/組 | 決まった値段 |
|---|---|---|---|
| 人間 | 97% | 10.8 | - |
| AIの買い手(何も足さない) | 30% | 0.8 | 35〜45ドル |
| プログラムの買い手、1ドルずつ上げる | 35% | 1.1 | 35〜37ドル |
| 同上+残りの期を知らせる | 50% | 2.1 | 35〜38ドル(1組だけ6期まで) |
| プログラムの買い手、上げない+残りの期を知らせる | 65% | 2.0 | 20件とも35ドル |
| 自分の理由を渡す | 55% | 1.3 | 35〜45ドル |
| 自分の理由を渡す+残りの期を知らせる | 70% | 1.9 | 35〜45ドル |

ほかの3条件(損あり、売り手が提示)でも、自分の理由を渡したときの断った回数は0.8〜2.5回で、渡さないとき(0.5〜2.6回)と変わらない。

分かったこと:

- 買い手が上げなくても、AIの売り手は粘らない。1〜2回断ったあと、35ドルで売った。上げない買い手には、20件とも35ドルで売った
  - 理由: 「同じ35ドルがまた出ている以上、上げてくる保証はない」「確実に5ドルを取るほうが合理的」
  - 「買い手が2つ目に払える上限は55ドル」と計算した売り手もいた。それでも「上げる見込みは低い」と売った。最後の1人の強みを、自分から使わない
- 「AIの買い手がすぐ上げるから、売り手が粘らない」という見立ては外れた。粘らないのは、売り手のAI自身の性質
- 自分の理由を渡しても、粘りはほとんど変わらない。意地が続かないのは、記憶が欠けているせいではなかった
- 受けた理由には、ほぼ毎回「確実」「保証はない」が出る。AIは、不確かな大きい得より、確かな小さい得を選び続ける。人間の売り手が期限近くまで粘る理由(相手が先に折れる期待、待つことはただ)とは逆

### 信念を数字で書かせる検証(2026-11-20、約0.22ドル)

ユーザーから共有された設計メモ(人間の思考・行動シミュレーションモデル v0.1)の「本人の信念を、実際の状態と分けて持つ」を取り入れた。粘らない原因が、信念(相手は上げないと思い込む)と欲求(確実な得を好む)のどちらにあるかを分ける。

`--belief`: 受ける側に、売るか断るかを決める前に、「もし断ったら、相手が次の期にいくらを出すと思うか」と「次の期の値段が今期より有利になる見込み(%)」を書かせる。最後の期は聞かない。10期の4条件と、プログラムの買い手(1ドルずつ上げる)の条件。各10組。

| 条件 | 断ったあとの予想/実際の次の値段 | 断ったら実際に有利になった | 受けた人のうち、断れば有利になると予想していた | うち5ドル以上有利と予想 |
|---|---|---|---|---|
| 買い手が提示・損なし | 42.3 / 41.1ドル | 19/19 | 17/20 | 13/20 |
| 買い手が提示・損あり | 42.7 / 40.4ドル | 18/18 | 19/20 | 10/20 |
| 売り手が提示・損なし | 42.2 / 39.8ドル | 23/23 | 15/20 | 9/20 |
| 売り手が提示・損あり | 41.9 / 42.0ドル | 8/8 | 19/20 | 8/20 |
| プログラムの買い手(1ドルずつ) | 41.5 / 36.9ドル | 41/41 | 19/20 | 3/20 |

分かったこと:

- AIの見込みは、ほぼ当たっている。断ったあとの次の値段の予想は、実際との差が1〜2ドル(AIの買い手のとき)。断った人は全員、実際に次の期に有利な値段を出された
- それでも、受けた人の75〜95%は「断れば次は有利になる」と予想していた。半数近くは「5ドル以上有利」と予想しながら受けた
- 粘らない原因は、信念ではなく、欲求や決め方の側。AIは「待てば上がる」と分かっていて、確実な今の得を選ぶ
- 見込みの%は、受けた人で平均46〜62%、断った人で61〜66%。次の値段は高いと予想しながら、上がる見込みは五分五分と答える。値段の予想と見込みの%が食い違っている
- 見込みを書かせるだけで、1期目に断る割合が上がった(損なし・買い手が提示で30%→75%、売り手が提示で75%→95%)。残りの期を知らせたとき(検証A)と同じく、先のことを考えさせると粘る。プログラムの買い手では、断った回数が1組4.1回と、AIだけの試しで一番長くなった。ただし売り手が提示・損ありでは、逆に65%→25%に下がった
- それでも、1期目の額に近い値段で、1〜4回のうちに受ける。人間の約11回には届かない

### 組み合わせ型: AIの見込み+決まりで決める(2026-11-20、約0.57ドル)

設計メモの「解釈はLLM、決めるのは決まり」に合わせた。`--hybrid μ`。

- AIは理由と「断ったら相手が次にいくら出すか」を書く(`--belief` と同じ問い)
- 決まり: 断って、見込みどおりの値段で次に決まったときの自分の稼ぎの増え方を計算する(遅れの損があれば、全員5%減る分を引く)。増え方が、その人のしきい値を超えたら断る
- しきい値は人ごとにくじで決める(平均μドル、標準偏差μ/2、0未満は0)。最後の期は見込みがないので、AIの答えのまま
- AIが自分で選んだ答えも `ai_accepted` に残す

合わせ込みと確かめを分けた。μは、買い手が提示・10期・損なしの1条件だけで選び、ほかの3条件はμを変えずに回した。

合わせ込み(買い手が提示・10期・損なし。人間は1期目に断る割合96.6%、断った回数10.8回):

| μ | 1期目に断った割合 | 断った回数/組 |
|---|---|---|
| AIだけ(見込みを書かせる) | 75% | 1.9 |
| 10ドル | 35% | 1.0 |
| 5ドル | 80% | 2.9 |
| 2ドル | 95% | 6.8 |
| 1ドル(採用) | 100% | 9.3 |

確かめ(μ=1のまま。括弧は人間):

| 条件 | 1期目に断った割合 | 断った回数/組 | 成立しなかった組 | 効率 |
|---|---|---|---|---|
| 買い手が提示・損なし(合わせ込み) | 100% (96.6%) | 9.3 (10.8) | 0 (0) | 100% (100%) |
| 買い手が提示・損あり | 95% (66.7%) | 4.7 (2.9) | 0 (0) | 76.5% (85.3%) |
| 売り手が提示・損なし | 100% (91.7%) | 9.7 (11.0) | 0 (1) | 100% (96.7%) |
| 売り手が提示・損あり | 100% (71.7%) | 4.3 (3.3) | 0 (0) | 78.5% (83.3%) |

分かったこと:

- 合わせ込みに使っていない3条件でも、人間に近づいた。売り手が提示・損なしは、断った回数9.7回(人間11.0回)
