# 台本: へんロボ、土地をまとめる交渉をAIで再現する

#181 の記事（`article.md`）の内容を、へんロボ1人の説明で動画にします。
交渉の記録を Godot で再生した録画（`assets/holdout_replay.mp4`。動画を作るときは `~/henrobo-video/181/` に置く）を、場面として使います。

## 前提

- 構成: ハイライト → 決まり文句 → 今日の話 → ゲームのルール → 3つの目次 → 1つ目 → 2つ目 → 3つ目 → エンディング → 次回 → プレイ動画1本 → 締め
  - ルールは目次の前で説明する。各章をすぐ本題から始めるため
- 目次の言葉: 目次、各章の始め、エンディングで、同じ文をそのまま使う。字幕の30字に収めるため、「何の話か」の1文と「中身」の1文に分ける。エンディングは「〜でした」にする
  - 1つ目: 「1つ目は、AIの売り手の話です。」「AIの売り手は、値段が上がると分かっていても売りました。」
  - 2つ目: 「2つ目は、断る判断の話です。」「断るかをプログラムが決めると、断る回数が人間に近づきました。」
  - 3つ目: 「3つ目は、値段を出す側のAIの話です。」「値段を出すAIは、断られるとすぐに大きく譲りました。」
- 決まり文句: 冒頭は「へんロボです。中小企業のAI導入の現場から、試したことをそのままお伝えします。」締めは「へんロボでした。それでは、また。」
- 字幕: 台詞1行が1文。字幕は1行で出すので、どの文も30字まで。冒頭の決まり文句だけは、言葉を変えずに読点で2行に分ける
- へんロボ: 落ち着いた大人の男性の会社員。丁寧語で、大げさにしない普通の話し方。1人で説明する
- 言葉の決まり（視聴者は、その台詞までに聞いたことしか知らない前提で書く。台本を直したら、別のエージェントに敵対的に反証させる）:
  - 何を・誰が、を省かない。30字に収めるときは、主語と目的語でなく修飾語を削るか、2文に分ける
  - 比喩の動詞（動く・揺らぐ・止まる など）と、ぼかした言い方を使わない
  - 言葉をそろえる:
    - ゲームの取り決めは「ルール」。「決まり」は台詞で使わない
    - 2つの交渉を言い分ける: 「AIだけの交渉」（AIが全部を判断）と「プログラムが手伝った交渉」（断るかどうかをプログラムが決める）。どちらの話かを、章の始めで言う
    - プログラムが手伝った交渉で断ったのは「プログラム」。「AIが断った」とは言わない
    - 人は「買い手」「売り手」。ゲームの中で「持ち主」は使わない（糸島の話の「田の持ち主」だけ）
    - 値段に答えるときは、売り手なら「売る／断る」、買い手なら「買う／断る」、両方なら「応じる／断る」。「受ける」は使わない
    - 値段の変化は「値段が上がる」「値段を上げる」。「値上げ」は使わない
    - 「粘る」は、値段が上がるのを待って断ること。「譲る」は、相手に有利な値段に変えること。どちらもルールの節で意味を言う
    - お金は「稼ぎ」でそろえる。「得」「利益」は、AIの言葉の引用のときだけ
    - 箇条や理由を並べるとき、「1つ目」「2つ目」は目次だけに使う。章の中では「1つの候補」「もう1つの候補」と言う
    - 「1ターン」「1回の交渉」「4つの条件」「遅れの損」「1回きりの交渉」「境目の額」は、意味を言ってから使う
- 事実は、記事（`article.md`）と記録（`log.md`、`code/social-sim/runs/c181*`）にあるものだけを使う
- へんロボを大きく出す場面は作らない（右下にいつもいるため）
- 眼鏡のキラリは、台詞の頭に「(キラリ)」と書いた行の直後に入れる
- 「(間)」は、その台詞の前に間をあける合図
- 録画は2本。冒頭用の `holdout_hook.mp4`（9秒、AIだけの交渉の1組）と、`holdout_replay.mp4`（2分17秒）。後者の中身は、タイトル → 4つの条件の1組ずつ（買い手が出す・損なし → 買い手が出す・損あり → 売り手が出す・損なし → 売り手が出す・損あり）→ まとめ。どの組も「プログラムが手伝った交渉」で、値段を出すAIが譲る幅もプログラムで抑えた版
