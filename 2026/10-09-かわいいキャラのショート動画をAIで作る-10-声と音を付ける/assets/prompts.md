# 指示文

> 声の設計は #28 に切り出した。このファイルは #28 の出発点として残す。

## 方針

- どんの声を先に決める。ぬめと音は、どんが決まってから合わせる(Issueの区切り)。
- 方言は地域を決めない。単語は標準語で、語尾と間だけで方言らしくする(10-06 世界観設定書)。
- 同じ台詞と同じ指示文を、5つのAI(GPT、ElevenLabs、VOICEVOX、MiniMax Speech、Fish Audio)に渡して聞き比べる。進め方は `comparison.md`。
- 指示文は2段に分ける。
  - キャラの声: 声そのものを決める。どの台詞にも同じものを使う。
  - 台詞ごとの読み方: 間と語尾だけを足す。声の説明は書かない。
- 声は先に `voice-baseline.md` の文章で決める。本番の台詞は、決めた声で最後に読ませる。
- 性別は決めない。指示文に男女を書かない(10-06 キャラ設定書)。
- 結果は `generated/don_gpt_1.mp3` のように、キャラ・AI・回数で名前を付ける。

## AIごとの入れ方

「キャラの声」の文章は、声の説明だけで、読ませる台詞を含まない。
そのままでは音声は出ない。AIごとに、説明と台詞を次のように入れる。
画面の名前は変わることがあるので、見つからなければ近い名前の欄を使う。

- GPT: ChatGPT のアプリではなく、OpenAI の読み上げ(gpt-4o-mini-tts)を使う。試すだけなら OpenAI.fm、なければ OpenAI Platform の Playground(Audio)。説明は指示の欄(Instructions / Vibe)、台詞は本文の欄(Script)に分けて入れる。下の「GPT に入れる文章」を使う。
- ElevenLabs: 声を作る画面(Voice Design)に、説明を入れて声を作る。できた声を選び、読み上げの画面(Text to Speech)に台詞だけを入れる。
- MiniMax Speech: 声を作る画面(Voice Design)に説明を入れて声を作る。作れなければ、用意された声から低めのものを選ぶ。台詞は読み上げの欄に入れる。
- Fish Audio: 用意された声から、説明に近いものを選ぶ。台詞だけを入れる。説明の欄があれば、そこに説明を入れる。
- VOICEVOX: 説明は使えない。台詞を入れ、下の「指示文を使えないAIの目安」で数値を調整する。

## キャラの声

### どん

```
「どん」の声。冬を何度も越えた年寄りのカピバラで、いつもぬるい湯だまりに浸かっている。
性別は決めない。男とも女とも決めにくい声にする。
声は低く柔らかく、少しかすれていて、温かい。
話す速さはとても遅い。答える前に小さな間を置く。温かい湯に浸かりながら考えている感じ。
ほとんど独り言のように、小さな声で話す。誰かに向けて声を張らない。
落ち着いていて、何があっても動じない。
語尾と間にだけ、田舎の柔らかさを出す。特定の地域の方言やなまりは真似しない。単語のアクセントは標準語のままにする。
明るくしない。芝居がかった読み方や、アニメのような演技はしない。
```

### ぬめ

```
「ぬめ」の声。今年の梅雨に生まれた小さなナメクジで、まだ冬を知らない。
性別は決めない。小さな子どものような、男とも女とも決めにくい声にする。
声は小さく軽く、少し高い。少し息が混じる。
短い文を、さっと素直に話す。
よく質問をする。声にかすかな心配がにじむが、甘えた声にはしない。
自然な標準語で話す。かわいこぶらない。キンキンした声や、アニメのような演技はしない。
```

### 指示文を使えないAIの目安

VOICEVOX や AivisSpeech は、指示文ではなく数値で調整する。

- どん: 話す速さを遅く、音の高さを低めに、抑揚を小さくする。文の前と「、」の後に間を足す。
- ぬめ: 話す速さはふつう、音の高さを高めにする。抑揚は少しだけ大きくする。
- 調整は1キャラ5分までにする(60分に収めるため)。

## 台詞ごとの読み方

キャラの声の指示文の後ろに、次の1行を足す。

### どん(カット6)

台詞:

```
……んー。今日は、ぬるい寄りだな
```

足す指示:

```
この台詞では、最初の「……」で長めに間を置く。「んー」は伸ばし、最後を少し下げる。「今日は」の後に短い間を置く。「だな」は、消えそうなくらい柔らかく終える。
```

### ぬめ(カット3)

台詞:

```
……んしょ
```

足す指示:

```
この台詞は、石に登るときに出る、短く小さな力みの声にする。ほとんど息の音でよい。誰かに話しかける言葉にはしない。
```

## GPT に入れる文章

GPT の読み上げは、指示の欄と本文の欄が分かれている。
声は新しく作れない。用意された声から1つ選び、指示文で寄せる。
声を選ぶ欄は、名前が英語で並ぶ(alloy、ash、sage など)。

### 1回目: どん(`voice-baseline.md` のどん1・3・5)

- 声: 低めのものを3つほど試し、一番近いものを残す。選んだ名前を `comparison.md` に書く。
- 指示の欄: 「キャラの声 / どん」をそのまま入れる。
- 本文の欄:

```
……んー。熱いっていうより、ぬるい寄りの熱い、だな

おれは、ここでいい

……行ったか
```

### 2回目: ぬめ(`voice-baseline.md` のぬめ2・4・5)

- 声: 高めで軽いものを選ぶ。どんと同じ声にしない。
- 指示の欄: 「キャラの声 / ぬめ」をそのまま入れる。
- 本文の欄:

```
どん、まだ熱い?

そっか

……んしょ
```

### 2回目: 2匹のやりとり

GPT の読み上げは、1回に1つの声しか使えない。
そこで、1行ずつ別に作り、あとで1つにつなぐ。

1. ぬめの声とぬめの指示で「どん、まだ熱い?」を作る
2. どんの声とどんの指示で「……んー。熱いっていうより、ぬるい寄りの熱い、だな」を作る
3. ぬめの声とぬめの指示で「そっか」を作る
4. 1〜3をつなぐ。1と2の間は、1秒ほど空ける(どんが遅れて答える間)

### 本番: どん(カット6)

- 声: 1回目で残したもの
- 指示の欄: 「キャラの声 / どん」の後ろに、「台詞ごとの読み方 / どん(カット6)」の足す指示を続ける
- 本文の欄: `……んー。今日は、ぬるい寄りだな`

### 本番: ぬめ(カット3)

- 声: 2回目で残したもの
- 指示の欄: 「キャラの声 / ぬめ」の後ろに、「台詞ごとの読み方 / ぬめ(カット3)」の足す指示を続ける
- 本文の欄: `……んしょ`

## ElevenLabs に入れる文章

ElevenLabs は2段階で使う。
まず声の説明から声を作り(Voice Design)、次にその声で台詞を読ませる(Text to Speech)。
画面の名前は変わることがあるので、見つからなければ近い名前のものを使う。

### 1段目: どんの声を作る(Voice Design)

声の説明の欄に、下の文章を入れる。
日本語で思った声が出なければ、英語の版に替える。

日本語の版:

```
年寄りのカピバラの声。性別は決めず、男とも女とも決めにくい声。低く柔らかく、少しかすれていて、温かい。とても遅く、独り言のように小さな声で話す。落ち着いていて、何があっても動じない。日本語を話す。特定の地域のなまりはない。明るくせず、アニメのような演技はしない。
```

英語の版:

```
An old, calm capybara speaking Japanese. Gender-neutral voice, neither clearly male nor female. Low, soft, slightly husky and warm. Very slow, quiet, like muttering to oneself. Unbothered and relaxed. Standard Japanese with no regional accent. Not cheerful, not theatrical, no anime-style acting.
```

試し読みの文章の欄には、下の文章を入れる。
短すぎると断られることがあるので、どんの台詞をつないで長くしてある。

```
……んー。熱いっていうより、ぬるい寄りの熱い、だな。おれは、ここでいい。湯気が上がるのを見てると、時間がすぎるのを忘れる。……そうか。……行ったか。
```

候補が数個出るので、聞き比べて1つを保存する。名前は「どん」にする。

### 2段目: 台詞を読ませる(Text to Speech)

- 声: 1段目で保存した「どん」
- モデル: 一番新しいもの(Eleven v3 など)。古いモデルより、間と息づかいが出やすい
- 安定度(Stability): 真ん中(Natural など)から始める。演技が強すぎたら上げる
- 本文の欄: 下の文章。`voice-baseline.md` のどん1・3・5にあたる

```
[ため息] ……んー。熱いっていうより、ぬるい寄りの熱い、だな。

おれは、ここでいい。

……行ったか。
```

`[ため息]` のような角かっこは、Eleven v3 の演技の指示(音声タグ)。読み上げずに、演技として反映される。
日本語のタグが効かなければ、英語の `[sighs]` に替える。それでも読み上げてしまうなら、タグを消す。

### 本番: どん(カット6)

```
[ため息] ……んー。今日は、ぬるい寄りだな。
```

### ぬめの声を作るとき

どんが決まってからにする。説明は「キャラの声 / ぬめ」を短くして使う。

```
A tiny young slug, like a small child, speaking Japanese. Gender-neutral. Small, light, slightly high and a little breathy. Short, plain sentences with a faint worried tone. Not cute-acting, not squeaky, no anime-style acting.
```

試し読みの文章:

```
どん、あれ何。どん、まだ熱い?ぬめ、もう行く。そっか。……んしょ。
```

本番(カット3)の本文: `[小さく力む] ……んしょ`(効かなければ `[exhales]`)
