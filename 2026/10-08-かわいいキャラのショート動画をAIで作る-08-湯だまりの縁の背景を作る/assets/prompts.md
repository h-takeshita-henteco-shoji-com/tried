# 指示文

背景3枚の指示文。順番は C1(夕方の引き)→ C9(夜)→ C2(フキの葉の寄り)。
画風の参照として、ぬめとどんの決定稿を添付する。キャラは描かせない。

## C1. 夕方の湯だまりの縁(引き)

添付: `input/nume-4views.png`、`input/don-bath-front.png`(画風の参照のみ)

```
添付の2枚は画風の参照です。キャラクターは描かないでください。
線の太さ、黒い輪郭線、平塗りの塗り方だけを合わせてください。

縦長(9:16)の背景画を1枚描いてください。キャラクターも人も描きません。

場面: 夕方の小さな湯だまりの縁。地面に近い低い目線からの引き。
- 画面の左: 縁の平たい石。上面は平らで、何も載っていない。
- 画面の右と右下: 湯だまりの水面。右から左へ、湯気がゆるく流れる。
- 右下の水面は、後で顔を重ねるため、物を置かずに空けておく。
- 画面の左端の外に庭石がある想定。庭石そのものは映さない。
- 左下の隅に、フキの葉の端が少しだけ見える。
- 空はオレンジから薄紫への夕方の色。

描かないもの: キャラクター、人、動物、文字、建物。
```

## C9. 夜の湯だまりの縁(C1と同じ構図)

添付: C1で決めた1枚

```
添付の画像と、構図・線・形をまったく同じにしてください。
変えるのは色だけです。時間を夕方から夜にします。

- 空: 濃い紺。星を少し。
- 全体: 明るさを落とし、青寄りにする。
- 湯気: 白く残し、夜でも見えるようにする。
- 物の位置、大きさ、輪郭線は動かさない。

描かないもの: キャラクター、人、動物、文字、月。
```

## C2. フキの葉の端(寄り)

添付: C1で決めた1枚、`input/nume-4views.png`(画風と大きさの参照)

```
添付の1枚目と同じ場所、同じ夕方の色と画風で、寄りの背景を描いてください。
キャラクターは描きません。

縦長(9:16)。
- フキの大きな丸い葉の端を、少し下から見上げる寄り。
- 葉の裏側が少し見える。葉脈は太い黒線で数本だけ。
- 葉の端から、小さな生き物が顔を出せる隙間を空けておく。
- 背景は湯だまりの縁の地面と、ぼかした夕方の空。

描かないもの: キャラクター、人、動物、文字。
```
