# m02 道路下水道局の案

## 施策

- 施策: 都心の南北の道 x=520(z=10 から z=190)の Basic Road 4区間を Medium Road に太くする。道具は `build_line`(既存の端点にそろえて Medium Road を引く)
- 議決: 要らない

## 実行計画

- 対象と操作順:
  1. `build_line` prefab=Medium Road、(520,10) から (520,55) 。接続先は node 617 と node 32134(segment 26707 を置き換える)
  2. `build_line` Medium Road、(520,55) から (520,100)。接続先は node 32134 と node 19541(segment 691)
  3. `build_line` Medium Road、(520,100) から (520,145)。接続先は node 19541 と node 23689(segment 30429)
  4. `build_line` Medium Road、(520,145) から (520,190)。接続先は node 23689 と node 15512(segment 27641)
  合計約124m。ゲームが「太くする」を道具で直接受けない場合は、同じ端点で引き直す。
- 設置条件の確認:
  - `net_near`(520,110 半径150): 4区間とも Basic Road で、1車線ずつ。両端の node は上のとおり。東西の Medium Road(y=100)がすでにつながる
  - `junction_info`(520,100): 信号あり、4方向とも車が通る。東西は Medium Road、南北だけが Basic Road で、ここが細い口になっている
  - `height_at`(520,100): 地面46.2、水面46.2(同じ値で、水の上ではないか未確定だが、既存の道路が通っている)
  - `zone_map`(520,100 半径150): x=520 の道は両側に建物が並ぶ。道路の幅は図で既に太く描かれ、拡張で建物にかかるかは未確認
- 接続工事: 不要(既存の node にそろえる)。費用は建設費に含む
- 予備候補: なし
- 中止する条件: 引き直しで両側の建物が壊れる、または接続が切れる(`net_reach` で来られない区間が出る)なら見送る。区間の端点が上の node と違うときも見送る

## 期待する効果

- 改善の見込み: x=520 の南北の道は1車線ずつの Basic Road で、東西の Medium Road(2車線ずつ)に挟まれた細い口になっている。ここを太くすると、止まった車の最多の場所(510,94)の詰まりが減ると予想する
- 数値と期限: `traffic`(510,94 半径200)の blocked は今24、density 100 の区間が6本中4本。予想は blocked 12以下。街全体の流れは今65%で、この1か所では動かないので、+1ポイント程度の見込み。確かめる期限は実行後の翌月の局案づくりのとき
- 確認方法: `traffic` を x=510, z=94, radius=200 で呼び、blocked と busiest の density を今の値と比べる。街全体の flow も見る
- 不確かな点: 先月の同じ型の案(x=80 の道)は採られず、効き目の実測がない。迂回で詰まりが隣の道に移る恐れがある。街全体の流れ70%の目標には、1か所だけでは足りない

これは局の予測です。ゲームの効果の正解を取得しません。

## 費用

- 建設費: 約930(Medium Road 7,500/km × 0.124km)
- 週の維持費の増え分: 約7(Medium 100 と Basic 40 の差 60/km × 0.124km)

## 戻せるか

戻せる。Basic Road に引き直せる。

## 前の月の答え合わせ

前の月の案(x=80 と (40,190) を Medium Road に太くする)は採られなかった。理由は、同じ月に交通の手を2つ打つと効き目が分からなくなるため、港を先にしたこと。今月は港の案とは別に、止まった車が最多の (510,94) へ場所を変えて出し直す。流れは64%から65%でほぼ動いていない。

## 判断の根拠

止まった車が最多の (510,94) は、東西の Medium Road と南北の Basic Road が交わる信号の口で、南北の4区間が density 100 だった。口を2車線にそろえるのは安く(約930)、維持費もほぼ増えない。街全体の流れ65%を70%にするには足りないが、確かめやすい小さな手として出す。重点の外の案で、建設費の枠は圧迫しない。

## 捨てたもの

- FreeTransport の有効化: 切符収入が0になる(今の収入1,463)。バスの利用が増える見込みは数字で確かめられない

- 港の出口 (-405,1515) の道を太くする: Harbor Road は建物の一部で太くできない(港湾空港局の担当)

- x=80 の南北の道の拡張: 先月の案。止まった車の最多が (510,94) に移ったため、今月は見送る
