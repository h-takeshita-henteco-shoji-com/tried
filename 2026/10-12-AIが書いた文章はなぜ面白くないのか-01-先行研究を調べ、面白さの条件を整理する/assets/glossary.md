# article.md の用語表

AIに文章を書かせると、同じものを途中で別の言葉に言い換えがちになる。読み手は、言葉が変わるたびに「別のものか」を考え直すことになる。
これを防ぐため、article.md を書く前に用語を決めた。

決まりは2つ。

- 初めて出すときだけ、言い換えを添える
- 2回目以降は「使う言葉」だけを使い、「使わない言葉」に言い換えない

## 用語

| 使う言葉 | 初出の言い換え | 使わない言葉 |
|---|---|---|
| 面白い | 知的な面白さ。笑える、感動する、美しい、は含めない | 興味深い、魅力的、おもしろい(ひらがな)、interesting |
| 読みやすい文章 | 迷わず分かり、最後まで読める文章 | 良い文章、読ませる文章、分かりやすい文章 |
| 面白い文章 | 読者の予想を、納得できる形で裏切る文章。前提として読みやすい文章であること | 良い文章、魅力的な文章 |
| 定義 | この連載で「読みやすい文章」「面白い文章」と呼ぶものの決まり | 意味、正体 |
| 論文 | (本も数冊含む) | 文献、研究、ペーパー |
| 要旨 | 論文の冒頭にある短いまとめ | アブストラクト、概要、サマリー |
| 全文 | 論文の中身すべて | 本文(記事の中身と紛れるため) |
| 本文 | 記事のタイトルの後に続く中身 | 中身、内容 |
| タイトル | (なし) | 見出し、題名 |
| 架空の論文 | 実在しない論文 | 捏造、ハルシネーション、嘘の論文 |
| 照合 | 論文のデータベースと突き合わせて、実在と書誌を確かめること | 確認、検証、チェック |
| 条件 | 面白い文章が満たしていそうな性質 | 要素、ポイント、要因 |
| 問い | 読者が答えを知りたくなる疑問 | 疑問、謎、フック |
| AI | Claude(Anthropic の AI) | モデル、Claude(初出以外) |
| 私 | やってみ太郎 | 筆者 |

## 判断に迷ったもの

- 「読みやすい文章」と「面白い文章」は、二段の定義である。「良い文章」は両方を含みうるので使わない
- 「面白い」は、記事の主題そのものである。ここが言い換わると、何を定義しているのかが揺れる。「興味深い」も使わない
- 「本文」と「全文」は、どちらも「中身」の意味で使いやすい。記事には「本文」、論文には「全文」と分けた
- 「タイトル」と「見出し」は、Aubin Le Quéré & Matias の論文では headline(見出し)である。読者の実感に近い「タイトル」に揃えた
