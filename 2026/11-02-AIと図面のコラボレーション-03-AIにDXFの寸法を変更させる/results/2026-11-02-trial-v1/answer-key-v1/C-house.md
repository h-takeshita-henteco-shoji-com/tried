# C（2LDK 平屋の平面図）の寸法変更の課題と正解

状態: 確定（2026-11-02）。Claude Opus 5.5 が Claude Code で下書きし、人が推奨案のまま採用した。
図面: `assets/drawings/house-2ldk`（DXF）。`code/drawings/make_house.py` で作った。
正解の図面: `answer-key/expected/C-1-1.dxf` など。同じスクリプトで、課題ごとの変更を当てて作った。
AIには渡さない。

## 決まり

- AIには DXF だけを渡し、変更後の図面を `drawing-changed.dxf` として保存させる。画像は渡さない。
- ライブラリは新しく入れさせない（#132、#138 と同じ）。作業フォルダの Python には ezdxf が入っていない。
- 採点は、変更後の図面を正解の図面と比べて行う（`code/drawings/check_change.py`）。
  - 図形: レイヤー（WALL、DOOR、WINDOW、FIXTURE、GRID）ごとに、余分な線と不足した線の長さを出す
  - 寸法: 書かれた値、測る2点の間の長さ、画面に描かれる文字の3つが合っているか。正解と同じ長さの寸法がそろっているか
- 最後に、変更前と変更後を LibreCAD で開き、人の目で見比べる。
- 判定は #132 と同じ6種類。正答、部分正答、誤答、適切な保留、誤った断定、不要な保留。

- 寸法: 通り芯の間隔（X方向5つ、Y方向3つ）と、全体の幅・奥行の2つ。計10

## C-1 単独の変更

### C-1-1 LDKの南の壁にある2つの窓のうち、東側（右）の窓の幅を1,650mmから1,820mmに広げてください。窓の左端は動かさないでください。

- 正解: 窓は x=3,300〜5,120 になる。壁の開口と窓の3本の線が変わる。ほかは動かない
- 言ってはいけないこと: 窓の中心を保って両側に広げる。左（西）の窓を変える

## C-2 関連要素の変更

### C-2-1 寝室1の幅（通り芯X5〜X6）を3,640mmから4,550mmに広げてください。東の外壁ごと東へ動かし、LDKと北側の水まわりは動かさないでください。

- 正解: 東の外壁と X6 の通り芯が 910 東へ動く。南と北の外壁、Y方向の間仕切り（Y2）が伸びる。寝室2 の幅も 4,550 になる。東の壁の窓2つが一緒に動く。寸法は X5〜X6 が 4,550、全体の幅が 10,920 になる
- 許すこと: 寝室1の南の窓、寝室2の北の窓、クローゼットを動かすかどうか（指示がないため、どちらでもよい）
- 言ってはいけないこと: 寸法の値だけ直して、図形を動かさない（またはその逆）

## C-3 複数条件の維持

### C-3-1 廊下の幅（通り芯Y2〜Y3）を910mmから1,365mmに広げてください。LDKと寝室1の大きさと位置は変えないでください。扉は、今の部屋とのつながりを保ってください。

- 正解: Y3 と Y4 の通り芯、北側の部屋（玄関、トイレ、洗面脱衣、浴室）、その扉・窓・設備、北の外壁が 455 北へ動く。寝室2 は南北に 455 広がる。寸法は Y2〜Y3 が 1,365、全体の奥行が 6,825 になる
- 許すこと: 寝室2 の東の窓を動かすかどうか。玄関と廊下の間の開口の位置
- 言ってはいけないこと: LDK や寝室1 を動かす。扉が壁のない所や別の部屋に出る

## C-4 条件の衝突

### C-4-1 建物の幅（10,010mm）を変えずに、寝室1の幅を4,550mmに広げてください。LDKは約14畳のまま保ってください。

- 正解: 両立しない。寝室1を 4,550 にすると、LDK の幅は 5,460 になり、約12畳になる。図面を変える前に、どちらを優先するか確認を求める
- 適切な保留: 図面を保存せず、両立しない理由と確認したいことを答えたもの
- 誤った断定: どちらかを勝手に優先して、図面を保存したもの
