# C（2LDK 平屋の図面一式）の寸法変更の課題と正解

状態: 確定（2026-11-02）。Claude Opus 5.5 が Claude Code で下書きし、人が推奨案のまま採用した。
図面: `assets/drawings/house-2ldk`（DXF）。`code/drawings/make_house.py` で作った v2。平面図、立面図（南・北・東・西）、断面図（A-A、B-B）を1つの DXF に描いた。
正解の図面: `answer-key/expected/C-1-1.dxf` など。同じスクリプトで、課題ごとの変更を当てて作った。
AIには渡さない。試しの v1 の課題と結果は `results/2026-11-02-trial-v1/`。

## 決まり

- AIには DXF だけを渡し、変更後の図面を `drawing-changed.dxf` として保存させる。画像は渡さない。
- 平面図を変えたら、立面図と断面図もそろえて直すことを求める。
- ライブラリは新しく入れさせない（#132、#138 と同じ）。作業フォルダの Python には ezdxf が入っていない。
- 採点は、変更後の図面を正解の図面と比べて行う（`code/drawings/check_change.py`）。
  - 図形: レイヤーごとに、余分な線と不足した線の長さを出す。平面図（WALL、DOOR、WINDOW、FIXTURE、GRID）、立面図（ELEV、ELEV_WINDOW、ELEV_DETAIL）、断面図（SECT、SECT_VIEW）
  - 寸法: 書かれた値、測る2点の間の長さ、画面に描かれる文字の3つが合っているか。正解と同じ長さの寸法がそろっているか
- 最後に、変更前と変更後を LibreCAD で開き、人の目で見比べる。
- 判定は #132 と同じ6種類。正答、部分正答、誤答、適切な保留、誤った断定、不要な保留。
- 試し（v1）で、指示文が足りずに確認を求める答えが多かった。本番の指示文には、決めきれない点を書き足した。

## C-1 単独の変更

## C-2 関連要素の変更

### C-2-1 寝室1の幅（通り芯X6〜X8）を3,640mmから4,550mmに広げてください。東の外壁は、寝室1と寝室2にまたがる部分をまっすぐのまま東へ動かし、寝室2も広がってかまいません。東の壁に付いた窓と設備は壁と一緒に動かし、ほかの窓と設備は位置を変えないでください。

- 正解: 東の外壁と X8 の通り芯が 910 東へ動く。南と北の外壁、寝室1と寝室2の間の壁が伸びる。東の壁の窓2つと寝室2のクローゼットが動き、寝室1のクローゼットとその折れ戸の開口は東の壁まで伸びる（開口 x=7,400〜10,810）。寸法は X7〜X8 が 3,640、全体の幅が 10,920 になる

- 正解の見直し（2026-11-03）: 最初の正解では、クローゼットの折れ戸の開口を元の幅（〜9,900）のままにしていた。本番で図面を保存した4つのモデルがそろって開口を東の壁まで広げ、クローゼットが伸びる以上その方が自然なため、正解を直した
- 言ってはいけないこと: 寸法の値だけ直して、図形を動かさない（またはその逆）

## C-3 複数条件の維持

### C-3-1 LDKを南北に455mm広げてください。通り芯Y5より北にあるもの（北側の外壁、浴室・洗面脱衣・ファミリークローゼット・パントリー、寝室2の北側）を、455mm北へ動かします。寝室1の大きさと位置は変えないでください。浴室・洗面脱衣・ファミリークローゼット・パントリーの大きさは変えないでください。寝室2・トイレ・ホールは広がってかまいません。キッチンの背面と冷蔵庫は、北の壁に付けたまま動かしてください。扉と窓は、今の部屋とのつながりを保ってください。

- 正解: Y5 と Y6 の通り芯、Y5 より北の壁・扉・窓・設備が 455 北へ動く。キッチンの背面と冷蔵庫も動く。LDK、トイレ、ホール、寝室2 が南北に 455 広がる。寸法は Y4〜Y5 が 1,365、全体の奥行が 7,735 になる
- 立面図: 東・西の面の幅が 7,735 になり、棟の高さが 91 上がる（4,856 → 4,947）。北の面は位置だけ変わる。断面図: A-A の奥行と棟の高さが変わる。B-B の奥に見える屋根の高さが変わる
