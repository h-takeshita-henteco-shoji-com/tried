# 指示文

AIに合成させる方式の指示文。Python で重ねる方式と、カット1と4で比べる。
窓口は Gemini。キャラと背景は `input/` の画像を添付する。

## P1. カット1(夕方の引き、どんだけ)

添付: `input/bg-c1-evening.jpeg`、`input/don-bath-front.png`

```
1枚目は背景、2枚目はキャラクター(どん)です。
1枚目の背景の構図、線、色は変えずに、どんを1匹だけ描き足してください。

縦長(9:16)。
- どんは画面の右下の水面に、首から上だけを出す。体は湯の中で見えない。
- どんは正面を向く。目は半円で、まぶたが半分おりている。頭に白いタオル。
- 顔の大きさは、画面の幅の約3分の1。
- 左の平たい石の上は、何も載せず空けておく。
- どんの顔、タオル、線の太さは2枚目と同じにする。

描かないもの: ほかのキャラクター、人、文字。
```

## P4. カット4(中くらいの引き、2匹が並ぶ)

添付: `input/bg-c1-evening.jpeg`、`input/don-bath-left.png`、`input/nume-4views.png`

```
1枚目は背景、2枚目はどん、3枚目はぬめの4面(正面、斜め、真横、背面)です。
1枚目と同じ場所を、少し寄った中くらいの引きで描いてください。
線、色、画風は1枚目に合わせます。

縦長(9:16)。
- 画面の左: 平たい石の上面。ぬめが1匹、石の上に乗る。
- 画面の右下: 湯の水面。どんが首から上だけを出す。体は見えない。
- 大きさ: どんの頭の高さは、ぬめの体の横幅の1.5倍。ぬめは、どんの顔より一回り小さい程度。
- ぬめは真横の姿で、画面の左を向く。どんに背を向ける。
- ぬめの2本の触角は、前(画面の左)へ倒す。根元から斜め前に伸び、上には立てない。
- ぬめの背中に丸い水色の水筒。紐は細い薄茶の1本で、体に斜めにかかる。
- どんは少し左(ぬめの方)を向く。目は半円。頭に白いタオル。

描かないもの: ほかのキャラクター、人、文字。
```
