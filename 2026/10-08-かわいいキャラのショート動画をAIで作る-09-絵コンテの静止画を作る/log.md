## 試したこと

絵コンテ(#12)の10カットを、静止画1枚ずつに清書する。
背景(#18)にぬめとどんを重ね、大きさは「どんの頭の高さ = ぬめの体の幅の約3倍」にする。
重ね方は、画像生成AIに合成させる方法と、Python で切り抜いて置く方法を比べる。
成果物はカット数分の静止画と、2方式の比較メモ。

## 結果

### 準備

- 時間の上限は60分。今日はカット1〜5。比較はカット1と4で行う。
- 素材は `assets/input/` に写した。背景3枚(#18)、ぬめの4面とどんの湯の姿2枚(#17)、ラフ(#12)。

### Python で重ねる(カット1、4)

- 切り抜き: 背景のクリーム色を外周から塗りつぶして消した(`assets/work/cutout.py`)。黒い輪郭線で止まるので、6枚ともきれいに抜けた。
- 触角を前に倒す: 根元から離れるほど大きく回して曲げた(`assets/work/antenna.py`)。付け根の線はつながったまま。30°、40°、50°を比べ、40°にした。
  - 1回目は向きが逆で、後ろへ倒れた。2回目は胴の上の線まで一緒に曲がった。触角だけを別の層にして直した。
- 重ねる: `assets/work/compose.py`。どんの頭の高さ330px、ぬめの体の幅110pxで、比率は3倍ちょうど。
  - 結果: `assets/generated/py-cut01.png`、`py-cut04.png`。
  - ぬめを0.14倍に縮めると、輪郭線が約1.7pxになった。どんの線(約5px)より細く、貼り絵に見えた。縮める前に線を太らせて揃えた。
  - ぬめが石の角にまたがって浮いた。石の上面へずらし、足元に薄い影を付けた。
  - 比率どおりだと、ぬめはかなり小さい。カット4の引きでは、触角の倒れ具合がやっと見える大きさ。

### 比率を3倍から1.5倍に変える

- ぬめをもう少し大きくしたくなった。3倍、2.5倍、2倍、1.5倍でカット4を並べた(`assets/work/ratio-compare.png`)。
- いったん2倍にした。触角の合図が読める、一番小さい大きさだったため。
- 2倍でもまだ小さく感じた。2倍、1.75倍、1.5倍を並べ直した(`assets/work/ratio-compare2.png`)。
- 1.5倍にした。2匹が同じ重さで並んで見える。どんが「大きな相手」に見える感じは薄れる。
- 以降のカットも1.5倍で揃える。#12 の絵コンテとこのIssueの「約3倍」は、1.5倍に読み替える。
- 線の太さは、縮める倍率から自動で決めるようにした。仕上がりの線を約3pxに揃える。
- ぬめが大きくなった分、背景の切り出しを左へずらし、石の上面に収めた。
- 結果: `assets/generated/py-cut04.png` を1.5倍で作り直した。

## 学び

- LLM より Python による合成の方が上手くいった。
  - LLM は、キャラが1匹なら指示どおりに描けた。2匹になると、比率・向き・触角が3つとも外れた。
  - Python は、決めた数字をそのまま守る。最初の1枚は重いが、2枚目からは数字を変えるだけで済んだ。
- 比率は、文章で決めるより絵を並べて決める方が早い。「3倍」は、画面で見ると小さすぎた。最後は1.5倍になった。
- 縮めたキャラは線が細くなり、貼り絵に見える。縮める前に線を太らせると、ほかの絵と揃う。
- 体を大きく傾けると、跳んで見えるか、縦長でウサギに見えた。動きは静止画で描かず、動画に回す。
