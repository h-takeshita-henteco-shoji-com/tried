# 説明文

#20 の説明文と、調べた型で書き直した説明文を、同じAIで比べる。
差が出れば書き方の問題、出なければAIの限界と見る。
AIは Qwen3-TTS の VoiceDesign モデルを使う(手元の Mac で実行)。

## どん

### A: #20 の説明文(基準)

#20 の `prompts.md` の「キャラの声 / どん」をそのまま使う。

```
「どん」の声。冬を何度も越えた年寄りのカピバラで、いつもぬるい湯だまりに浸かっている。
性別は決めない。男とも女とも決めにくい声にする。
声は低く柔らかく、少しかすれていて、温かい。
話す速さはとても遅い。答える前に小さな間を置く。温かい湯に浸かりながら考えている感じ。
ほとんど独り言のように、小さな声で話す。誰かに向けて声を張らない。
落ち着いていて、何があっても動じない。
語尾と間にだけ、田舎の柔らかさを出す。特定の地域の方言やなまりは真似しない。単語のアクセントは標準語のままにする。
明るくしない。芝居がかった読み方や、アニメのような演技はしない。
```

### B: 型に沿った英語版

属性を短く並べる。物語と禁止を消し、性別は高さと声色で言い換える。

```
Native Japanese speaker. Elderly, androgynous voice, mid-low pitch. Timbre: soft, warm, slightly husky. Pace: very slow and relaxed. Volume: quiet, murmuring to oneself. Emotion: calm, sleepy, content.
```

### C: Bの日本語版

```
日本語話者。年配で、中性的な声。やや低め。声色は柔らかく温かく、少しかすれている。とてもゆっくり、くつろいで話す。小声で、独り言のようにつぶやく。穏やかで、眠たげで、満ち足りている。
```

### D: Bを柔らかくした版

B1が「良いが少し怖い」ため。声色と感情だけを替えた。
かすれを「丸く、息が少し混じる」に、眠たげを「優しく微笑む」にした。

```
Native Japanese speaker. Elderly, androgynous voice, mid-low pitch. Timbre: soft, warm, round and gently breathy. Pace: very slow and relaxed. Volume: quiet, murmuring to oneself. Emotion: kind, gentle, content, with a faint smile.
```

### E: Cを柔らかくした版

Cが「特徴的だが、もう少し柔らかく」のため。替えた所はDと同じ。

```
日本語話者。年配で、中性的な声。やや低め。声色は柔らかく温かく、丸みがあり、かすかに息が混じる。とてもゆっくり、くつろいで話す。小声で、独り言のようにつぶやく。優しく、穏やかで、かすかに微笑んでいる。
```

## 読ませる台詞

`voice-baseline.md`(#20)の、どんの1・3・5。句読点は全角にする。
間は説明文ではなく、台詞の「……」と読点で作る。

```
……んー。熱いっていうより、ぬるい寄りの熱い、だな。おれは、ここでいい。……行ったか。
```

## ぬめ

どんと同じく、A(#20 のまま)、B(型に沿った英語)、C(Bの日本語版)を比べる。
どんと並べたときに差が出るよう、高さ・軽さ・速さをどんと逆向きにした。

### A: #20 の説明文(基準)

```
「ぬめ」の声。今年の梅雨に生まれた小さなナメクジで、まだ冬を知らない。
性別は決めない。小さな子どものような、男とも女とも決めにくい声にする。
声は小さく軽く、少し高い。少し息が混じる。
短い文を、さっと素直に話す。
よく質問をする。声にかすかな心配がにじむが、甘えた声にはしない。
自然な標準語で話す。かわいこぶらない。キンキンした声や、アニメのような演技はしない。
```

### B: 型に沿った英語版

```
Native Japanese speaker. Young child, androgynous voice, slightly high pitch. Timbre: small, light, a little breathy. Pace: natural, short and plain sentences. Volume: soft. Emotion: curious, innocent, faintly worried.
```

### C: Bの日本語版

```
日本語話者。小さな子どもで、中性的な声。やや高め。声色は小さく軽く、少し息が混じる。ふつうの速さで、短く素直に話す。声は控えめ。好奇心があり、無邪気で、かすかに心配そう。
```

### 読ませる台詞

`voice-baseline.md`(#20)の、ぬめの1〜5をつなげた。

```
どん、あれ何。どん、まだ熱い？ぬめ、もう行く。そっか。……んしょ。
```
