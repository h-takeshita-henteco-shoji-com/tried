# m06 港湾空港局の案

## 施策

- 施策: 乗客の少ない大型バス4路線の予算を20ポイント下げる(試し)。`set_transport_line_budget` を、line 136(Bus Line 28)、line 126(Bus Line 41)、line 127(Bus Line 37)、line 199(Bus Line 34)に、200 → 180 で使う
- 議決: 予算

## 実行計画

- 実行可否: 確認済み
- 対象と操作順: `set_transport_line_budget` を次の順に1回ずつ。
  1. line 136(Bus Line 28)200 → 180(vehicles 190)
  2. line 127(Bus Line 37)200 → 180(vehicles 57)
  3. line 199(Bus Line 34)200 → 180(vehicles 51)
  4. line 126(Bus Line 41)200 → 180(vehicles 50)
- 設置条件の確認: 建設なし。`list_transport_lines`(type=bus)で、4路線とも budget 200、complete=true、pathFailed 0 を確かめた。乗客(passengersLastPeriod / passengers)は 136 が 30 / 54、127 が 18 / 20、199 が 11 / 44、126 が 32 / 35。車の数に比べ、乗客は極めて少ない
- 接続工事: 不要
- 予備候補: なし。4路線のどれかの budget が 200 でなければ、その路線は見送る
- 中止する条件: 実行前の `list_transport_lines` で budget が 200 でない路線は見送る。`traffic` の流れが 60% 以上なら全体を見送る(今は 54%)

## 期待する効果

- 改善の見込み: 6-3 の流れ(54%、目標60%以上)に対し、ほとんど乗客のいない大型路線の走行バスを減らし、道の上の車を減らす。局の予測で、効きは小さい見込み
- 数値と期限: 対象4路線の vehicles の合計 348 → 約313(各路線の約10%減、局の見積もり)。`traffic` の流れ 54% の変化は数値を見積もれない(減る約35台は走る車 7,681 の約0.5%)。期限は次の月例
- 確認方法: `list_transport_lines`(type=bus)で、line 136・127・199・126 の vehicles と targetVehicles の合計を見る。参考に `traffic` の流れ・cars・blocked(全街)を、今と同じ条件で見る
- 不確かな点: 流れの変化を、この施策だけに帰せない。m03-2 では41台減って流れが 54 → 56% になったが、切り分けていない。同じ月に走る他の局の試し(ごみ・荷物・道路)と混ざるおそれがある。バスの乗客が車に移ると効きは弱まる
- 試し: 仮説は、乗客のほとんどいない大型路線の予算を下げると、走るバスが減り、道の上の車が減って流れが上がる。測る数は `list_transport_lines` の対象4路線の vehicles の合計(基準348)。参考に `traffic` の流れ(基準54%)。場所は対象の4路線。編成方針の「分からないこと」には当たらず、6-3 の新しい試し

これは局の予測です。ゲームの効果の正解を取得しません。
