- 市の計画: 4-4 資源循環
- 操作:
  1. 実行前に `buildings_near(x=-2541, z=-2104, radius=400, problem="Garbage")` の total と、`complaints` のごみの印を基準として記録する
  2. `test_place_building(prefab="Landfill Site", x=-2660, z=-2165, facing="east")` を打ち、ok=true、wouldDemolish 0、入口の road があることを確かめる
  3. `place_building(prefab="Landfill Site", x=-2660, z=-2165, facing="east")`(pay は既定の True)

### m08-2 止めたままの貨物駅 28755 を取り壊す(試し)

- 元にした局の案: economy。手直しした点: 測る数を、街全体の noGoods・noResources から、28755 に関わる止まった車の数に絞った。noGoods・noResources は補いとして見る
- 議決: 取り壊し
- 採択理由: 28755 は止めても、荷を積んだトラック230台が敷地で WaitingSpace のまま40〜210日動かない(`vehicles_stuck` で7日以上止まった294台)。取り壊しで車ごと消えれば、荷の予約が外れて行き先の店・工場が頼み直すという仮説を、ほかの手では確かめられない。
- 今月選んだ理由: 重点3(6-4・7-1)の唯一の案で、分からないことの一覧の筆頭2項目(28755 の空き待ち、原料がない工場の原因)の試し。止めたままの駅は働き口0・家0で、壊しても今の運用で失うものがない。
- 公約: 3(間接。店と工場の放棄が減れば税収が保てる)
- 市の計画: 6-4、7-1 企業の立地、地場企業(8-1 の数も下がる見込み)
- 操作:
  1. 実行前に `cargo` で基準を記録する(stoppedTrucks、Goods の stoppedTrucks、stoppedInBuildings、noGoods、noResources)。`vehicles_stuck(kind="truck", building=28755)` の vehicles も記録する
  2. `preview_bulldoze(x=3449, z=-1555, radius=30, what="building")` を再度呼び、targets が 28755 の1棟だけで、道路区間0であることを確かめる
  3. `bulldoze(x=3449, z=-1555, radius=30, what="building")`。道路は壊さない
  4. 見回り1・見回り2・月末に `cargo` と `vehicles_stuck(kind="truck", building=28755)` を見る
- 実行計画: 局の `preview_bulldoze` は targets 1棟(28755)、道路区間0、送電線0、失う働き口0・家0、電気が切れる建物0、modelAgreement 1.0。隣の貨物駅 13893 は (3529,-1555) で円の外(80m)。市長も同じ引数で `preview_bulldoze` を呼び、同じ結果(targets は 28755 の1棟、jobs 0、homes 0、停電0、水の施設なし、transportStations は 28755 だけ)を得た。予備候補なし。中止する条件は、preview の targets が 28755 以外の建物か道路区間を含むとき、または 28755 が TurnedOff でなくなっているとき
- 費用: 建設費 0、週の維持費の増え分 0(止めたままで維持費は既に0)
- 予想: 局の予測。30日目までに、駅・港の中で止まったトラック 237 → 10前後、`vehicles_stuck(kind="truck", building=28755)` の vehicles 327 → 0に近い、Goods の stoppedTrucks 490 → 300以下。品物がない店120・原料がない工場35は、下がる向きまでは言えるが量は見積もれない。期限は月末(9か月目の月例)。不確かな点は、建物を壊すと車も消える動きを確かめていないこと。車が消えても、荷が別の入口から届くかは輸入の経路しだい
- 試し: 試し。仮説は「動かない車が荷を抱えて店・工場の注文を塞いでいる。取り壊しで車が消えれば、注文が頼み直されて届く」。測る数は `vehicles_stuck(kind="truck", building=28755)` の vehicles(基準327)と、`cargo` の Goods の stoppedTrucks(基準490)と stoppedInBuildings(基準237)。補いに `cargo` の noGoods(基準120)と noResources(基準35、中心 (2911,-961) 20棟)。場所は貨物駅 28755 (3449,-1555) と、その車の行き先。分からないことの一覧の「28755 の空き待ちが解けない理由」と「原料がない工場の原因」の試し
- ほかの局への響き: 港湾空港局の 8-1 の数(駅・港の中で止まったトラック)は下がる見込みで、良い向き。鉄道の荷の受け口が1つ減るので、28755 を動かし直す手はなくなる。28755 につながる線路はそのまま残り、線路の維持費(週1,939 の一部)は減らない。輸入の多くは道路のつなぎ口(258/214/36 台)から来るため、品物の届き方への響きは小さいと見るが、確かめていない
- 戻せるか: 戻せない
- 取り壊しのとき:
  - 壊した後に失うもの(`preview_bulldoze`): 建物1棟(28755 Cargo Center)。働き口0、家0、電気が切れる建物0、道路区間0、送電線0、水の施設0。失う駅は 28755 だけで、隣の 13893 ほか貨物駅は残る(`transport_reach` で 13893・3940・4740・40031 は外とつながる)。止めたままなので、今の荷の流れから失うものはない。失うのは、駅を動かし直す選択肢と、置き直すときの建設費
  - 壊さない代わりの手との比べ: (1) 止めたまま続ける: m07-1 で中の車は 483→230 に減ったが、残る車は40〜210日止まり、noResources 38→35、noGoods 116→120 とほぼ動かなかった。続けても仮説を確かめられない。(2) 動かし直す: 前と同じ詰まり(中の車483)に戻るおそれがあり、局も中止した。(3) 取り壊し: 費用0、失う働き口・家0で、止まった車を消す唯一の手。仮説を1か月で確かめられるため、取り壊しを選ぶ

### m08-3 バスの予算を150%から130%に下げる(試し)

- 元にした局の案: port。手直しした点: なし
- 議決: 予算
- 採択理由: バスの週の支出は22,089、収入は5,121で、差し引き約17,000の持ち出し。週の収支は +10,203 → +6,369 と細り、予算を20ポイント下げると約2,900の支出減が見込める。乗客の多くの路線は1桁〜数十人(Line 28 は190台で乗客4)で、台数を減らした影響は小さいと見た。
- 今月選んだ理由: 公約3(赤字を続けない)の黒字が2か月で約4割細り、今月の5案のうち週の収支を守る側に働く唯一の案。今月の2つの試し(南西のごみ、東の貨物駅)と測る数が重ならない。
- 公約: 3
- 市の計画: 6-3 公共交通を主軸とした交通体系(財政の守る線「週の収支を黒字に保つ」にも当たる)
- 操作:
  1. 実行前に `economy` で bus が昼150・夜150 であることを確かめる。`economy_breakdown` の PublicTransportBus(支出22,089、収入5,121)、`list_transport_lines(type="bus")` の vehicles の合計、`traffic` の cars・flow・blocked を基準として記録する
  2. `set_budget(target="bus", percent=130)`
  3. 直後に `economy` で bus の day と night が130か確かめる
- 実行計画: 建物も線も作らない。今の bus は昼150・夜150(`economy`。市長も `economy_breakdown` で PublicTransportBus 支出22,089・収入5,121 を確かめた)。下げ幅20は上限内。`set_budget` の percent は50〜150(`tool-reference.md`)。予備候補なし。中止する条件は、実行前の `economy` で bus が150でないとき、または実行前の週の収支が赤字のとき(今は +6,369)
- 費用: 建設費 0、週の維持費の増え分 約 −2,900(減る側の見積もり)
- 予想: 局の予測。PublicTransportBus の支出 22,089 → 約19,100(9か月目の月例)。`list_transport_lines(type="bus")` の vehicles の合計が減る。`traffic` の cars 7,829 はバスの減る台数分だけ下がる見込み。確認は `economy_breakdown` の PublicTransportBus の支出と収入、`list_transport_lines(type="bus")` の vehicles の合計、`traffic` の cars。不確かな点は、支出と台数が予算にどれだけ比例するかをこの街で測っていないこと。乗客が減って運賃収入5,121が下がるおそれもある。乗客の多い Line 35(406人)と Line 55(197人)は混むかもしれない
- 試し: 試し。仮説は「バスの予算を下げると台数と維持費が減り、週の収支が持ち直す」。測る数は `economy_breakdown` の PublicTransportBus の支出(基準22,089)と収入(基準5,121)、`list_transport_lines(type="bus")` の vehicles の合計(基準は実行前に記録)。場所は街全体のバス路線。分からないことの一覧の項目には当たらない(一覧の試しは m08-1 と m08-2)
- ほかの局への響き: バスで動いていた人が車に移ると、道路の詰まりが増えるおそれ(6-3、街全体の flow 53%)。乗客の多い路線の待ちが延び、幸福度が下がるおそれ(今85。来月の `city_info` で見る)。運賃収入が減ると節約分が目減りする。予算の変更は街全体なので、`traffic` の cars は m08-2 の荷の車の変化とも混ざる。そのため効き目はバスの支出と台数で測る
- 戻せるか: 戻せる(`set_budget(target="bus", percent=150)`。予算の議決が要る)
