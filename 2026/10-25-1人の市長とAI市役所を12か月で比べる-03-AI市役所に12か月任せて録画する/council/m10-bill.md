### m10-1 焼却場10351 を止めて、東の住宅の汚染の出どころを確かめる(試し)

- 元にした局の案: health。手直しした点: ほかの局への響きに、電気の容量の減り(15MW)と働き手30人を足した
- 議決: 要らない
- 採択理由: 汚染の印37の中心は東の高密度住宅 (2053,666) 13棟で、地面の汚染255の点が焼却場10351 (2070,866) の位置に当たる。止めれば新しい汚染が出なくなり、円の住宅の印が減ると判断した。
- 今月選んだ理由: 4-3 は重点で、目標15から最も遠い施策の1つ。分からないことの一覧の「汚染の出どころ」に当たる唯一の試しで、建設費0・戻せる。
- 公約: 直接はない。市の計画の 4-3 のため(住宅の汚染なので 1-2 の健康77にもつながる見込み)
- 市の計画: 4-3 脱炭素社会
- 操作:
  1. 実行前に `complaints` のごみの印を見る(今20)。35を超えていたら見送る
  2. 基準を測る。`buildings_near(x=2053, z=666, radius=250, problem="Pollution", brief=true)` の total(局の確認で12)と、`map_layer(type="pollution", x=2053, z=666, radius=400, n=9)` の grid・max・average
  3. `set_building_active(id=10351, active=False)` を1回呼ぶ
  4. 見回り1・見回り2・月末に、2と同じ引数で測る。月末に `services` のごみと `complaints` のごみの印を見る
- 実行計画: 局が `buildings_near(x=2070, z=866, radius=15, service="Garbage")` で 10351 が Combustion Plant・稼働中・貯蔵87%・車32/34 と確かめた。市長も同じ引数で呼び、同じ値と Power Output 15MW・働き手30を確かめた。`preview_bulldoze` で対象は10351の1棟、電気が切れる建物0。予備候補はなし。中止する条件は、10351 が見つからない、止まっている、id が別の建物、ごみの印が35を超える、のどれか。月末にごみの印が基準20より増えたら `set_building_active(id=10351, active=True)` で戻す
- 費用: 建設費 0、週の維持費の増え分 0(止めると維持費と働き手が0になり、減る側)
- 予想: 円 (2053,666) 半径250 の汚染の印 12 → 月末8以下(局の予測)。街全体の印37は向きだけ見る。地面の汚染は、m05-1 の2267では1か月目にほぼ動かず、2か月目に下がった。そのため印が半分しか減らない恐れがある。確認は上の2つの道具・同じ範囲で、実行直後・見回り1・見回り2・月末
- 試し: 仮説は「焼却場10351を止めると、その周りの地面の汚染が下がり、住宅の汚染の印が減る」。測る数は `buildings_near(x=2053, z=666, radius=250, problem="Pollution")` の total と、`map_layer(pollution, x=2053, z=666, radius=400, n=9)` の値。場所は (2053,666) の円。基準は12棟、地面の最大255(実行直前に測り直す)。一覧の「汚染の出どころ」の項目
- ほかの局への響き:
  - 4-4 ごみ: 10351 の車32台が止まり、近くのごみの集まりが遅れる。m05-1 では印が 9→15 に増えた。今のごみの容量の使用は72%で、受け入れ先はある
  - 電気(3-3): 発電の15MWを失う。電気は 1,681,664 / 2,325,568 で余りがあり、来ない市民は出ない見込み。m05-1 では容量が約79,000減った
  - 働き口(6-4、7-1): 働き手30人が職を失う。働き口87,100に比べて小さい
  - 6-3 交通: ごみの車が別の埋立地へ回り、東の道路の車が少し増える恐れ
- 戻せるか: 戻せる(`set_building_active(id=10351, active=True)`)

### m10-2 東に公園1棟と岩の飾り7棟を置き、公園などを100以上にする(試し)

- 元にした局の案: urban。手直しした点: なし
- 議決: 要らない
- 採択理由: 公園などは93で目標100まで7。取り壊しゼロで置ける公園は (2688,45) の1棟だけで、残りは道路も電気も要らない岩(service が Beautification)で埋める。8棟とも `test_place_building` で ok・wouldDemolish 0 を確かめてある。
- 今月選んだ理由: 4-2 は重点で、残り2か月。今月置かなければ目標に届かない。建設費3,200は上限230,000の1.4%で、戻せる。
- 公約: 直接はない。市の計画の 4-2 のため
- 市の計画: 4-2 花や緑による潤い
- 操作: 上から順に、1棟ごとに同じ引数の `test_place_building` が ok=true・wouldDemolish 0 であることを確かめてから `place_building` を呼ぶ
  1. `place_building(prefab="JapaneseGarden", x=2688, z=45, angle=0, pay=True)`(入口は北 (2688,61)、道路は区間26352)
  2. `place_building(prefab="Boulder 01", x=2640, z=40, angle=0, pay=True)`
  3. `place_building(prefab="Boulder 03", x=2620, z=40, angle=0, pay=True)`
  4. `place_building(prefab="Boulder 01", x=2620, z=75, angle=0, pay=True)`
  5. `place_building(prefab="Boulder 02", x=2640, z=80, angle=0, pay=True)`
  6. `place_building(prefab="Boulder 04", x=2660, z=80, angle=0, pay=True)`
  7. `place_building(prefab="Boulder 03", x=2640, z=100, angle=0, pay=True)`
  8. `place_building(prefab="Boulder 02", x=2660, z=100, angle=0, pay=True)`
  - 置く前に `buildings_near(x=0, z=0, radius=9000, service="Beautification", brief=true)` の total を基準として測る(局の確認で93)
- 実行計画: 局が8棟それぞれを `test_place_building` で ok=true・wouldDemolish 0 と確かめた。JapaneseGarden は費用2,500、入口の道路は Basic Road 区間26352(12.7m)。岩は費用100、道路・電気・水・下水は不要。近くの既存園42573 は電気・水・下水とも届き、給水塔16957 が近い。岩どうしは20m以上離れるが、8棟を同時に置いた状態は試せていない。そのため2棟目以降の断りは実行時に出うる。予備候補はなし。中止する条件は、1棟ごとに実行前の試しが ok=false、wouldDemolish が1以上、または所持金が 2,082,287 を下回ること。その棟だけ見送る
- 費用: 建設費 3,200、週の維持費の増え分 40
- 予想: 公園などは93 → 公園だけなら94、岩も数に入れば101(局の予測)。確認は `buildings_near(x=0, z=0, radius=9000, service="Beautification", brief=true)` の total と、岩の id が一覧に出るか。期限は月末(10か月目の30日目)。不確かな点は、岩が total に入るか。地価(4-1)への効きは見積もれない
- 試し: 仮説は「岩(Boulder)は service が Beautification の建物なので、公園などの数に入る」。測る数は上の `buildings_near` の total と、置いた岩の id が一覧に出るか(街全体の数だが、数の定義を確かめる試しのため、置いた id の有無で見る)。場所は (2600〜2688, 40〜100)。基準は93。一覧の項目には当たらない(数の定義の試し)
- ほかの局への響き:
  - 4-2 の中身: 岩は花や緑ではない。数の目標に届いても、潤いの中身は公園1棟分に近い。議会と次の市長にこの差を示す
  - 4-1 地価: 公園1棟で円の地価が少し上がる見込み。岩の効きは分からない
  - 財政: 維持費 +40。黒字 +8,676 を削るのは0.5%
  - m10-1 の円 (2053,666) 半径250 とは約700m離れ、重ならない
- 戻せるか: 戻せる(後で取り壊せる。建設費は戻らない)

### m10-3 バスの予算を130%から110%に下げる(試し)

- 元にした局の案: port。手直しした点: 測る数を街全体の流れから、バスの支出と台数に絞った。流れは補いとして見る
- 議決: 予算
- 採択理由: バスは支出19,213に対し収入4,597で、乗客1桁の路線が多い(Line 28 は165台で乗客28)。前回の150→130 では支出 22,089→19,226、台数 1,920→1,674 と当たり、流れも 53→55% と悪くならなかった。
- 今月選んだ理由: 週の黒字 +8,676 は収入の2.5%と薄く、公約3に効く唯一の案。前月は信号の試しと数が混ざるとして見送ったが、今月は roads の信号を採らないので混ざりが減る。
- 公約: 3(赤字を続けない)
- 市の計画: 6-3 公共交通を主軸とした交通体系(財政の守る線にも当たる)
- 操作:
  1. 実行直前に `economy` で bus が昼130・夜130であることを確かめる。違えば見送る
  2. 基準を記録する。`economy_breakdown` の PublicTransportBus の支出と収入、`list_transport_lines(type="bus")` の vehicles の合計、`traffic()` の flow・cars・blocked
  3. `set_budget(target="bus", percent=110)` を1回呼ぶ
  4. 直後に `economy` で bus が110/110になったか確かめる
  5. 月末に2と同じ道具で測る
- 実行計画: 局が `economy` で bus の day 130・night 130 を確かめ、`set_budget` の引数(percent は50〜150)を `tool-reference.md` で確かめた。変更幅は −20 で枠 ±20 の内。予備候補はなし。中止する条件は、実行前の bus が130でないこと。週の収支が赤字になっていても、減る側の案なので見送らない
- 費用: 建設費 0、週の維持費の増え分 約 −2,900(支出が予算に比例するとした局の見積もり)
- 予想: PublicTransportBus の支出 19,213 → 約16,300、バスの台数が減る(局の予測)。補いの flow は55% → 55〜57%。期限は月末。不確かな点は、節約額が比例するかと、乗客の多い路線(Line 35 は乗客506)の待ちが延びるか
- 試し: 仮説は「バスの予算を下げると台数と維持費が減り、走るバスが減って道路の詰まりが減る」。測る数は `economy_breakdown` の PublicTransportBus の支出と、`list_transport_lines(type="bus")` の vehicles の合計(仕組みに近い数)。flow は補い。場所は街全体のバス。基準は実行直前に測る(局の確認で支出19,213)。一覧の項目には当たらない
- ほかの局への響き:
  - 幸福度・人口(公約1): バスを待つ時間が延び、乗客の多い路線の住民の満足が下がる恐れ。前回の下げでは幸福度85のまま
  - 6-3: バスから車に移る人で、cars と blocked が増える恐れ。前回は blocked 857→1,076 と増えた
  - 運賃収入が少し減る(前回は 5,121→4,697)
  - m10-1 のごみの車の回り道も街の交通を変えるので、flow の変化はバスだけのものと言えない。そのため flow は補いに留める
- 戻せるか: 戻せる(`set_budget(target="bus", percent=130)`)

- 見る道具と引数:

  - `buildings_near(x=-1115, z=-877, radius=500, problem="NoGoods", brief=true, limit=50)`

- いつ見るか: 見回り1、見回り2、月末

- 採った理由: 重点の 6-4・7-1 で、壊す手が1か月で戻ったため、品物が届かない元を絞らないと次の案が出せない。

## 採らなかった案

- roads: 東の2つの3差路 (2110,330)・(2110,240) に信号を付ける試し。実行条件はそろっている(市長も `junction_info(2110,330)` で trafficLights=false・canEnableLights=true を確かめた)。採らなかったのは、m10-3 のバスの予算の下げが街全体のバスの台数を変え、円 (2082,271) 半径200 の blocked と混ざるため。加えて、m10-1 の試しの円 (2053,666) 半径250 と約50m重なり、10351 のごみの車の回り道も円の車を変える。3件の上限の中で、重点の2つと公約3のバスを先にした。来月、ほかの交通の手と重ならない形なら出し直せる

## 判断の根拠

重点の 4-3 と 4-2 には、実行条件を確かめた案が1件ずつあり、どちらも費用が小さく戻せるので採った。m10-1 は分からないことの一覧の「汚染の出どころ」の試しで、場所 (2053,666) にほかの施策を重ねない。3件目は、6-3 の2案のうち、黒字 +8,676 が薄い中で週約2,900を減らすバスの予算を選び、混ざりを避けるため信号を見送った。重点の 6-4・7-1 は施策の案がなく、economy の調査を採って品物が届かない元を絞る。
