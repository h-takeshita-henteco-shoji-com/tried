- 元にした局の案: health。手直しした点: なし(響きの見立てと、測る数の円を足した)
- 議決: 要らない
- 採択理由: ごみの印33の中心 (-130,316) の円(半径400)に印11棟があり、うち8棟は x -238〜-186 で置き場のすぐ東にある。最寄りの埋立地12880 は貯蔵99%・車2/19、16914・25692 は100%・車0で、受け入れ先が足りないと見た。市長も同じ引数で `test_place_building` を呼び、2棟とも ok・取り壊し0・入口は Large Road に2mを確かめた。

- 公約: 直接はない。市の計画の 4-4 のため。公約3に維持費 +約320 の響き
- 市の計画: 4-4 資源循環

- 予想: 局の予測を引き継ぐ。円 (-130,316) 半径400 のごみの印 11 → 5以下、`complaints` のごみの印 33 → 25以下。期限は12か月目の月例。確かめは見回り1・2と月末に同じ円の `buildings_near(problem="Garbage")` と、新しい2棟の車の数・貯蔵(`buildings_near(x=-290, z=460, radius=80, service="Garbage")`)。不確かな点は、印の原因が受け入れ先の不足だという直接の証拠がないこと(焼却場10351 の停止との関係は分けていない)と、車が回り始めるまでの日数

### m11-2 バスの予算を110%から130%に戻す(試し)

- 元にした局の案: port。手直しした点: なし
- 議決: 予算
- 採択理由: バスの予算を下げた2回(m08-3、m10-3)とも、街全体の blocked が増えた(857→1,076、782→997)。今の flow 54% は目標60%から遠く、台数を戻して blocked が戻るかを確かめる手は、6-3 の街全体の数に直接かかる。
- 今月選んだ理由: 重点2(6-3)の案は roads の信号と、この案の2つ。信号の円は基準の blocked が12と小さく、街全体の flow を動かさないと局が書いている。街全体の数に効く見込みのあるこちらを先にした。週の増え分約2,857は要領の枠8,000の内で、黒字は約 +8,900 に残る。
- 公約: 3 に響く(支出が増える)。直接は市の計画の 6-3 のため
- 市の計画: 6-3 公共交通を主軸とした交通体系
- 操作:
  1. `economy` で bus が昼110・夜110 であることを確かめる。`city_info` の週の収支が +5,000 以上かを確かめる
  2. 基準を記録する。`traffic()` の flow・blocked・cars、`economy_breakdown` の PublicTransportBus の支出と収入、`list_transport_lines(type="bus")` の vehicles の合計
  3. `set_budget(target="bus", percent=130)` を1回(昼と夜が130になる)
  4. 直後に `economy` で bus 130/130 を確かめる。月末に2の道具で同じ数を測る
- 実行計画: 設置の条件はない。bus は昼110・夜110(局と財政局が `economy` で確かめた)。+20 は要領の予算の幅±20 の内、130 は道具の範囲50〜150 の内。同じ130は m08 まで使っていた値。予備候補は120(+10)。中止する条件: bus が110でなければ見送る。週の収支が +5,000 を下回っていれば見送る
- 費用: 建設費 0、週の維持費の増え分 約2,857(m10-3 の減り分から見積もり)
- 予想: 局の予測を引き継ぐ。街全体の blocked 997 → 900以下、flow 54% → 55%以上。PublicTransportBus の支出 16,356 → 約19,200、台数 約1,420 → 約1,670。期限は12か月目の月例。確認は `traffic()` の blocked と flow、`economy_breakdown`、`list_transport_lines(type="bus")`。不確かな点は、m10 の blocked の増えに焼却場の停止や放棄の戻りが混ざっていたこと、乗客が一桁の路線が多く台数を増やしても流れが良くならないおそれ
- 試し: 仮説は「バスの台数を戻すと、車に移った人が戻り、街全体の blocked が減る」。測る数は `traffic()` の blocked(基準997)と flow(基準54%)。場所は街全体(工事はない)。分からないことの一覧に直接の項目はないが、バスを下げた2回の blocked の増えの原因を分ける。m11-1 の測る数(中央の円のごみの印)とは重ねない
- ほかの局への響き:
  - 公約3・財政: 週の収支 +12,081 → 約 +9,200(m11-1 と合わせて約 +8,900)。所持金は出発点を上回ったまま
  - 6-3 の円の数: バスが増え、停留所の多い道で一時の止まりが増えるおそれ。roads の調査 (2704,297) の blocked にも混ざる
  - 運賃の収入は台数とともに少し戻る見込み(m10 は 4,597→4,455)
- 戻せるか: 戻せる(`set_budget(target="bus", percent=110)`)
- 取り壊しのとき: 該当なし

## 採らなかった案

- roads: 東の3差路 (2110,330) と (2110,240) に信号を付ける試し。実行条件は確認済みだった。採らなかった理由は、同じ月に m11-2 で街全体のバスの台数を戻し、試しの円 (2108,313) の blocked(基準12)と congestion に混ざるため。基準の blocked が12と小さく、混ざると効き目を分けられない。試しの場所に同じ月のほかの施策を重ねない決まりに当たる
- economy: 東の (2170,190) 半径130 を事務所区画に指定し直す試し。本文に、空き43マスのうち道に面して建てられるマスの数が未確認と書かれ、建つ条件が確かめられていない。また `zone_area` は円の中の建物のない区画マスを全部塗り替えるので、同じ円の空いた高密度住宅40マスも事務所に変わるおそれがあるが、その扱いが書かれていない。roads の信号の円 (2108,313) 半径200 とも重なる。出し直すなら、`zone_rect` か `zone_polygon` で商業の空きだけを囲む範囲と、道に面した空きの数(`zone_summary` の emptyFacingRoad など)を添える
- urban: 施策の案なし(調査 s11-1 は採った)
- education: 施策の案なし
- fire: 施策の案なし

## 判断の根拠

採れる4案のうち、health と port は実行条件が本文で確かめられ、試しの場所と測る数も分かれる。ごみ(4-4)は今月の重点1で、同じ形の埋立地が3回とも近くの印を減らしており、印の8棟は置き場の東の街区に集まる。交通(6-3)は信号と予算の2案があるが、両方を採ると円の数が混ざるので、街全体の flow と blocked に効く見込みのある予算の案を採った。economy は道に面した空きが未確認で、住宅の空きマスまで塗り替える響きが書かれていないため採らなかった。
