### m03-1 南西のごみの中心の東に埋立地を2棟置く(試し)

- 元にした局の案: health。手直しした点: なし。実行の前後に、近くの地価を測る手順を足した(響きを確かめるため。街は変えない)
- 議決: 要らない
- 採択理由: ごみの印は 23→44 と倍になり、中心の南西 (-1983,-1945) では埋立地23032・29270・25826・19182が満杯で、157も99%。受け入れ先を足せば、収集車の行き先ができると判断した。市長も `test_place_building` で2か所とも ok、費用4,000、取り壊し0、入口の道路ありを確かめた
- 今月選んだ理由: 重点1の 4-4 に当たる唯一の案で、ごみは市の計画の目標0から最も遠い。分からないことの一覧の「焼却場を足したのにごみの印が増えた原因」を確かめる試しで、費用も8,000と小さい
- 公約: 直接はない。市の計画の 4-4 のため。公約3には維持費 +320 の響き(黒字は保てる)
- 市の計画: 4-4 資源循環
- 操作:
  1. 置く直前に `test_place_building(prefab="Landfill Site", x=-1910, z=-2000, facing="west")` で ok と wouldDemolish 0 を確かめる
  2. `place_building(prefab="Landfill Site", x=-1910, z=-2000, facing="west", pay=True)`
  3. `city_info` で所持金を見る。2,082,287 以上なら次へ
  4. `test_place_building(prefab="Landfill Site", x=-1910, z=-2120, facing="west")` で ok と wouldDemolish 0 を確かめる
  5. `place_building(prefab="Landfill Site", x=-1910, z=-2120, facing="west", pay=True)`
  6. 置いた後、`buildings_near(x=-1910, z=-2060, radius=300, service="Garbage")` で、2棟の車と貯蔵を見る
  - 置く前に一度だけ `land_value(x=-1910, z=-2060, radius=250)` を測り、響きの基準にする
- 実行計画:
  - 確認済みの設置条件: (-1910,-2000) west は ok、費用4,000、入口 (-1942,-2000) から Small 4 Lane Road(segment 24981)まで10m、取り壊し0。(-1910,-2120) west は ok、費用4,000、入口 (-1942,-2120) から Basic Road(segment 16384)まで10m、取り壊し0(局と市長が同じ引数で確かめた)。埋立地は電気・水・下水が要らない
  - 予備候補: なし。1棟が断られたら、もう1棟だけ置く
  - 中止する条件: 直前の試しが ok でないか、壊れる建物が1棟でも出たら、その棟を見送る。1棟目の後の所持金が出発点 2,082,287 を下回るなら、2棟目を見送る
- 費用: 建設費 8,000、週の維持費の増え分 320
- 予想: 局の見立て。新しい埋立地(各8,000,000)が収集の行き先になり、ごみの印が減る。今の値は `complaints` のごみの印44(南西の中心に14棟)。予想は4か月目の月例で25以下。数値の幅は見積もれない。確かめは `complaints` のごみの印と中心、`buildings_near(x=-1910, z=-2060, radius=300, service="Garbage")` の2棟の車と貯蔵率。不確かな点は、収集車が新しい埋立地を選ぶか。焼却場41481は車15/34で余るため、原因が収集の届き方なら効きは小さい
- 試し: 仮説は「満杯の埋立地が近くに多く、新しい埋立地が収集の行き先になってごみの印が減る」。測る数は `complaints` のごみの印(基準44)と、南西の中心 (-1983,-1945) の棟数(基準14)。場所は (-1983,-1945) の周り。分からないことの一覧の「ごみ焼却場9282を足したのに、街全体のごみの印が 23→44 に増えた原因」の試し
- ほかの局への響き:
  - 4-1 地価・4-3 汚染(住宅都市みどり局、保健環境局): 半径250mの中に高密度住宅43棟(家302、地価の平均41)と事務所28棟がある(`building_stats`)。埋立地は土の汚れを出し、近くの地価を下げる向き。高密度住宅4,057棟のうち43棟で、街の平均58への響きは小さいと見る。汚染の印31が増えないかを月末に見る
  - 6-3 交通(道路下水道局): 収集車が南西に集まり、入口の道路が混むおそれ。量は見積もれない
  - 財政: 維持費 +320 で、週の収支 +7,337 は黒字のまま
- 戻せるか: 戻せる(取り壊しは議決が要る)

### m03-2 (2236,-950) の3差路に信号を付ける(試し)

- 元にした局の案: roads。手直しした点: なし
- 議決: 要らない
- 採択理由: この3差路の周りの Basic Road 区間は、2月の3回とも density 100 で、円 (2237,-936) 半径150 は blocked 21、congestion 47。拡幅は試しの道具に断られ(36011 が TooShort)、残る手は信号。市長も `junction_info(2236,-950)` で node 5405、canEnableLights=true、信号なしを確かめた
- 今月選んだ理由: 費用0で戻せ、測る円が狭く効き目を切り分けやすい。同じ 6-3 の port のバスの案は街全体の流れで測るため、この試しと測る数が重なる。効き目の小ささも前月から変わらないため、こちらを選んだ
- 公約: 直接はない。市の計画の 6-3 のため
- 市の計画: 6-3 公共交通を主軸とした交通体系
- 操作: 実行前に `junction_info(x=2236, z=-950)` を見る。canEnableLights が true で信号がなければ、`set_traffic_lights(x=2236, z=-950, active=true)` を1回。月末に効かない(blocked が21以上)か悪くなったら、`set_traffic_lights(x=2236, z=-950, active=false)` で外す
- 実行計画:
  - 確認済みの設置条件: node 5405、入る区間は 3334(bearing 90)、36011(270)、10391(0)の3本で、いずれも Basic Road、譲れの標識なし
  - 予備候補: 隣の node 30823 (2220,-950)。canEnableLights=true、信号なし(局が確かめた)。16mしか離れないので両方には付けない。今月は使わない。5405 で悪くなったときは、5405 を外して来月の案に回す
  - 中止する条件: 実行前の `junction_info` で canEnableLights が false、またはすでに信号があれば見送る
- 費用: 建設費 0、週の維持費の増え分 0(局の見込み。`economy_breakdown` では未確認)
- 予想: 局の見立て。信号で車が順に進み、詰まりが減る。今の値は `traffic(x=2237, z=-936, radius=150)` の flow 54、blocked 21、congestion 47、averageDensity 92。予想は月末に blocked 15以下。数値は見積もれない。確かめは同じ円の `traffic` を見回り1・2と月末に見る。街全体の flow(今54%)は記録するが、判定には使わない。不確かな点は、16m先の node 30823 との間に車がたまり、かえって悪くなるおそれ
- 試し: 仮説は「信号を付けると、3差路で車が順に進み、blocked が減る」。測る数は `traffic(x=2237, z=-936, radius=150)` の blocked と congestion。場所は (2236,-950) の周り。基準は blocked 21、congestion 47。分からないことの一覧の項目ではない(6-3 の担当の試し)
- ほかの局への響き:
  - 3-4・1-2(消防局、保健環境局): 南北の道 10391 の先に消防署32853と診療所32923がある。信号待ちで消防車と救急車が遅れるおそれ。火事の印は1(工場12882、(2184,-918)、この交差点から約60m)。月末に火事の印と病気の数を見る
  - 6-4・7-1(経済観光文化局): 品物と原料のトラックも通るため、悪くなれば品物がない店に響く。円の blocked が増えたら外す
- 戻せるか: 戻せる
