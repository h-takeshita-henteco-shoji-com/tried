# m04 港湾空港局の案

## 施策

- 施策: 貨物駅28755(Cargo Center、(3449,-1555))を10日間止めて動かし直す試し。道具は `set_building_active`。2回目の試し
- 議決: 要らない

## 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. 実行の直前に `cargo()` を測り、stoppedInBuildings の基準を記録する
  2. `set_building_active(id=28755, active=False)`
  3. 10日後の見回り1で `cargo()` と `vehicles_stuck(kind="truck", building=28755, limit=60)` を測る。その直後に `set_building_active(id=28755, active=True)`
  4. 見回り2と月末に同じ2つの道具で測る
- 設置条件の確認: 建物の新設はない。28755 は `cargo` の stations に載り、`transport_reach` で outsideConnected=true。前月と同じ操作が通った(台帳 m03-port の executed ok=true、費用0)
- 接続工事: 不要。出口に道を足す案は `test_build_line`(Basic Road、(3417,-1555)→(3400,-1555))が、建物28755を壊すと返して断ったため外した
- 予備候補: なし
- 中止する条件: `set_building_active` が id 28755 を断る場合。または実行前の stoppedInBuildings が 150 未満の場合(試す必要がない)

## 期待する効果

- 改善の見込み: 前月は止めて動かし直すと、28755 の敷地の中の止まりが 575 → 295 に減った。同じ操作をもう一度すれば、WaitingSpace に溜まった車が捌け、250 以下の目標に近づくと予想する。
- 数値と期限: `cargo` の stoppedInBuildings。今 295(28755 が 294)。予想は 150〜280。数値は見積もれない。月末(30日目)までに確かめる
- 確認方法: `cargo()` の stoppedInBuildings と stoppedInBuildingsTop。`vehicles_stuck(kind="truck", building=28755)` の bySeenStopped(7days+ が 339 から減るか)を、実行前・見回り1・見回り2・月末で比べる
- 不確かな点: 前月は 90 日止まった車(8、36、664、670、675 など)が同じ (3441,-1555) に残った。止めても動かない可能性がある。貨物列車13本が 28755 へ荷を運び続けており、止めても再開後に積み戻る恐れがある。その場合は 295 付近で下げ止まる
- 試し: 仮説は、28755 を止めると敷地の中の車が掃け、再開後の入口が空くので止まりが減る。測る数は `cargo` の stoppedInBuildings(28755 の分)。場所は 28755。基準は 295。編成方針の「貨物駅28755 の敷地の中で、なぜトラックが止まり続けるか」に当たる

これは局の予測です。ゲームの効果の正解を取得しません。
