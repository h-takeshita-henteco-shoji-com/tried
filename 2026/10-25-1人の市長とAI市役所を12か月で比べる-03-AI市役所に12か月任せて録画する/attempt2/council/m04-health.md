## 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `buildings_near(x=-1862, z=-2000, radius=60, brief=true)` で建物が0棟、`net_near(x=-1820, z=-2000, radius=80, service="Road")` で南への道がないことを見る
  2. `build_line(prefab="Basic Road", points=[[-1820,-1960],[-1820,-2040]], pay=True, demolish=False)`。端 (-1820,-1960) は既存の点7989(道31714の端)にsnapし、snapped 1 以上を見る。overlaps が返ったら見送る
  3. `place_building(prefab="Landfill Site", x=-1862, z=-2000, facing="east", pay=True)`。entrance.road が null でなく、demolished の count が0を見る
  4. `services` の garbage.capacity が 160,000,000 → 168,000,000 になることを見る
- 設置条件の確認:
  - 敷地: `buildings_near(x=-1850, z=-2010, radius=130, brief=true)` は 28092 (-1976, -2012) の1棟だけ。予定の敷地 x -1894〜-1830、z -2040〜-1960 に建物はない
  - 区画: `zones_at(x=-1860, z=-2000, radius=60)` は Unzoned 8(空き8)だけ。区画の建物はない
  - 地形: `height_at(x=-1860, z=-2000)` は 56.865、水面と同じ値(水なし)。近くの埋立地の地面と同じ高さ帯
  - 道: `net_near(x=-1850, z=-2010, radius=130)` で道 31714 の端 (-1820, -1960)(点7989)を確認。南へ延ばす道はまだない。埋立地は電気・水・下水が要らない(`list_building_types`)
  - 未確認: 土地の購入(所有)は、道具で見る手がない。`place_building` が断ったら見送る
- 接続工事: Basic Road 80m。`list_net_types` の Basic Road は 5,000 / km なので建設費 400、週の維持費 約3(40 / km)
- 予備候補: なし(確認済みの別の場所がない)
- 中止する条件: `build_line` が overlaps を返す、または snapped が0。`place_building` が断る、entrance.road が null、demolished が1以上。建設費が 5,000 を超える

## 期待する効果

- 改善の見込み: 印の集まる (-2430, -1807) の周りの埋立地3つ(157・23032・29270)が100%で、焼却場41481も99%。受け入れ先が1つ増えれば、車の行き先ができてごみの印が減ると予想する(効く見込みは、m03 の s03-3 の結果)
- 数値と期限: `complaints` のごみの印は今74。月末までに 60以下と予想(量は見積もれず、下げ幅は幅を持たせた)。`services` の garbage.capacity は 160,000,000 → 168,000,000。満杯の埋立地は今8。新設分が満ちなければ 8 のまま
- 確認方法: `complaints` の Garbage、`services` の garbage.full と capacity、`buildings_near(x=-1862, z=-2000, radius=60, service="Garbage")` の storage と車の数。見回り1・2と月末
- 不確かな点: 印の家は埋立地から約600m西で、新設の埋立地の車が (-2430, -1807) の周りまで回るかは分からない。運ぶ車が道で止まる(blockCounter 40台超)問題は別で、収集車の渋滞は直らないかもしれない。新設の埋立地は地面の汚染を足し、近くの家の汚染の印を増やす恐れがある(西70mに家28092の1棟)
- 試し: 仮説は、受け入れ先を満ちた3つの南に足すと収集車の行き先が増え、ごみの印が減る。測る数は `complaints` の Garbage(基準74)と `services` の garbage.full(基準8)、新設の storage と車の数。場所は (-1862, -2000)。編成方針の分からないことの「ごみの印が (-2430, -1807) に集まる原因の手当て。受け入れを増やすと印が減るか」に当たる
