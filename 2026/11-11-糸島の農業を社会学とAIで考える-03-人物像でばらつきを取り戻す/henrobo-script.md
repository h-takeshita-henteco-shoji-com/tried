# 台本: へんロボ、AIに公共財ゲームをさせて、人間らしく振る舞えるか確かめる

#168・#169・#172 をまとめた記事（`article.md`）の内容を、へんロボ1人の説明で動画にします。
ゲームの記録を Godot で再生した録画（`~/henrobo-video/172/godot-*.mp4`）を、場面として使います。

## 前提

- 尺: 本編が約9分。そのあとに、Godot の録画3本(各約4分半)をカットせずに流す。23場面
- 構成: ハイライト → 決まり文句 → 3つの目次 → 1つ目 → 2つ目 → 3つ目 → エンディング → プレイ動画3本 → 締め
- 目次の言葉: 各章の始めとエンディングで、同じ言葉をそのまま使う
  - 1つ目: 公共財ゲームで、AIの人間らしさを測る
  - 2つ目: AIに足りないものを探す
  - 3つ目: 結果が合っても、人間をまねできたとは言えない（へんロボの見立て）
- 決まり文句: 冒頭は「へんロボです。中小企業のAI導入の現場から、試したことをそのままお伝えします。」締めは「へんロボでした。それでは、また。」
- 字幕: 台詞1行が1文。字幕は1行で出すので、どの文も30字まで。冒頭の決まり文句だけは、言葉を変えずに読点で2行に分ける
- へんロボ: 落ち着いた大人の男性の会社員。丁寧語で、大げさにしない普通の話し方。1人で説明する
- 声: #132 の `assets/voice-design/B_en_calm_1.wav` を元に複製する
- 言葉の決まり: 何を・誰が、を省かない（「付けた人」でなく「減点を付けた人」）。「ポイント」「共同の口座」「口座に入れる」「減点」で統一し、「罰」は使わない。「物差し」「くじの位置」は、説明してから使う
- 事実は、記事（`article.md`）と記録（`log.md`、`code/social-sim/runs/`）にあるものだけを使う
- へんロボを大きく出す場面は作らない（右下にいつもいるため）
- 眼鏡のキラリは、台詞の頭に「(キラリ)」と書いた行の直後に入れる
- 「(間)」は、その台詞の前に間をあける合図
- Godot の録画は3本。#169 の罰ありの組（`godot-169.mp4`）、罰するプログラムの参加者がいる組（`godot-bots.mp4`）、固定0.7の組（`godot-rho07.mp4`）
