# 原文とAIの書き直しの比較

## 手順

1. 原文3本を、内容だけの要約にした(`summaries.md`、Claude Opus 5.5)
2. 要約だけを Sonnet 5.5 に渡し、書き直させた(`rewrites/`)。ツールは使わせず、元記事を見られないようにした
3. 原文と同じ8条件で、書き直しに印を付けた(Claude Opus 5.5)

指示文(3本共通。分量だけ原文に合わせて変えた):

```
ツールは一切使わないでください(検索もファイル読み込みもしない)。以下の要約だけを材料にして、記事を書いてください。

条件:
- 要約の「対象読者」に向けた読み物として書く
- 分量は約2,200字
- 出力は記事の題と本文だけ。前置きや解説は付けない

要約:
(summaries.md の該当部分)
```

## 結果の要点

- 面白さを狙った2本(A、B)では、書き直しが原文の仕掛けを落とした。A は伏せる順序、B は比喩と語り手の声である
- 面白さを狙わない1本(C)では、書き直しが原文と同等か、少し分かりやすかった
- 書き直しは3本とも、見出し、結論の予告、まとめの列挙を足した。読みやすくする方向の加工である

## A. コードは設計である

| 観点 | 原文 | 書き直し |
|---|---|---|
| 分量 | 2,162字、見出しなし | 1,672字、見出し5つ |
| 結論の位置 | 題でだけ示す | 2%で「先に結論を言います」 |
| ソフトウェアの話だと明かす位置 | 72% | 2%で予告、34%で本題 |
| 「コストが下がり品質が下がる」 | 69%。読者は行き先を知らない | 31%。行き先を知ったうえで読む |
| 答え(自動テスト) | 88% | 57% |
| 足したもの | ― | コンパイラをロボットに対応づける説明、風洞実験のたとえ、「明日からできること」の要点2つ |

- 条件4(出す順序)が消えた。原文は対象を伏せて驚かせたが、書き直しは先に明かした
- 条件1(予想から外れる)は残るが弱い。外れを予告してから見せるため、驚きにならない
- 書き直しは、原文が暗に任せた対応(ロボット=コンパイラ)を言葉にした。分かりやすさは上がった

## B. 科学者とあたま

| 観点 | 原文 | 書き直し |
|---|---|---|
| 分量 | 3,843字、見出しなし | 2,528字、見出し11 |
| 逆説の位置 | 3% | 0%(見出し「結論から言う」の直後) |
| 対比の反復 | 「頭のいい人」14回、「頭の悪い人」9回 | 9回、8回。見出しごとに1つの対比へ分けた |
| 比喩 | 足の早い旅人、富士のすそ野、恋は盲目、死骸の山、大工 | ほぼなし(「道の脇の小さな違和感」程度) |
| 語り手 | 書き手が老科学者として語る | 老科学者を第三者として紹介する |
| 結び | 読者を3種に分けて皮肉る | 「持ち帰れることは三つ」と教訓を並べ、「静かにそう教えてくれる」で閉じる |
| 足したもの | ― | 読者への橋渡し(「考えすぎて動けない」経験)、言い過ぎを和らげる但し書き(「遅いほうがよいということではない」) |

- 条件6(型の繰り返し)は残った。ただし見出しで区切ったため、対比が畳みかける勢いは消えた
- 書き手にしか持てない視点が薄れた。比喩と語り手の声は要約で消しており、AIは新しく作らなかった
- 但し書きが、逆説の角を丸めた。原文は言い切ったまま進む
- AIが自分で足した1文に、小さな裏切りがある。「人は最も頭の悪いやり方で、頭のいい人になってしまう」

## C. 竜巻などの激しい突風とは

| 観点 | 原文 | 書き直し |
|---|---|---|
| 分量 | 約600字と表 | 608字と表 |
| 構成 | 結論先、表、補足 | 同じ |
| 題 | 「〜とは」 | 「竜巻だけではない」と小さな裏切りを予告する |
| 足したもの | ― | 被害の形が違う理由(渦なので帯、吹き出すので面)、「3種すべてに備えて」という行動の呼びかけ |

- 原文と同等で、理由の説明が増えた分だけ分かりやすい
- 小さな裏切り(「竜巻」の語の範囲)を、題で拾った。原文は補足に埋めていた

## 解釈と限界

- AIは、要約から読みやすい文章を作れた。面白さを生む仕掛け(伏せる順序、比喩、語り手の声)は再現しなかった
- ただし、この比較には交絡がある
  - 要約を結論先の箇条書きにした。AIが結論を先に置いたのは、要約の順序に従っただけかもしれない
  - 比喩を要約で消した。AIに比喩を作る力がないとは言えない
- 評価は1人のAI(Claude Opus 5.5)の印だけ。私(やってみ太郎)の読みとまだ照らし合わせていない

## 次に試すとよいこと

- 要約を原文の順序のまま渡し、AIが伏せる順序を保つかを見る
- 指示に「面白く」を足し、何が変わるかを見る
- 原文と書き直しを、どちらか伏せて私が読み、どちらが面白いかを判定する
