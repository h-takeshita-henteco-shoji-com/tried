# 台本: へんロボ、毎回同じ量を入れるAIが、入れる量を変え始める条件を探す

#173 の記事（`article.md`）の内容を、へんロボ1人の説明で動画にします。
ゲームの記録を Godot で再生した録画（`~/henrobo-video/173/godot-*.mp4`）を、場面として使います。

## 前提

- 構成: ハイライト → 決まり文句 → 3つの目次 → 1つ目 → 2つ目 → 3つ目 → エンディング → プレイ動画1本 → 締め
- 目次の言葉: 各章の始めとエンディングで、同じ言葉をそのまま使う
  - 1つ目: 相手が見えても、AIは入れる量を変えなかった
  - 2つ目: 「順位」の一文で、AIが入れる量を変え始めた
  - 3つ目: 量を変えても、AIは人間とは違う（へんロボの見立て）
- 決まり文句: 冒頭は「へんロボです。中小企業のAI導入の現場から、試したことをそのままお伝えします。」締めは「へんロボでした。それでは、また。」
- 字幕: 台詞1行が1文。字幕は1行で出すので、どの文も30字まで。冒頭の決まり文句だけは、言葉を変えずに読点で2行に分ける
- へんロボ: 落ち着いた大人の男性の会社員。丁寧語で、大げさにしない普通の話し方。1人で説明する
- 言葉の決まり:
  - 何を・誰が、を省かない（「量が揺らぐ」でなく「AIが入れる量を変える」）。30字に収めるときは、主語と目的語でなく修飾語を削るか、2文に分ける
  - 比喩の動詞（動く・揺らぐ など）を使わず、起きたことをそのまま言う
  - 「ポイント」「共同の口座」「口座に入れる」「入れる量」「減点」で統一し、「罰」は使わない。チャット(話し合い)の条件は扱わない
- 事実は、記事（`article.md`）と記録（`log.md`、`code/social-sim/runs/c173abl/`）にあるものだけを使う
- へんロボを大きく出す場面は作らない（右下にいつもいるため）
- 眼鏡のキラリは、台詞の頭に「(キラリ)」と書いた行の直後に入れる
- 「(間)」は、その台詞の前に間をあける合図
- Godot の録画は2本。動機なしの組（`godot-none.mp4`）と、順位を意識させた組（`godot-rank.mp4`）。どちらも第0組
