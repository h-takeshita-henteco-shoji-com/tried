### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `place_building` prefab="High School", x=2700, z=850, facing="west"(pay=true)。`test_place_building` で ok、placed=false、cost=24000、enoughMoney=true、entrance.road=segment 13565(距離 10.3m)、wouldDemolish=0 を確認済み
- 設置条件の確認:
  - `test_place_building`: 上の引数で ok。取り壊しは 0 棟、失う家 0
  - `water_trace`(2700, 850): 近くの建物(2692, 817)は電気・水・下水の grid がすべて true。水の網に取水口と排水口がつながっている
  - 電気: `water_trace` の建物の grid で true を確認。送電線の引き直しは不要
- 接続工事: 不要(入口の道路 segment 13565 が面している。電気・水・下水は近くの網につながっている)
- 予備候補: 確認済みの予備は1つ。(1420, -1150) は `test_place_building`(High School、facing west)で置けるが、入口の16m以内に道路がない(road: null)。道路を引く工事が要るので、予備にはしない。使うなら道路の追加を、実行前に `test_build_line` で確かめる
- 中止する条件: `place_building` で断られたら、理由と colliding を読む。取り壊しが出る(wouldDemolish > 0)なら、その場では置かず、市長に戻す。断られた場合は予備を使わず、案を見送る
- 再調査の結果(条件付き採択の件、2026-10-29):
  - 条件1(10代が定員の95%を超える): 未達。`citizens_summary` の10代は 22,372、高校の定員は `services` で 24,360。10代は定員の 91.8%。95% の 23,142 に届かない
  - 条件2(運賃0を外した後、週の収支の余力が560以上): 運賃0(m01-3 の FreeTransport)を外すと満たす。`economy_breakdown` の PublicTransport の運賃の収入 5,179 が、外すと戻る。今の週の収支 +9,965 から、m01-2(信号の上限 468)、m01-1(公園と幹線 79)、m01-4(埋立地 163)、m01-6(警察 480)の計 1,190 を引き、高校の 560 も引くと約 +8,215。守る線 +3,000 に対し余力は約 5,215 で、560 を超える
  - 運賃0を残したままなら、余力は約 36(市長の見積もりと同じ)で、条件2は満たさない
  - 採否の判断は市長に任せる。この案は、FreeTransport を外す案と組み合わせて採るときに条件を満たす。案の実行計画(配置)は変わらず、確認済みのまま

### 期待する効果

- 改善の見込み: 10代の数(22,372)に対して高校の定員(24,360)の余裕が約9%しかない。10代が増えると定員を下回る。高校1棟(定員 +1,000)で余裕を約13%に増やし、2-3 の目標を保つ、と予想する。10代が定員を超える前に増やす手として見る
- 数値と期限: 高校の定員 24,360 → 25,360(建った後の `services` の education.high)。10代 22,372 は今の値(10代は定員の 91.8%)。期限は建ってから次の月例(2か月目の見回り)
- 確認方法: `services` の education.high と、`citizens_summary` の age.teen。今の値(24,360 / 22,372)と同じ条件で比べる。建設後の `buildings_near`(service=Education、prefab High School)で棟数が1増えたことも確かめる
- 不確かな点: 定員の増えが効くのは、10代が増えたときだけ。今月の10代の数は変わらないので、定員の効きは「定員が10代を下回らない」ことで測る。10代の増え方は月ごとに変わり、量は見積もれない。学校の定員は、働き手や予算が足りないと実際の入学数が減る可能性がある(services の capacity は予算100%・働き手がそろったときの数)
- 試し: なし

## 判断の根拠

- 教育の数字は出発点で目標を満たしている(小学校の定員 14,268 ≥ 子ども 11,344、高校の定員 24,360 ≥ 10代 22,372)。ただし高校の余裕は約9%で、10代の増えにつれて早く詰まる
- 今月の案は、高校1棟の増設1件。定員を先に増やし、10代が定員を超えるのを防ぐ。候補 (2700, 850) は、取り壊しなし、道路に面する、電気・水・下水が届く、の3条件を確認した
- 案の数を1件にした理由: 教育の数字は目標内で、ほかに効く手がない。件数を埋めるための案は作らない。編成方針の重点の外なので、市長が採るかを判断する
- 調査は出さない。教育の問題の原因は分かっている(定員の余裕の少なさ)
- 1か月目に作った地図の画像 `council/m01-education-map.jpg` は、zone_map の save_to で保存された。局が書くファイルの範囲の外。市長が使わなければ削除してよい
- 再調査: 条件1(10代 95% 超)は未達(91.8%)。条件2は、運賃0を外せば満たす(余力約5,215)。運賃0を残すなら満たさない。案の配置は変えず、採否は市長に任せる
