## 案1: 止まりの多い交差点 (2110, 330) に信号を1基付ける

### 施策

- 議決: 要らない

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  0. 付ける前に `city_info` の所持金と `economy_breakdown` の total.expenses(今 332,175)を記録する
  1. `set_traffic_lights(x=2110, z=330, active=true)`
  2. 付けた後に `city_info` の所持金と `economy_breakdown` の total.expenses を記録し、0 と比べる(建設費は所持金の差、維持費は週の支出の差)
  3. 上限の判定: 所持金の減りが 208,287 を超える、または週の支出の増えが 468 を超えたら、`set_traffic_lights(x=2110, z=330, active=false)` で外す
  4. 見回りのとき、`traffic(x=2150, z=350, radius=250)` で止まった車を測る
- 設置条件の確認:
  - `junction_info(2110, 330)`(1か月目、再確認した是正の段でも同じ): 信号なし、canEnableLights=true、譲れ標識を付けられる。入る道は4車線の3本(segment 3990、22887、26735)
  - 信号は道と線路が交わる交差点には付けられないが、この交差点は道どうしの交差点なので対象になる
  - 実行の前に、もう一度 `junction_info(2110, 330)` で canEnableLights を確かめる
- 接続工事: 不要
- 予備候補: 2基目は 2152, 483(`junction_info` の canEnableLights=true、1か月目の確認)。使うのは2か月目で、1基目の増えが 234 以下のときだけ
- 中止する条件: 実行の前の `junction_info` で canEnableLights が false になっていたら見送る。上の上限(所持金の減り 208,287、週の増え 468)を超えたら外す

### 期待する効果

- 改善の見込み: 交差点の周りで止まった車が多い(2110, 330 の周り50台)。信号で合流の順番を決めれば、止まりが減ると見込む。市全体の流れ(6-3)への効きは、1基だけでは小さい
- 数値と期限: 止まった車(`traffic` の blocked)。今の値は、範囲 (2150, 350)、半径 250 で 163台(blockedSpots は (2100, 309) の 50台が近い)。予想は、2か月後に同じ範囲で 3 割以上減ること。これは局の予測で、ゲームの効果の正解ではない。期限は、見回り1(10日目)で向きを見て、月末(30日目)で判定する
- 確認方法: `traffic`(x=2150, z=350, radius=250)の blocked と blockedSpots を、信号を付ける前後で比べる。市全体の流れは `traffic` の flow(今 51%)を同じ日に記録する
- 不確かな点: 信号の周期(道具に数字がない)で、効き目が変わるかもしれない。市全体の流れ 51% を 60% にする量は見積もれない。信号を付けて渋滞が増えたら外す
- 試し: 試し。仮説は「合流の順番を信号で決めると、交差点の止まった車が減る」。測る数は `traffic` の blocked(範囲 (2150, 350)、半径 250)。場所は上の交差点。基準は今の 163台。編成方針の「分からないこと」は項目にない(担当の問題の、交通の流れの原因を見る手)

### 費用

- 建設費: 上限 208,287 以内で実行する。道具に数字がない。`list_net_types`(service=Road)に信号の項目がなく、`economy_breakdown` の networks にも既存の信号がないため、見積もれない。上限は所持金 2,082,287 から下限 1,874,000 を引いた余力。実行の前後の所持金の差で確かめる(操作順 0 と 2)
- 週の維持費の増え分: 上限 468 以内で実行する。道具に数字がない。`economy_breakdown` の週の支出の差で確かめる(操作順 0 と 2)。上限 468 は財政局の1月の表の余力(財政局の数に揃えた)。Road の expenses 8,526 は道路の網の合計と一致し、信号は含まれていない

### 戻せるか

戻せる。`set_traffic_lights` で active=false にすれば、元の交差点に戻る。

## 判断の根拠

- 担当の数字は、交通の流れ 51%(目標 60%)。止まった車は 1,008台。電気・水・下水が来ない市民は 0 で、今は達成している
- 止まりの局所的な集まりを3つ見た。(2150, 350) の周り、半径 250 に止まった車が 163台で、そのうち交差点 (2110, 330) が近い。信号は道具で付けられる(canEnableLights=true)
- 是正(第2回): 信号の建設費と維持費は道具で確かめられない。1基目を付けて、前後の所持金と週の支出を測ってから2基目を決める。1基目の上限は、所持金の余力 208,287 と、財政局の1月の表の余力 468 にする
- 是正(第3回): 信号の費用は、道具の一覧にも既存の施設の記録にもない。見積もりの代わりに上限(建設費 208,287、週 468)を書いた。財政局は、この上限を超えるかどうかで置く可否を判定する。実際の額は、置いた後の差で確かめる
- 2280付近の狭まりは、広げ直しで効きそうだが、取り壊しの議決が要る。失うゾーニングは、36011 だけの数が数えられないので、今月は案にせず、調査で見る
- 是正(第2回): 事業3の道は、道具の試しで通った。駅と空港の道は、建物の翌月に引く。島の橋と水道管は、試しで通ったが 47,420 で、経済観光文化局の 42,500 より多い
- 是正(第3回): 島Bの橋と水道管は、5月に引く形にした。名所の前月にあたる。他局との合意は、局では確かめられない。市長の調整で確かめる
- 是正(第4回): 島Bの橋と水道管は7月に引く(財政局の表に合わせた)。名所は8月。費用は 47,420 のまま。4車線化は9月に実行し、取り壊しの議決は8月の議会に出す(計画の事業2)。流れの積み上げは、`traffic` の範囲の外の3か所(138台)で書いた。届く見込みは未確認(計画の「流れの積み上げ」)
- 案は1件だけにした。ほかの候補は、手として効く見込みがないか、実行条件が確認できないか、今月の根拠が足りないため、捨てた
