# 保健環境局の長期計画

## 目標(12か月後)

- 1-2 健康の平均(`citizens_summary`): 78 → 80以上
- 4-3 汚染の印(`complaints`): 32 → 15以下
- 4-4 ごみの印(`complaints`): 15 → 0
- 見るだけ: 体調の悪い市民(`citizens_summary`)2,391、死体の印(`complaints`)52。計画の目標にしない

## 事業

### 1. 南西の埋立地を増やす

- 狙い: ごみの印が集まる南西(-458, -1468)の近くに、空いた埋立地を置く。西の埋立地は満杯で、収集車が遠くまで行っている(4-4)
- 段階: 1月に埋立地(-620, -1770、南向き)と道路を引く。2月に、ごみの印と収集車の止まりを見る。効かなければ、2か所目を探す
- 費用の見込み: 建設 4,280、週の維持 約163
- 求めること: なし
- やめる条件: 週の収支が +3,000 を切る。2か月たってもごみの印が減らない

### 2. 焼却場の近くの汚染を下げる(木の試し、次は焼却場の移し)

- 狙い: 住宅の汚染(255)と汚染の印を下げる(4-3)。焼却場 2267 の北の住宅地(x 3500〜3710、z -20〜-145)は、汚染が 250 前後で飽和している
- 段階: 1月に木を植え、(3600, -65) 周りの5点で汚染の基準を測る。2月と3月に同じ5点を測る。3月に平均が基準から下がらなければ、焼却場 2267 を空き地5(4545, 2382)へ移す案を出す。空き地5は `test_place_building`(Combustion Plant)で ok を確認済みで、入口の道路は未接続。空き地1は港湾空港局の空港候補と重なるので外す。移す先の道路は `test_build_line` で確かめる。移したら4月に、ごみの印と収集車の止まりを見る
- 費用の見込み: 木 約500 以内。移し(`relocate_building`)は建設費 30,000 の1/5 で 約6,000。道路の費用は未確認
- 求めること: 移し先へ道路を引くなら、道路下水道局に道路の延長を求める。3月の案で確かめる
- やめる条件: 3月の5点の平均が下がらず、空き地5に移せないなら、この手をやめる。工場(3882, -296)の汚染は、この計画では扱わない

### 3. 体調の悪い市民の原因を調べる(調査)

- 狙い: 体調の悪い市民 2,391 の原因が、汚染(事業2)、医療の届き方、霊柩車の渋滞のどれかを確かめる。健康の平均 78 → 80 の手を決める
- 段階: 1月の見回りと月末に、badHealth(`citizens_summary`)、health(`map_layer` 9×9)、霊柩車(`vehicles_stuck`)を見る。2月の案で次の手を決める。badHealth が汚染と一緒に減るなら、事業2を健康の手にする。health 0 の所に多いなら、診療所(10,000、週 400)を出す。霊柩車の渋滞が続けば、次の求めを出す
- 費用の見込み: なし
- 求めること: 霊柩車の渋滞が続くなら、道路下水道局に死体の印の周り(2100, -820 付近)の渋滞を見てもらう
- やめる条件: 3回の見回りで、どの候補にも差が出なければ、調べるのをやめ、健康の手を未定とする

## 月ごとの予定

| 月 | 予定 |
|---|---|
| 1 | 埋立地と道路を引く。空き地に木を植え、汚染の基準を測る。体調の悪い市民の原因を見る(調査) |
| 2 | ごみの印と収集車の止まりを見る。汚染の5点を測る。調査の結果から、健康の次の手を決める。差が出なければ、badHealth と汚染の5点の組を3月に比べ、一緒に減るなら事業2を健康の手に、減らなければ健康の手を未定にする |
| 3 | 汚染が下がらなければ、焼却場 2267 を空き地5へ移す案を出す(移し先の試しを先に行う)。下がれば木を広げる。埋立地が効かなければ、2か所目を探す |
| 4 | 汚染と、ごみの印を測り直す。焼却場を移したなら、ごみの印と収集車の止まりを見る |
| 5〜6 | 効いた手を続ける。健康の平均と体調の悪い市民を見る |
| 7〜9 | 汚染の印を下げる手を、重ねて試す(工場の汚染は含まない) |
| 10〜12 | 目標(健康 80、汚染 15、ごみ 0)との差を見て、残りを埋める |
