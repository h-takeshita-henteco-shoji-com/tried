### 2050-01-01 月例(1か月目)

#### 答え合わせ

前の月の施策はなし(1か月目)。

- 前回の「次にやること」: なし(初回)
- 公約の進み具合
  1. 人口: 178,872。出発点。2か月目の月例で増えているかを見る
  2. 電気・水・下水が来ない市民: 0 / 0 / 0。出発点で達成。保つ
  3. 赤字: 週 +9,965(収入 342,140、支出 332,175)。黒字
  4. 観光: 今いる観光客 1,646、Tourism の週の収入 45。目標は 3,000 以上と 1,000 以上で、遠い

試しの結果: 前の月の試しはなし。

#### 気づいたこと

- 観光は、旅客の入口が0棟(`buildings_near` PublicTransport 15棟は貨物駅、貨物港、バス車庫、地下鉄の入口のみ)。Tourism の収入が45と小さい原因とみる。attractiveness の平均は6で、名所は6棟
- 交通の流れは51%。止まった車1,008台、渋滞の印2,499台。止まりが多い場所は (2309, -925)、(-726, -736)、(2100, 309)
- 貨物駅 28755(3449, -1555)の中で492台が止まる(目標は敷地内の合計250以下)。品物がない店は228(目標120以下)

#### 施策

まとめる段で6件を採った(詳細は council/m01-bill.md)。結果の欄は、実行する市長が書く。

- m01-1 空き地3に公園1棟と幹線・送電線(公約4、4-2)。予想: 公園 81 → 82、attractiveness 基準0を3月に測る。結果: 成功。公園 id 12574(1,000)、幹線 13区間・橋3(7,700)。送電線は計画の始点 (712,1644) が公園の歩道と公園本体に ObjectCollision で断られ、始点を (664,1622) に動かして引いた(1,000、5区間)。advance(1) 後、公園の grid.electricity=true。attractiveness の基準は、公園を建てた後に測ったため平均8(最大125 は公園の位置)で、計画の基準0とは違う。地価の基準(建てる前、(712,1644) 半径150): 平均1、最大2
- m01-2 (2110,330) に信号1基: 議会が点5(財政)で否決。上限 208,287 の実額を示せず、直す段で取り下げた(council/m01-bill-2.md)。2月に実額を示して出し直せる
- m01-3 運賃0(公約3、6-3)。予想: 流れ 51% が上がるか。月末に効かなければ外す。結果: 成功。FreeTransport active=true(費用0)
- m01-4 南西に埋立地(4-4)。予想: ごみの印 15 が3月までに減る。結果: 部分実行。埋立地 id 7542 は置けた(4,000)。道路は test_build_line が、始点 (-620,-1802) でも (-620,-1807) でも埋立地 7542 との overlaps(幅80・長さ64)で断った。計画の中止条件に従い道路は引かず、取り壊しもしていない。埋立地は入口に道路がなく、働かない
- m01-5 焼却場の北に木(4-3)。予想: 5点の汚染平均 250 が下がるか。結果: 成功。20本を植えた(200)、26点は blocked。基準(植える前、(3600,-65) 半径60 n=5): 平均251、最小163、最大255
- m01-6 ホテル取り壊しと警察署(3-4、議決)。予想: 犯罪の印 3 → 1。結果: 失敗(未実行)。preview_bulldoze は 44162 の1棟、働き口0・家0。しかし m01-1 の送電線の確認のため advance(1) を呼んだ後に bulldoze を打ち、hook が「advance の後(臨時)は取り壊しを打たない」と止めた。警察署も置いていない。順序の誤りは実行する市長の側
- 調査: s01-1 貨物駅の枠待ち(port)、s01-2 観光客と Tourism の動き(economy)、s01-3 2280付近の止まり(roads)
- 週の収支の見込み: +9,965 → 約 +4,064(信号を取り下げた後。守る線 +3,000)。長期計画は council/plan-city.md
