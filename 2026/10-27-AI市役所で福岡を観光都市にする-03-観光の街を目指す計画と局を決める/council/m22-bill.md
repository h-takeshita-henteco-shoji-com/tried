# m22 まとめと議案

今月の局の案は7件(urban 2、roads 2、port 2、ほか案なし)。確認済みの5件から4件を採り、1件を条件付きで戻す。観光(5-1・5-2)は、economy が案なし、port の入口が実行条件なしで、今月も施策にならない。市長は代案を作らない。調査で、観光の手がかりを取る。

費用の見込み: 建設費 2,500。週の維持費の増え 約 -1,400(公園 +40、40031 の停止 -1,440)。週の収支は +5,957 から約 +7,360 の見込み(守る線 +3,000 の上)。所持金は約 2,641,300(守る線 1,874,000 の上)。

## 施策

### m22-1 放棄店 6208 の跡に公園 JapaneseGarden を置く

- 元にした局の案: urban-1。手直しした点: なし
- 議決: 取り壊し
- 採択理由: Beautification は 96 で目標 100 にあと4。放棄店 6208 と 24321 の取り壊しは、働き口0・家0(`test_place_building` の lostByDemolish)で、電気・水・下水が届き、入口の道路もある。
- 今月選んだ理由: 4-2 の安い手(建設費 2,500)が20月・21月と当たり続けている。損失0の候補が確認済みで、実行条件がそろう。
- 公約: なし(4-2 の数字のため。間接に人口)
- 市の計画: 4-2 花や緑による潤い
- 操作:
  1. `preview_bulldoze`(x=56, z=22, radius=12, what="building")で、壊すのが 6208 と 24321 だけ、失う働き口・家が0を確かめる
  2. `bulldoze`(x=56, z=22, radius=12, what="building")(議決のあと)
  3. `test_place_building`(prefab="JapaneseGarden", x=56, z=22, facing="east")が ok、入口の道路が Basic Road(segment 36249)を確かめる
  4. `place_building`(prefab="JapaneseGarden", x=56, z=22, facing="east", pay=true)
- 実行計画: 局の確認は、`test_place_building`(assume_removed_buildings=[6208])が ok、補正なし(angleUsed 270、入口 (72,22))。`water_trace` で electricity・water・sewage が true。予備候補B (1856,253)、facing north は、働き口5を失うので、使うときは市長が判断し、`water_trace` で水・電気を確かめてから。中止する条件: `preview_bulldoze` で働き口か家が1以上、`test_place_building` が断られる、(56,22) の電気か水が false。
- 費用: 建設費 2,500、週の維持費の増え分 40
- 予想: `buildings_near`(service=Beautification)の数が 96→97(22月末)。目標 100 には残り3(23・24月)。確認は `buildings_near`(x=56, z=22, r=50, service="Beautification", brief=true)。4-1 の地価への効きは見積もれない(20月の例で +1 程度)。
- 試し: なし
- ほかの局への響き: 放棄店の撤去で NoGoods 印が1棟減る見込み。働き口0・家0なので、人口と失業は動かない。維持費 +40 は小さい。
- 戻せるか: 戻せない
- 取り壊しのとき: 壊した後に失うものは、働き口0・家0(放棄店2棟、`test_place_building` の lostByDemolish)。壊さない代わりの手は、予備候補B(働き口5を失う)か、公園なし。放棄店は NoGoods・FatalProblem で機能しておらず、壊さない手に利点が見当たらない。

### m22-3 3叉路 (2236,-950) に信号を付ける(試し)

- 元にした局の案: roads-2。手直しした点: なし
- 議決: 要らない
- 採択理由: 上位の止まり (2302,-946) は blocked 75(地点の上位 51)。3叉路は信号も譲れもなく、`junction_info` で canEnableLights true。同じ型の信号は (2668,330) で blocked 53→0 と効いた。
- 今月選んだ理由: 止まり上位の地点で、道の差し替えは 36011(9m)が断るため、信号が唯一の確認済みの手。費用0で戻せる。分からないことの一覧の「信号で流れは動くか」の試しになる。
- 公約: なし(6-3 の数字のため)
- 市の計画: 6-3 公共交通を主軸とした交通体系
- 操作: `junction_info`(x=2236, z=-950)で canEnableLights true を確かめ、`set_traffic_lights`(x=2236, z=-950, active=true)
- 実行計画: node 5405、3区間(3334、36011、10391 すべて Basic)。予備候補なし((2280,-950) は人の信号が既にある)。中止する条件: 実行時に canEnableLights が false なら見送る。
- 費用: 建設費 0(局は道具の説明に記載なしとした。実行後の所持金で確かめる)、週の維持費の増え分 0(同上)
- 予想: `traffic`(x=2302, z=-946, r150)の blocked 75→50以下(22月末ではなく23月末)。効きの量は見積もれない。1車線の Basic 3334 の容量が上限なら効かない。
- 試し: 仮説は「無信号の3叉路が Basic 3334 からの合流を止め、(2280,-950) の信号の出口を詰まらせる」。測る数は `traffic` の blocked。場所は (2302,-946) r150。基準は 75(地点の上位 51)。分からないことの一覧の「道路の差し替えと信号で流れは動くか」(2050-02-01 の行)。この場所に、同じ月のほかの施策は重ねない。増えたら外す。
- ほかの局への響き: 信号待ちで上流の (2172,-917)、(2225,-1042) が増える恐れ。維持費が増えるかは未確認。
- 戻せるか: 戻せる(`set_traffic_lights` active=false)

## 採らなかった案

- urban-2: x=2200 の幹線沿いに木を植える(試し、4-1)。実行計画が「未確認」で、木を植える空きが道具で確かめられていない。木が騒音を弱めるかも未確認。種別: 条件付き。条件: 植える多角形の座標を、`net_near` と `buildings_near` で道路・建物と重ならない空きとして確かめ、40本以上の見込みを書く。
- port-2: 路線28の予算を 180%→200% に戻す(予算)。乗客が 110→53 に減ったが、92→29→110→53 と期間ごとに大きく揺れ、1期間の値で戻す根拠にならない。台数が約19増えて週 約+2,400 の維持費が出るが、その見積もりは粗い(他路線の台数を確かめていない)。予算を下げたとき流れは 53→55 に上がっており、戻すと流れの目標 60 から遠のく恐れ。種別: 条件付き。条件: `list_transport_lines`(number=28)で passengersLastPeriod が2期間続けて92未満であること、`economy_breakdown` の PublicTransportBus の支出と全路線の台数から 1台当たりの維持費を出し直すこと。
- 調査 health(汚染の帯の出どころ)、fire(48237 の経過)、finance(区127 の基準): 上限3件のため採らない。4-3 は目標 15 から遠いが施策の手がなく、3-4 は印が散らばる。finance の区127 は人口 2,693 で、税の試しの基準としての優先が低い。23月に出し直してよい。
- economy、health、education、fire、finance の施策: 案なし。局の役割から外れた判断ではなく、各局が実行条件の未確認や効きの測れなさを理由に挙げている。市長は代案を作らない。観光(5-1・5-2)は、economy が名所の場所を確かめられず、port が入口の道を引けず、22か月めも施策にならなかった。
