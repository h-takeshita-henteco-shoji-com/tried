# 道路下水道局の長期計画

## 目標(12か月後)

- 交通の流れ(traffic の flow): 52%(24月)→ 60%以上(6-3。港湾空港局と分け持ち)
- 電気・水・下水が来ない市民: 0 / 0 / 0 を保つ(3-3)
- 名所 11580 と公園 30466 の電気: 届いたまま。毎月見る(5-1、4-2)
- 旅客の入口の道と電線: 港湾空港局が駅を置いたら、つなぐ(5-1、5-2)

## 事業

### 事業1: 止まりの多い場所を、車線と信号で減らす(6-3)

- 狙い: traffic の blocked が多い場所を、同じ範囲で測って減らす
- 段階: 23月に (2082,-840) を4車線化と (3130,-490) の信号(外れ)。24月に、4車線化を戻す(やめる条件に当たる)。25月に、(1882,-903) の止まりが1車線の Basic 区間(26706、9422 など、x 1820〜1880)の詰まりか、上流の溢れかを見て、4車線にするか決める
- 費用の見込み: 建設費 0、週の維持費 0(Basic と Small 4 Lane は km 当たりの額が同じ)
- 求めること: なし
- やめる条件: 2回の測りで基準より増えたら、戻す

### 事業2: 名所 11580 と公園 30466 の電気を保つ(5-1、4-2)

- 狙い: 送電線の届きを保つ
- 段階: 18月に届きを確認(完了)。以後は毎月、印を見る(24月は印なし)
- 費用の見込み: 0(既存の線)
- 求めること: なし
- やめる条件: 電気が切れたら、枝を見直す案を出す

### 事業3: 旅客の入口に、道と電線をつなぐ(5-1、5-2。駅が置かれたら)

- 狙い: 旅客の入口を、外の道と電気につなぐ
- 段階: 駅が置かれた月に、建物が先、道が後で引く。電線 (3250,-1420)→(3237,-1293) は14月に test ok(320)
- 費用の見込み: 入口の道 約400(週 約3.2)
- 求めること: 港湾空港局に、旅客の入口の場所を求める
- やめる条件: 第24月末までに駅が置かれなければ、引かない(24月末も旅客の駅は0。未着手のまま閉じる)
