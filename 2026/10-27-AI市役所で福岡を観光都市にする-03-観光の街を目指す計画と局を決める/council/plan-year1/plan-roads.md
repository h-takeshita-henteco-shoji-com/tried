# 道路下水道局の長期計画

## 目標(12か月後)

- 交通の流れ(`traffic` の flow): 54%(11月)→ 60%以上(6-3。港湾空港局と分け持ち、主に道路下水道局が担う)
- 電気・水・下水が来ない市民(`city_info`): 0 / 0 / 0 を保つ(3-3)
- 旅客の入口と名所の道・水・電気(5-1、5-2 の材料)。場所は港湾空港局と経済観光文化局が決め、局は後から引く

## 事業

### 事業1: 残った blocked の場所を、信号か太くする手で抜く(6-3)

- 狙い: blocked が集まる交差点の待ちを減らし、流れを上げる
- 段階: 11月は交差点 (2280,-950) に信号を試した(案1)。12月は信号を残し、1区間を太くする(案2、10647)
- 費用の見込み: 信号は建設費 0(実測)。太くする1区間は建設費 200、週の維持費 +2 程度
- 求めること: なし
- やめる条件: 信号は、見回り1か2で同じ範囲(`traffic` の x 2290、z -950、r 150)の blocked が 72 より増えたら外す

### 事業2: 名所と旅客の入口に、道・水・電気を通す(観光の材料)

- 狙い: 観光の名所と入口が置かれた場所に、電気と水の網をつなぐ
- 段階: 置かれた月に引く(建物が先、道路が後)。名所 40850(1580,-530)は10月に送電線が通り、12月に道を東と南から引く(案1)
- 費用の見込み: 送電線 約280(済)。名所の道 約1,040。旅客の駅への道・水・電気は約2,100 以内(駅が決まってから)
- 求めること: 経済観光文化局に名所の場所、港湾空港局に駅の場所
- やめる条件: 12月末までに名所か駅が置かれなければ、引かない

## 計画の変更

- 11月: 9月の z=-560 の4車線化は戻さず続ける。理由: 11/7 の blocked(r300、基準66)は14で、戻す条件(2か月続けて増える)を満たさない
- 11月: (2310,-944) の4車線化は、この場所では不可と確認。理由: `test_upgrade_road` で、3334 は 36011 とぶつかり、36011 は 9m で TooShort。信号の試しに替える
- 11月: 10月の案(駅の接続、名所の送電線)は、駅と名所の建物がないため再提出しない。事業2の段階に従う
- 12月: 信号は残す。理由: 月末の r150 の blocked は 82(基準 72)だが、見回りは 0〜2 で、外す条件(見回りで 72 超)に当たらない
- 12月: 名所 40850 の道を、1手として優先する。理由: 10棟目が RoadNotConnected のまま、訪問が週 1 のため
