## 案1: 小学校 15301 を1校止め、維持費を減らす

### 施策

- 案の id: education-1
- 施策: 小学校 15301(-1350, -1076)を `set_building_active`(id=15301, active=false)で止める。止めると維持費と働き手が0になり、定員から348が減る。市の計画 2-3 の定員の目標(定員が子ども以上)は満たしたまま、週の維持費を下げる
- 議決: 要らない

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. 基準を記録する: `map_layer`(type=education_elementary, x=-1350, z=-1076, radius=300, n=5)。今の値は 最小63、平均176、最大290。最小の地点は (-1050, -776)

  3. 実行後に `services` を呼び、elementary の定員が 14,268 から 13,920 になったかを確かめる
  4. 実行後に、手順1と同じ引数で `map_layer` を呼び、最小が0になっていないかを確かめる
- 設置条件の確認: 建物を置かないため、敷地と道路の確認は不要。対象の確認は次のとおり
  - `buildings_near`(x=-1350, z=-1076, radius=30): id 15301、Elementary School、problems None、grid の electricity・water・sewage がすべて true、生徒 178 / 348
  - 近くの小学校 15022(-1350, -986、生徒 179 / 348)と 43936(-1370, -1350、生徒 181 / 348)に余裕がある。生徒 178 人はこの2校と 25802(-1010, -1350、213 / 348)で吸収できる見込み
  - 高校の定員は小学校と別の数なので影響しない(`services` の high 24,360 は変わらない)
- 接続工事: 不要
- 予備候補: 10396(-1190, -100、生徒 186 / 348)。近くの 4141(-1370, -100、200 / 348)と 7424(-470, -190、192 / 348)に余裕がある。使うときも、手順1と4の `map_layer` を同じ引数で取り、同じ条件で判定する。15022 は 15301 と 90m しか離れず、同じ区域を覆うため、予備にしない
- 中止する条件: 実行前に、`services` の elementary の定員が 14,268 でないとき、または `citizens_summary` の子どもが 11,000 を超えるとき(定員から348を引いた値が子どもの1.3倍を切る)は見送る。実行後に `map_layer` の最小が0になったとき、または `services` の定員が 13,920 にならなかったときは、`set_building_active`(id=15301, active=true)で戻す

### 期待する効果

- 改善の見込み: 2-3 の定員の目標は、1校止めても満たす(定員 13,920 ≥ 子ども 8,842)。効果は週の維持費の減少で、守る線の余裕を増やす。定員の目標の数字は動かさない(局の予測)
- 数値と期限: 週の維持費。今の値は `city_info` の weeklyExpenses 335,050(2051-03-07)。予想は週 -160(EducationBoost の25%分を含めて約 -200)。期限は16月の月末
- 確認方法: `services` の elementary(定員 14,268 → 13,920)、`city_info` の weeklyExpenses(335,050 からの差)、`citizens_summary` の子ども(8,842)との比(1.57)、手順1と同じ `map_layer` の最小(63 からの変化)
- 不確かな点: 止めた学校の生徒 178 人が近くの小学校に入るかは、道具で確かめるまで見積もれない。覆いの最小 63 の地点 (-1050, -776) は、15301 の覆いが抜けると下がるおそれがある。教育の質の変化は数値にしない。維持費の減少は、道具の数字(upkeepPerWeek 160)から見積もれる

## 判断の根拠

- 小学校の定員は 14,268、子どもは 8,842 で、定員は子どもの1.61倍。13月・14月と同じく1.3倍を超えており、長期計画の「超えが続けば1校止める」条件に当たる。止めた後の定員は 13,920(子どもの1.57倍)で、1.3倍を保つ。案1を出す
- 高校の定員は 24,360、10代は 19,442 で、余裕は 4,918。休止の条件(余裕1,000を切る)に当たらないので、高校は置かない
- 止める学校は、近くに余裕のある小学校がある 15301 を選んだ。生徒 178 人は 15022、43936、25802 の余裕(合計 約 470)で吸収できる見込み。覆いの最小 63 の地点は確かめ直す
- 案は1件にした。小学校は1校ずつ止める方針で、2校目は1か月置いて判断する

## 捨てたもの

- 小学校を2校同時に止める案: 長期計画の「1校ずつ」に反する。2校目は、1校目の結果を見てから判断する
