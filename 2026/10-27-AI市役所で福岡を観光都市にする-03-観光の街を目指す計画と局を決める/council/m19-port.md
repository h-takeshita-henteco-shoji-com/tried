# m19 港湾空港局の案

## 案1: 島Bに旅客の駅を置く(整地は市長に求める)

### 施策

- 案の id: port-1
- 施策: 島B(能古島とみられる)の北側の陸地、座標 (-4700,1600) に Train Station を南向き(angle 180)で1棟置く。入口の道は (-4700,1576) から (-4700,1552)、(-4640,1552) へ Basic Road で既存の道 13902 に接続する。水管と電線で電気・水・下水をつなぐ
- 議決: 要らない

### 実行計画

- 実行可否: 未確認
- 対象と操作順:
  1. (市長に依頼) `level_terrain`(test=true、polygon [[-4715,1545],[-4685,1545],[-4685,1585],[-4715,1585]]、height 71.5)で整地の費用を確かめ、問題なければ実行する。結果の raisedM3、loweredM3、cost を局に渡す。局の道具には level_terrain がないため、局では確かめられない
  2. `place_building`(prefab "Train Station"、x -4700、z 1600、angle 180、pay true)。入口は (-4700,1576)
  3. `place_building` の ports で駅の水・電気・下水のつなぎ口を確かめる
  4. `build_line`(prefab "Basic Road"、points [[-4700,1576],[-4700,1552],[-4640,1552]]、pay true)。整地を先に行う。端 (-4640,1552) は既存の道 13902 のノード 23669 に合わせる
  5. `build_line`(prefab "Water Pipe"、points [[-2715,215],[-3600,800],[-4500,1300],[-4700,1560]]、pay true)。最後の点は、手順3で得た駅の水のつなぎ口に合わせて直す
  6. `build_line`(prefab "Power Line"、points [[-4650,1500],[-4700,1560]]、pay true)。(-4650,1500) は送電線 22680 の電柱 15953 に合わせる。最後の点は、手順3で得た電気のつなぎ口に合わせて直す
- 設置条件の確認:
  - 駅: `test_place_building`(Train Station、(-4700,1600)、angle 180)ok。費用 45,000、入口 (-4700,1576)、入口の道は未設置で road null、壊れる建物 0(第19月の再調査でも同じ)
  - 駅のつなぎ口: `list_building_types`(service PublicTransport)の Train Station は ports が空。`buildings_near`(3490,-1555 r60)の既存の貨物駅 13893、28755 も ports が空。置く前に、つなぎ口の座標は道具で得られない
  - 道: `test_build_line`(Basic Road、[[-4700,1576],[-4700,1552],[-4640,1552]])は整地なしで ok だが gameCheck に SlopeTooSteep(区間1)。整地(level 71.5)を仮定すると ok、警告なし、費用 440、重なり 0(第19月)
  - 水管: `test_build_line`(Water Pipe、[[-2715,215],[-3600,800],[-4500,1300],[-4700,1560]])ok、32区間、費用 6,200、重なり 0(第19月の再調査でも同じ)。ただし終点 (-4700,1560) は駅の敷地から約40m南で、駅のつなぎ口ではない
  - 電線: `test_build_line`(Power Line、[[-4650,1500],[-4700,1560]])ok、1区間、費用 200、重なり 0(第19月の再調査でも同じ)。終点 (-4700,1560) は同じく駅の敷地の外
  - 電気: `buildings_near`(4700,1600 r250)で、近くに風力発電 44460(-4660,1440)があり、電気の元になる
  - 道の網: `net_reach`(-4700,1560 r300)で、道の 9 区間は、つなぎ口から入れず、出られない区間は 0
  - 地面: 整地前の (-4700,1590) は 81.1 m(第19月に `height_at` で確認)
- 再調査の結果: 条件を満たせなかった。(a) 整地の費用は、局の道具に level_terrain がなく確かめられない。市長の試しの結果が来るまで未確認。(b) 駅のつなぎ口(水・電気・下水)は、置く前に道具で得られない(ports が空)。水管と電線の終点を候補の座標で ok にしても、それが駅のつなぎ口に当たるかは確かめられない。置いてから確かめる形は、事前確認の代わりにならない
- 接続工事: 道(Basic Road、整地が前提)、水管、電線。合計 6,640。整地の費用は市長の試しで確かめるまで未確認
- 予備候補: なし。島Bの別の位置や向きでも、駅のつなぎ口を置く前に得られない点は同じ。ほかの候補を出すなら、この点を解く手(つなぎ口の座標を道具で得る方法)が要る
- 中止する条件:
  - 市長の `level_terrain` 試しが断る、または整地の費用で週の収支や所持金が守る線(週の収支 +3,000、所持金 1,874,000)を割る
  - 手順3の駅のつなぎ口が、水管 (-4700,1560) や電線 (-4700,1560) と離れ、接続線を引き直せないとき
  - 第19月末までに整地の結果が来ないとき(調整16)

### 期待する効果

- 改善の見込み: 旅客の駅が1棟あれば、観光の入口(5-1、5-2)の数が 0 から 1 になり、経済観光文化局の求めを満たす。島Bは電気・水・下水が届くので、駅の網は届く見込み。ただし、観光客が駅から入ってくるかは、駅の外へのつながり(transport_reach)を置いてから確かめる
- 数値と期限: 旅客の入口(`buildings_near` で Train Station の棟数)。今の値 0。予想 1。第21月末までに確かめる。観光客への効きは見積もれない
- 確認方法: `buildings_near`(x -4700、z 1600、radius 200)で棟数。`transport_reach` で外へのつながり。`city_info` の観光客と `economy_breakdown` の Tourism を、第19月の基準(1,795、週61)と比べる
- 不確かな点: (a) 整地の費用は局の道具で確かめられず、市長の試しを待つ。(b) 駅のつなぎ口は置いてからしか分からない(ports が空)。(c) 駅が外とつながるかは未確認。(d) 観光客が増えるかは分からない
- 試し: なし(入口の数は置けば確かめられる。効きは、置いたあとに別に測る)

## 判断の根拠

- 旅客の入口は、島Bの駅を1つ置く形だけが残っている。港の候補は、置ける場所がすべて断られた。島Bの駅は、置く試しが ok。道の斜面は整地を仮定すると通り、水管と電線も通る。
- 再調査の条件は2つ。(a) 整地の費用は局の道具にないため、市長の試しの結果を待つ。(b) 駅のつなぎ口は、list_building_types と buildings_near の ports が空で、置く前に得られない。水管と電線の終点を候補の座標で ok にしても、駅のつなぎ口に当たるかは確かめられない。(b) は、試しの道具では解けない
- したがって、案は未確認のまま残す。実行可否は確認済みにできない。市長が採るかは、(a) の結果と、(b) の扱いを見て決める
- 8-1 の2つ目の貨物センターは、試しが ok でも、隣の 13893 に列車が1本も来ないため効果が見込めない。13893 の原因を調査で見る
- 調査は1件。施策の案は、実行できる形の1件だけにする。残りの候補は実行条件が確認できないので出さない
- 週の収支は +7,740 から、案1の維持費 約991 を引いても守る線(+3,000)の上に残る。所持金 2,555,946 から建設費 51,840 を引いても守る線(1,874,000)の上
