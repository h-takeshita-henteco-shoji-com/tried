# m08 財政局の案

## 案1: 政策 Recycling を有効にし、公園の予算を 140 にする

### 施策

- 案の id: finance-1
- 施策: 政策 Recycling を有効にする(ごみ -15%、住宅税の収入 -5%)。公園(parks)の予算を 150 から 140 にして、住宅税の減りを補う。事務所の税は触らない。場所の指定はなし(街全体)
- 議決: 予算

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: (1) `economy` で parks の day と night が 150 であることを、実行直前に確かめる。`city_info` で週の収入から支出を引いた額(今 16,355)を確かめる。(2) `set_budget(target="parks", day=140, night=140)`。(3) `economy_breakdown` で Beautification の週の支出が 7,212 から約 6,731 に下がったかを見る。(4) `list_policies` で Recycling が active=false、costPerWeek 0 であることを確かめ、`set_policy(name="Recycling", active=true)`。(5) `city_info` で週の収入から支出を引いた額が 3,000 以上か確かめる。
- 設置条件の確認: 該当なし(建設なし)。`list_policies` の一覧に Recycling があり、costPerWeek 0 を確認済み(今月)。`economy` の budget に parks(day 150、night 150)がある。`tool-reference.md` で set_budget の target に parks、set_policy の name に政策名があることを確認済み。
- 接続工事: 不要
- 予備候補: なし。道路の予算 120 → 100(約 -1,483/週)で補う案は、交通の流れ 56%(目標 60)を悪くするおそれがあり、計画の保留に当たるので使わない。
- 中止する条件: (a) `set_budget` か `set_policy` が断る、または Recycling の costPerWeek が 0 でない。(b) (1)〜(4) の後の `city_info` で、週の収入から支出を引いた額が 3,000 未満なら、同じ月のうちに `set_policy(name="Recycling", active=false)` で Recycling を外す。(c) (3) で Beautification の支出が 7,212 から下がらなければ、補いが効いていないので、Recycling を外す。

### 期待する効果

- 改善の見込み: 4-4 資源循環のごみの印を減らす見込み。Recycling の説明は、ごみを15%減らすとしている。確認した事実は、ごみの印 23(hotspot (-580,-1307))、埋立地は満杯0、ごみの使用は 77,785,610 / 160,000,000。ごみの量が減れば、収集の負荷が減る、と局は見る(未確認)。公園の予算の減りは、週の収支を守るための補いで、4-4 には当たらない。
- 数値と期限: 測る円(x 1000、z -600、半径 1280)の中のごみの印は、今 8(7月末)。この円は、m08-4 の埋立地の円(x -700、z -1180、半径 500)の外にある(中心どうしの距離 約 1,796m。円どうしの隙間 約 16m)。減る量は数値で見積もれない(ごみの量と印の関係が未確認)。確かめる期限は次の月例(9か月目、2050-08-30 ごろ)。週の収支は、見込み約 +3,425(税の -13,411 と予算の +481 の合計)。
- 確認方法: `buildings_near`(x 1000、z -600、radius 1280、problem "Garbage"、brief true)の total、`services`(garbage の used)、`city_info`(週の収入と支出)、`economy_breakdown`(Residential、Beautification)。見回り1、見回り2、月末に、同じ道具と同じ引数で測る。基準は7月末の値(円の印 8、garbage の used 77,785,610、週の収支 16,355)。
- 不確かな点: (1) Recycling の -15% が、円の中の印の数にどれだけ効くかは、数値で見積もれない。(2) 住宅税の -5% は局の見込み(収入 268,229 の 5%)。実際の減りは `economy_breakdown` で確かめる。(3) 公園の予算の減りが、公園の効き(地価、幸福)にどれだけ響くかは未確認。4-1 の地価の平均を見るだけにする。(4) 週の収支の見込み +3,425 と守る線 3,000 との余裕は約 425 と小さい。
- 試し: 試し。仮説: Recycling の garbage -15% が、ごみの量を減らし、円の中のごみの印を減らす。測る数: `buildings_near`(problem "Garbage"、円 x 1000、z -600、半径 1280)の total と、`services` の garbage の used。場所: 円の中(m08-4 の円の外)。基準: 円の印 8、garbage の used 77,785,610(7月末)。編成方針の分からないことの「ごみの印が 8→23 に増えた原因」に当たる。

### 費用

- 建設費: 0
- 週の維持費の増え分: 政策の直接の費用は 0(`list_policies` の Recycling の costPerWeek 0)。公園の予算 150 → 140 で、Beautification の週の支出は 7,212 から約 6,731 に減る見込み(約 -481。支出が予算に比例すると局は見る。確かめは `economy_breakdown`)。住宅税の収入の減りは約 -13,411/週(268,229 の 5%、局の見込み)。合わせて週の収支は 16,355 から約 3,425 の見込み。

### 戻せるか

戻せる。`set_policy(name="Recycling", active=false)` と `set_budget(target="parks", day=150, night=150)` で戻せる。

### 再調査の結果

- 条件1(事務所税を使わない): 満たした。補いを公園の予算に替えた。事務所の税は 3 のまま。6-1 と m07-4 の測りは触らない。
- 条件2(補いの効きがゼロでも週の収支 +3,000 以上): 補いは支出の減り(公園の予算)で、住宅税の減りは 13,411。`economy_breakdown` の数字では、補いなしの見込みは 2,944 で、守る線を割る。公園の予算の減りを足すと約 3,425 で、守る線の上に残る。予算の減りは、サービスの効きとは別に、支出の式で決まる額。ただし、これは見積もりで、実行直前に Beautification の支出で基準を確かめ、下がらなければ中止する(中止する条件 c)。

## 判断の根拠

週の収支は 16,355 で、守る線 3,000 との差は 13,355。EducationBoost の判定は、戻す条件に当たらないので続ける。重点3の 4-4 に効く手は、今は政策 Recycling だけが確認できた。Recycling だけでは週の収支が約 2,944 となり、守る線を割る。前の版は事務所税 +1 で補ったが、事務所の税は m07-4 と 6-1 の測りに重なり、補いの効きがゼロなら守る線を割るため、市長が差し戻した。今回は、補いを公園の予算 150 → 140(約 -481/週)に替えた。これで見込みの週の収支は約 3,425 となり、守る線の上に残る。公園の予算は 4-2 の棟数に効かないので、重ならない。ごみの測る円は m08-4 の埋立地の円の外に取った。案は1件、議決は予算の1種類。調査は、ごみの印が収集車の詰まりか量かを分けるため、1件を出す。
