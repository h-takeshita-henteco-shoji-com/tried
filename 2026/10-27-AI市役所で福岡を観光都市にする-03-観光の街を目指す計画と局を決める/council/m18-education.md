### 実行計画

- 実行可否: 確認済み
- 対象と操作順: 1) 実行前に `services`(小学校の定員 13,572)と `citizens_summary`(子ども 8,929)を見る。定員から 348 を引いた値が子どもの1.3倍以上かを確かめる。2) `set_building_active`(id 25802、active false)。3) 止めたら `map_layer`(type education_elementary、x -1010、z -1350、radius 400、n 9)と `map_layer`(type education_elementary、x -1370、z -1350、radius 400、n 9)を見る。基準は、25802 の窓で 0 の点が1つ(-610,-950 の東の端)、43936 の窓で最小 3
- 設置条件の確認: 対象は既存の小学校で、建設はない。`buildings_near`(Education、x -1100、z -1200、r 900)で、25802 が problems None(稼働中)、grid の電気・水・下水が true、生徒 227/348。停止のための道具で、敷地と道路の条件は要らない
- 接続工事: 不要
- 予備候補: なし。15022(-1350,-986)は 15301 と同じ地区で覆いを重ねて減らすため使わない。43393(-1170,-1828)は SW 角の覆い(43936 窓の最小 3)に効くと見て使わない
- 中止する条件: 実行前に、定員(13,572 - 348 = 13,224)が子どもの1.3倍(11,608)を下回るなら見送る(今は1.48倍)。実行後、25802 の窓か 43936 の窓に、基準より多い 0 の点が出たら、新しい 25802 を先に `set_building_active`(true)で戻す。なお 0 が残るなら 43936 も戻す

### 期待する効果

- 改善の見込み: 2-3 の小学校の定員は子どもを上回ったままで、目標は既に満たしている。止めた分で週の維持費を減らし、財政の余裕を少し広げる。効果は小さい
- 数値と期限: 小学校の維持費が週 -160(EducationBoost 込みで約 -200)。定員と子どもの比は 1.48(今 1.52)。期限は19月末
- 確認方法: `services`(elementary の定員)、`citizens_summary`(child)、`map_layer`(education_elementary)の2つの窓。今の値は、定員 13,572、子ども 8,929、25802 の窓で 0 の点1、43936 の窓で最小 3
- 不確かな点: 覆いは学校ごとの寄与を返さないため、0 が出ても 25802 と 43936 のどちらの停止かを切り分けられない。両方の窓が重なるため、0 が出たら新しい方から戻す。週の維持費の減りは、ほかの施策と混ざった週の収支では数えにくい。数値は見積もれない(維持費は道具の値で確定)
- 試し: あり。仮説: 25802 を止めても、ほかの小学校の覆いで足り、窓に新しい 0 は出ない。測る数: `map_layer`(education_elementary)の2つの窓の最小と 0 の点数、`services` の小学校の定員、`citizens_summary` の子ども。場所: 25802 と 43936 の周り(半径400m)。基準: 25802 の窓で 0 の点1、43936 の窓で最小3。編成方針の「分からないこと」には載らない。17月の 43936 の試しの続き
