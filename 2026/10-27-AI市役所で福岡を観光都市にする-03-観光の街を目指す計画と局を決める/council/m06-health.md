## 案1: 政策 SmokingBan を有効にして健康を試す

### 施策

- 案の id: health-1
- 施策: 全市に政策 SmokingBan を有効にする(`set_policy` name="SmokingBan" active=true)。健康(市の計画 1-2)の試し。
- 議決: 要らない

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: `set_policy`(name="SmokingBan", active=true)を1回。実行の前に `list_policies` で SmokingBan が active=false、costPerWeek=0 であることを確かめる。
- 設置条件の確認: 該当なし(政策で、建物と線は使わない)。`list_policies` は 2050-05-31 に確認: SmokingBan active=false、costPerWeek 0、costBasis「no direct cost」。
- 接続工事: 不要
- 予備候補: なし(政策は場所を使わない)
- 中止する条件: 実行の前に SmokingBan が active=true になっている、または costPerWeek が0より大きくなっていたら見送る。政策の変更は月に1件までなので、同じ月に別の政策を採っていたら実行しない。

### 期待する効果

- 改善の見込み: 健康の平均は 79 のまま。SmokingBan で体調の悪い市民が減れば、健康の平均が上がると予想する。確認した事実は、体調の悪い市民が1,700(`citizens_summary` の badHealth)、健康の平均が79(同)。効きの量は見積もれない。
- 数値と期限: 健康の平均 79 → 80 以上。期限は 2050-07-01(7月の初め)。
- 確認方法: `citizens_summary` の average.health と peopleWithProblems.badHealth を、今月末の値(79、1,700)と同じ道具・同じ項目で比べる。
- 不確かな点: 効きが出るかは未確認。政策の効きは、ゲームの数字で測るしかない。健康は、ほかの理由(汚染、ごみ、診療所)でも動くので、政策だけの効きとは言い切れない。
- 試し: 仮説は「SmokingBan が体調の悪い市民を減らし、健康の平均を上げる」。測る数は `citizens_summary` の average.health と badHealth。場所は全市。基準は 健康 79、badHealth 1,700(2050-05-31)。判定は7月初め。編成方針の「分からないこと」のどれにも当たらず、市の計画 1-2 の試し。

### 費用

- 建設費: 0
- 週の維持費の増え分: 0(`list_policies` の costPerWeek 0)

### 戻せるか

戻せる。`set_policy`(name="SmokingBan", active=false)で外せる。

5月の案 m05-health-1(SmokingBan を試す)は、政策の変更の上限(月1件)で採られなかった。今月の案1で出し直す。手当て: 今月の政策の変更は、この案だけにする。

- 編成方針の重点に当たるか: 当たらない

- 議決: 要らない(`empty_building` は議決の表にない)

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: (1) `empty_building`(id=48698, active=true)を1回。(2) 次の月例、または `services` の garbage.full.count が 0 になったのを確かめてから、`empty_building`(id=48698, active=false)で戻す。

- 接続工事: 不要(空にするだけで、建設しない)
- 予備候補: なし(空にできなければ、取り壊しの議案にはしない。見送る)

### 期待する効果

- 改善の見込み: 満杯の埋立地 1 → 0 は、確かめた事実(`services` の full.count 1)を直接減らす。ごみの印への効きは量を見積もれない。48698 の周りにごみの印の建物があるかは、今月は確かめていない。
- 数値と期限: garbage.full の count 1 → 0 を、2050-06-30 までに。ごみの印は 17 のまま、目標 0 に向けて確認する。
- 確認方法: `services` の garbage.full.count と ids、`complaints` の Garbage の buildings(17)。今月末の値と同じ道具・同じ項目で比べる。
- 不確かな点: ごみの印は、満杯の埋立地の数だけで決まらない(焼却場の貯蔵と収集車にも左右される)。ごみの印が動くかは、今月は見積もれない。
- 試し: なし
