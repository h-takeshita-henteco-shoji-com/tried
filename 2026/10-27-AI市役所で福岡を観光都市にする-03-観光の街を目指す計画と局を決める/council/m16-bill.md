### m16-3 焼却場 2267 を止め、汚染の印を減らす(試し)

- 元にした局の案: health-1。手直しした点: なし
- 議決: 要らない
- 採択理由: `complaints` の Pollution が 21 で目標 15 以下に6足りない。2267 の近くの住宅 31499 に Pollution の印があり、m02-3 では同じ停止で 45→35 に減った。garbage.full 0、Garbage 4、東の埋立地 39575 は 7% で、電気も容量 2,318,624 に対し使用 1,707,040 で余る。
- 今月選んだ理由: 分からないことの一覧に「汚染の印の出どころ」が残り、試しを1件採る決まりに合う。費用が 0 で、週の維持費が減り、いつでも戻せる。
- 公約: 3(維持費の減り)。計画の 4-3
- 市の計画: 4-3 脱炭素社会(副次で 4-4 資源循環のごみの印)
- 操作: 1) `services` で garbage.full が 0、`complaints` の Garbage が 9 以下であることを実行直前に確かめる。2) `set_building_active`(id 2267、active false)。3) 見回り1・2・月末に `complaints`(Pollution、Garbage)、`services`(garbage、electricity)、`map_layer`(pollution、x 3650、z -50、radius 300)を測る
- 実行計画: 接続工事は不要。予備候補はなし。中止する条件(戻す手は `set_building_active`(id 2267、active true))は、(1) 見回りか月末で Garbage が 15 を超える、(2) electricity の used が capacity を超える、または citizensWithoutService の electricity が 0 より増える、(3) garbage.full が 1 以上になる
- 費用: 建設費 0、週の維持費の増え分 約 -1,440(局の見積もり。実行後に `city_info` で見る)
- 予想: Pollution 21 → 11〜15(月末)。Garbage 4 → 8〜10(上限 15)。量は見積もれない(前例 m02-3 の -10 と +11 から)。不確かな点は、15 MW が外れたときの電気の余裕
- 試し: あり。分からないことの一覧の「汚染の印の出どころ(hotspot (3696,-10) の住宅11棟)」。仮説: 2267 の煙が近くの住宅の汚染の印を出し、止めると減る。測る数: `complaints` の Pollution 件数と、`map_layer`(pollution、中心 (3650,-50)、radius 300)の平均。場所: 2267 の周り (3604,-30) の半径 300。基準: Pollution 21(2051-04-06)。平均は止める前に測る。同じ場所に、同じ月のほかの施策は重ねていない
- ほかの局への響き: ごみの印が 4 から増える(4-4 の目標 0 から遠ざかる)。上限 15 で戻す。電気は余裕がある見立て
- 戻せるか: 戻せる
- 取り壊しのとき: 該当なし

### m16-4 政策 FreeTransport を有効にする(試し)

- 元にした局の案: finance-1。手直しした点: 測る数の主軸を、`list_transport_lines`(type=bus)の passengers と passengersLastPeriod にした。`traffic` の flow は参考に記録する。m16-2 の信号が r100 の局所で流れに混ざるため
- 議決: 要らない(政策は議決の種類に入らない)
- 採択理由: 流れ 53%(目標 60)、止まった車 862、渋滞の印 2,292。バスの運賃収入は週 4,796 だけで、無料にしても週の収支 +12,150 は約 +7,354 に残り、守る線 +3,000 に余裕がある。
- 今月選んだ理由: 分からないことの一覧の試し枠として、費用が運賃収入の減りだけで、戻せる。m16-3 とは場所も測る数も別。
- 公約: 3(収支の黒字を保つ範囲)。計画の 6-3
- 市の計画: 6-3 公共交通を主軸とした交通体系
- 操作: 1) 実行直前に `economy_breakdown` で PublicTransport の収入が約 4,796/週であることを確かめる。2) `set_policy`(name "FreeTransport"、active true)。3) `list_transport_lines`(type bus)で基準の passengers を実行直後に記録し、見回り1・2・月末と第17月の月例で比べる
- 実行計画: 接続工事は不要。予備候補はなし。中止する条件は、`set_policy` が断った場合、運賃収入が約 4,796 から大きく違う場合、週の収支の見込みが +3,000 を割る場合。戻す手は `set_policy`(name "FreeTransport"、active false)
- 費用: 建設費 0、週の維持費の増え分 0。運賃収入が週 約 4,796 減る
- 予想: 効きの量は見積もれない。乗客の数(passengers)が実行直後より増えるか、交通の流れ 53% が上がるかを、第17月の月例で判定する。不確かな点は、1か月では信号や道路の工事の揺れと分けにくいこと
- 試し: あり。分からないことの一覧のうち、6-3 の効きに当たる(信号 (-1640,-1010) の blocked 26→9 が信号の効きかも関わる)。仮説: 運賃が 0 になると公共交通の利用が増え、車が減って流れが上がる。測る数: `list_transport_lines` の passengers(バス全路線)。参考: `traffic` の flow と blocked。場所: 街全体のバス路線。基準: 実行直後の passengers と flow 53%。担当の数字の範囲: 週の収支(費用の確認)
- ほかの局への響き: 週の収支 -約 4,796。交通の流れは m16-2 の信号も混ざるので、判定は乗客の数を主とする
- 戻せるか: 戻せる
- 取り壊しのとき: 該当なし
