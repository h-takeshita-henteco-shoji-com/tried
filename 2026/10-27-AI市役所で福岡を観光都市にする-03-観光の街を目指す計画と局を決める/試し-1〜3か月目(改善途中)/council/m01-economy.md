# m01 経済観光文化局の案

## 案1: 観光の政策 Recreational Use を有効にする

### 施策

- 案の id: economy-1
- 施策: 街全体に政策 Recreational Use をかける(対象は街全体。場所の指定なし)。観光客と名所の効き目を、測る数で確かめる試し
- 議決: 要らない

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: `set_policy(name="RecreationalUse", active=True)` を1回。戻り値の費用見積もりを確かめ、0なら実行する
- 設置条件の確認: 該当なし(政策。`list_policies` で、名前 RecreationalUse、有効状態 false、costPerWeek 0、costBasis「no direct cost」を確認)
- 接続工事: 不要
- 予備候補: なし。政策の変更は月1件なので、代わりの政策は今月使わない
- 中止する条件: `list_policies` で RecreationalUse が見つからない、または週の政策費用が 0 から増えたら見送る。週の収支が +3,000 を切るおそれがあれば見送る

### 期待する効果

- 改善の見込み: 観光の5つの数字(観光客、訪問、Tourism の収入、attractiveness、名所)のうち、観光客と Tourism の収入を上げる見込み。一覧の説明は効果の実測値ではないため、見込みは予想として書く。政策の効き方の量は見積もれない
- 数値と期限: 今いる観光客 1,646、訪問の平均 139、Tourism の週の収入 45、attractiveness の平均 6。期限は2050-01-31(月末の見回り後)
- 確認方法: `city_info` の tourists(now、visits)、`economy_breakdown` の Tourism の income、`map_layer`(type=attractiveness、n=9)の average。街全体で、今と同じ条件で比べる。urban と finance も同じ範囲で同じ数を測る(調整A)
- 不確かな点: 政策の効き方は未確認。効果が出ない場合でも、費用は0なので戻せる。数値は見積もれない
- 試し: 仮説は「Recreational Use が名所と観光地の魅力を上げ、観光客が増え、観光の収入が上がる」。測る数は上の4つ。場所は街全体。基準は今の値(1,646 / 139 / 45 / 6)。編成方針の重点1(観光)の「効き目が分からない」項目に当たる

### 費用

- 建設費: 0(政策)
- 週の維持費の増え分: 0(`list_policies` の costPerWeek 0)

### 戻せるか

戻せる。政策の解除(`set_policy(name="RecreationalUse", active=False)`)で元に戻せ、費用は残らない。

### 前の月の答え合わせ

なし(1か月目)

## 判断の根拠

- 観光の5つの数字は、どれも目標から遠い(観光客 1,646 → 3,000、Tourism 45 → 1,000、attractiveness 6 → 12、名所 6 → 10)。担当の重点はこれに当たる
- 名所の追加が本命だが、街の中心は道路と住宅が詰まり、12マスの名所を置ける空きがない。中心の放棄された店を取り壊す案も、道路と建物が重なり置けなかった。北西の空き地の公園2棟は、置く場所は確かめられたが、水道管・下水管・送電線の接続(約 250m 級)が未確認のため、今月の案にはできない。接続を確かめる手は2月の試しに回す(調整C)
- 観光の政策は、費用0で戻せ、今月の政策の変更の1件に当たる。一覧には観光に直接効く名前の政策がなかったが、Recreational Use の効き方は未確認。試しとして、測る数を決めて出す
- 品物がない店 228 は観光の収入を止めている。貨物駅 28755 の出口の詰まり(492 台が建物の中で止まる)は港湾空港局の調査(調整B)。経済観光文化局は、hotspot の店が貨物駅以外の道から荷を受けるかだけを見る
- 案の数は1件にした。ほかの候補は、接続や場所の未確認、または政策の上限(月1件)で出せなかった
