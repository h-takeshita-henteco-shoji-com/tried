# 港湾空港局の長期計画

## 目標(12か月後)

- 5-1、5-2(入口): 旅客の駅・港・空港 0 → 1以上(`buildings_near` の service=PublicTransport)
- 8-1: 駅・港の敷地の中で止まったトラック 506 → 250以下(`cargo` の stoppedInBuildings。3月末は514。事業3は止めたので、見るだけ)
- 6-3: 交通の流れ 51% → 60%以上(`traffic` の flow。3月末は56%)

## 事業

### 1. バス路線の台数の見直し(6-3)

- 狙い: 乗客に比べて多い路線の台数を半分にし、道の車と維持費を減らす
- 段階: 1月に5路線(28、38、39、37、11)の予算を下げた(済)。3月末の流れは56%で、1月の51%から上がった。5路線の乗客は、今の値で118(前の集計は79)。流れが上がった原因は、まだ分からない。8〜12月に、60%に届くまで台数を調整する
- 費用の見込み: 週の維持費は下がった(約2,400減の見込み。道具で未確認)
- 求めること: なし
- やめる条件: 乗客が大きく減り、流れも上がらないとき、予算を戻す

### 2. 旅客の駅(5-1、5-2 入口)

- 狙い: 旅客の駅を1つ置き、観光の入口を0から1にする
- 段階: 3月に案(port-1)。4月に置く(調整I)。順番は駅、線路、道路、電気、水道管。置いた後の4月に `transport_reach` で外とつながるかを確かめ、つながらなければ入口に数えない。戻し方は案の「戻し方」(まず `set_building_active` で止める)
- 候補: 駅 (3300,-1640) 南向き。線路 (3312,-1640)→(3390,-1655)→(3471,-1680)。道 (3300,-1664)→(3275,-1655)→(3275,-1620)→(3400,-1625)。電気 (3311,-1293)→(3300,-1640)。水道管 (3455,-1555)→(3300,-1640)
- 費用の見込み: 建設費 約48,440、週の維持費 約1,010増(上限 100,000 / 1,920 の内)
- 求めること: なし
- やめる条件: 4月に置く前の試しが断られたら、置かずに見送る

### 3. 貨物駅28755の混雑(8-1)

- 狙い: 駅の出口で空き待ちのトラックを減らす
- 段階: 3月に止めた。道は原因ではなく、隣の13893は0台。原因は分からないまま
- 費用の見込み: 0
- 求めること: なし
- やめる条件: 止めた
