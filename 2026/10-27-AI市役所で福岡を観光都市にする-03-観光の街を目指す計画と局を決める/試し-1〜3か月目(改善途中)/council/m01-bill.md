### m01-1 放棄された店の跡に広場を置く(1850,-150)

- 元にした局の案: urban-1。手直しした点: なし
- 議決: 取り壊し
- 採択理由: 4-2 の Beautification は 81 で、目標 100 に 19 足りない。`test_place_building` が通った候補は(1850,-150)だけで、失うのは家 1 と放棄された店 1 棟。
- 今月選んだ理由: 確認済みの置き場が今月はここだけで、費用は 2,500 / 週 32 と小さい。ほかの候補は働き口か家を増やして失うため採らない。
- 公約: 1(人口)に小さく響く。家 1 を失う。4(観光)は広場の attractiveness を測る材料にする
- 市の計画: 4-2 花や緑による潤い(主)、4-1 都市と自然が調和したコンパクトなまち(副)
- 操作:
  1. `land_value`(x=1850, z=-150, radius=200)と `map_layer`(type=attractiveness, x=1850, z=-150, radius=200, n=5)で基準を測る(地価 62、attractiveness 19)
  2. `preview_bulldoze`(x=1862, z=-152, radius=22, what="building")。想定は 5113 と 14155 の2棟だけ
  3. 議決のあと `bulldoze`(x=1862, z=-152, radius=22, what="building")
  4. `test_place_building`(prefab="Regular Plaza", x=1850, z=-150, facing="east")
  5. `place_building`(prefab="Regular Plaza", x=1850, z=-150, facing="east")
  6. `buildings_near`(x=1850, z=-150, radius=30)で electricity を見る
- 実行計画: 局が `test_place_building`(assume_removed_buildings=[5113, 14155])で ok、入口の道路 segment 21007(距離2)を確認済み。予備候補はない。中止する条件は、議決が通らない、直前の `preview_bulldoze` が2棟より増える、`test_place_building` が断る、置いた後の electricity が false、のどれか。
- 費用: 建設費 2,500、週の維持費の増え分 32
- 予想: `buildings_near`(service=Beautification)の数が 81 から 82 になる(1月末)。2月に `land_value`(x=1850, z=-150, radius=200)の平均が基準 62 より2以上上がれば効きありとする。量は見積もれない。
- 試し: なし
- ほかの局への響き: 家 1 を失う(人口は 178,872 の 0.001% 未満)。経済観光文化局の試し(economy-1)は街全体の attractiveness を測る。広場は半径200だけで、街の平均への響きは小さい。経済観光文化局は、広場の周りだけ別に読む。
- 戻せるか: 戻せない(取り壊し)
- 取り壊しのとき: 壊した後に失うものは、住宅 1 棟(家 1 世帯)と放棄された店 1 棟(働き口 0)。`preview_bulldoze` で確認済み。壊さない代わりの手は、働き口 35 を失う店か、家 2 を失う住宅を壊す候補で、失うものが大きい。何も置かない手は、4-2 が 81 のままになる。

### m01-3 バス路線5本の台数を半分にする(試し)

- 元にした局の案: port-1。手直しした点: 判定に (-1056,-1100) 周りの `traffic` を足した(m01-2 との重なりを分けるため)
- 議決: 予算
- 採択理由: 路線 28、38、39、37、11 は、台数が 36〜186 台で乗客が 6〜58(期間の値)。台数が乗客に比べて多い。台数を減らすと、道の車が減り、バスの維持費(PublicTransportBus 週 22,051)も減る。
- 今月選んだ理由: 建設も取り壊しもなく、戻せて、週の収支を約 2,400 改善する見込み。6-3 を動かす確認済みの手が、これと m01-2 の2つだけ。
- 公約: 3(赤字を続けない)に良い方向。1(人口)への害はない見込み
- 市の計画: 6-3 公共交通を主軸とした交通体系
- 操作: `set_transport_line_budget` を次の順に呼ぶ。
  1. line=136(路線28)、percent=100
  2. line=139(路線38)、percent=100
  3. line=21(路線39)、percent=100
  4. line=127(路線37)、percent=100
  5. line=200(路線11)、percent=50
- 実行計画: 局が `list_transport_lines` で 5 路線の line、台数、乗客を確認済み(pathFailed 0)。予備候補はない。中止する条件は、議決が通らない、呼んだ後の targetVehicles が半分程度に下がらない、のどちらか。
- 費用: 建設費 0、週の維持費の増え分 約 -2,400(減る。概算で、実際の額は月末の `economy_breakdown` で確かめる)
- 予想: `traffic` の flow が 51% から 52% 以上に上がる。止まり車 1,008 が減る。5 路線の合計約 221 台が減る。確認は見回り2(20日目)と月末(30日目)。上がり幅は見積もれない。バスが混みの原因か未確認なので、上がらないこともある。
- 試し: 仮説は「バスの空走が道の車を押し出し、台数を減らすと流れが上がる」。測る数は `traffic` の flow(街全体)と busiest の混み具合、`list_transport_lines` の 5 路線の passengersLastPeriod。場所は街全体と、(-1056,-1100) の周り(半径300)。基準は flow 51%、blocked 1,008、乗客は路線28 が 34、38 が 5、39 が 16、37 が 41、11 が 11。流れが52%以上に上がり、乗客の減りが小さければ続ける。上がらなければ戻す。
- ほかの局への響き: 観光客もバスに乗るので、観光客の移動が少し悪くなるかもしれない。経済観光文化局は、観光客の数(m01-4 の測り)と合わせて読む。
- 戻せるか: 戻せる(同じ道具で 200% と 100% に戻す。台数が戻るまで数日かかる)
- 取り壊しのとき: 該当なし

- 実行計画: 局が `list_policies` で RecreationalUse の有効状態 false、costPerWeek 0 を確認済み。予備候補はない。中止する条件は、`list_policies` で見つからない、週の政策費が 0 から増える、週の収支が +3,000 を切るおそれ、のどれか。

## 採らなかった案

- health-1: 汚染を出す工場4棟の取り壊し。工業の需要は 60 と高く、壊した跡の区画は工業のまま建て替わるおそれがある。汚染の源がこの4棟かも確かめていない。品物がない店 228 と働き口 60 への響きもある。種別: 条件付き。条件: `zones_at` と `buildings_near` で、4棟の半径300m以内の汚染の印の建物の数と、跡の区画が工業のまま建て替わらない手(区画を外す `zone_area` type="none" を含めて)を示し、失う働き口 60 と noGoods への響きを書く
- fire-1: 消防の予算を 140 から 150 にする試し。火事の印の 2002 と 5804 は、Fire と FatalProblem が付いている。焼け落ちた建物なら、予算を上げても印は消えない。種別: 条件付き。条件: `buildings_near`(x=3300, z=-780, radius=400, problems_only=true)で 2002、5804、41298 が燃えている稼働中の建物か、焼け落ちた建物かを確かめる。焼け落ちた建物なら、`bulldoze`(what="abandoned")で片づける案(`preview_bulldoze` で失うものを添える)に直す

案を出さなかった局: education(案なし。担当の数字が目標を満たす)、finance(案なし。税と予算の効きを測る根拠がない)。理由は妥当と見て、市長の代案は作らない。
