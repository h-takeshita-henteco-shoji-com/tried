# m01 消防局の案

## 案1: 消防の予算を 140 から 150 にして、火事の印を減らす試し

### 施策

- 案の id: fire-1
- 施策: 消防の予算を昼・夜とも 140% から 150% にする。対象は街全体(消防署・消防小屋の出動)。道具は `set_budget`
- 議決: 予算

### 実行計画

- 実行可否: 確認済み
- 再調査の結果: 条件を満たした。`buildings_near`(x=3300, z=-780, radius=400, problems_only=true)で、2002(3388,-742、Shop07)と 5804(3125,-836、Elementary School)は、どちらも abandoned=false で、Fire と FatalProblem が付いた稼働中の建物。焼け落ちた建物ではないので、取り壊しの案には直さず、予算の試しを残す。41298(3305.7,644、Villa01)は、この円の外(約1,400m 北)にあり、abandoned=false、Fire が付き、5人が住んでいる稼働中の住宅。
- 再調査で分かった追加の事実: `buildings_near`(x=3388, z=-742, radius=600, service="FireDepartment")で、消防署 Fire House 3棟のエンジンの使用中は、18411(3595,-604)が 1 / 8、18786(3545,-334)が 0 / 8、49026(3290,-604)が 0 / 8。火の建物の近くでもエンジンが出ていない。`net_reach`(x=3300, z=-760, radius=250)では、道路から入れない建物は 0。道は届いている。このため、予算の上限を増やしても出動が増えるかは確かめられていない。3月の判定で確かめる。
- 対象と操作順: 1. `set_budget(target="fire", day=150, night=150)` を1回呼ぶ。範囲は 50〜150 で、今の 140 から +10 のため型の上限(±20)に収まる。2. 次の月の見回りで `economy` の fire が 150 になったことを確かめる
- 設置条件の確認: 該当なし(予算の変更で、建物と線は置かない)。`economy` で fire の day と night が 140 だと確認した
- 接続工事: 不要
- 予備候補: なし(予算の変更のみ)。効かなければ `set_budget(target="fire", percent=140)` で戻す
- 中止する条件: 議決で否決された場合。`set_budget` が断った場合。週の収支の見込みが +3,000 を下回る場合(今は +9,965 で、見積もりの増えは約 2,280 のため、下回らない)

### 期待する効果

- 改善の見込み: 火事の印の建物 2002 と 5804 は、稼働中で、火の印が残っている。消防の予算を上げると出動の上限が増え、火を早く消せる、と予想する。ただし、消防署のエンジンは今ほとんど出ていない(1 / 8、0 / 8、0 / 8)。上限を増やすだけで出動が増えるかは確かめていない。効き目の大きさは見積もれない。
- 数値と期限: `complaints` の Fire の建物数。今は 4(2050-01-01)。3か月後(2050-04 頃の月末)に 2 以下になれば当たり、4 のままなら外れ。
- 確認方法: `complaints`(Fire の件数)と `buildings_near`(x=3300, z=-780, radius=400, problems_only=true, brief=true)で、火事の印の建物が同じ区域に残るかを見る。加えて `buildings_near`(x=3388, z=-742, radius=600, service="FireDepartment")の「Fire engines in use」を、今の 1 / 0 / 0(上限 8)と比べる。今の値と同じ道具・同じ範囲で比べる。
- 不確かな点: 火事の印は、その時点で燃えている建物の数で、起きる数は分からない。予算の上限を増やしても、エンジンが呼ばれる仕組みが変わらなければ効かない。原因が局所の出動か、建物の古さか、街の密度かは、まだ分からない(下の調査で確かめる)。効き目が出なければ予算は戻す。
- 試し: 仮説: 消防の予算を上げる → 出動の上限が増える → 燃えている建物の消火が早くなる → 火事の印の建物が減る。測る数: `complaints` の Fire の建物数と、消防署3棟の「Fire engines in use」。場所: 街全体と、(3300,-780) 半径 400m。基準: 火事の印 4(2050-01-01)、エンジンの使用中は 1 / 0 / 0(上限 8)。編成方針の「分からないこと」の項目は今月なしだが、火事の印の原因が分からないため、この案を試しとして扱う。

## 判断の根拠

- 火事の印 4 棟と犯罪の印 3 棟の合計 7 が、目標の 4 以下を超えている。火事の印 4 棟は、消防署の届きが最大の所にあり、届かないことは原因ではないと見た。原因は確かめられていないので、予算を上げる試しを案1にし、同時に火事の建物が残るかを見る調査を出した。
- 再調査で、火事の印の 2002 と 5804 は稼働中と確かめた。焼け落ちた建物ではないので、取り壊しの案は要らない。予算の試しは残す。ただし、近くの消防署のエンジンは今ほとんど出ていないため、効き目は見積もれない。3月に出動の数も見る。
- 犯罪の印 3 棟の近くで、道路に面した空きは確認できなかった。候補はすべて、公園との重なり、道路との重なり、住宅の取り壊し、入口の道路なしのどれかで、実行条件が未確認。このため警察署の案は出さない。
- 案は1件とした。ほかの手は、実行条件が確認できないか、費用が守る線を割るため。件数を埋めるために案は作らない。
