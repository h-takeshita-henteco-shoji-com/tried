## 判断の根拠

- 担当の数字: 街全体の流れは 53(目標60)で、前月と同じ。電気・水・下水が来ない市民は 0 / 0 / 0 で、保てている。
- 案の手: 道幅の差し替えは、局所は効くが流れを動かさないと、m04-2、m05-3、m06-3 で確かめた。今月は交差点の手(信号)に替える。6-3 の編成方針の指示(交差点や信号など別の手に限る)にも沿う。
- 交差点の選び方: 無信号の交差点を8か所確かめた。止まりが多いのは (3162,-300) の4差路(blocked 27)。(2700,330) は今 blocked 8、(-275,-960) は blocked 0 で、信号の効きは小さいと見て外した。
- 案の数を1件にした理由: 信号は1か所に絞ると、効きを局所の数で分けて測れる。同じ手を別の交差点に広げると、効きを分けられない。2か所目の候補は、案1の結果を見てから決める。
- 実行の制約: 信号の費用は道具で確かめられない。そのため executionReady は false にした。設置条件(canEnableLights、trafficLights false)は確認済み。
- 政策: HeavyTrafficBan は費用 0 だが、重い車を道から締め出す。トラックが届ける店の品物(品物がない店 256)と貨物の流れに当たるため、今月は採らない。
- 調査: 東の枝 x=2110 は blocked 19 で、両端が無信号の3差路。案1の結果とあわせて見るため、調査を1件出す。
