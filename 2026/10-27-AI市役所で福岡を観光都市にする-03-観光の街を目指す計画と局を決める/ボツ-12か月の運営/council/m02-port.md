# m02 港湾空港局の案

## 案1: 乗客の少ないバス路線3本の台数を半分にする(試し)

### 施策

- 案の id: port-1
- 施策: バス路線3本の台数割合を下げる(画面の路線番号 38・39・11。内部の line は 139・21・200)。道路の混みを減らし、交通の流れを上げる
- 議決: 予算

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `set_transport_line_budget(line=139, percent=100)`: Bus Line 38(画面の番号 38)。台数の目標を 102 → 約51。乗客24、長さ20.31km、pathFailed 0
  2. `set_transport_line_budget(line=21, percent=100)`: Bus Line 39(番号 39)。台数の目標を 65 → 約33。乗客13、長さ12.82km、pathFailed 0
  3. `set_transport_line_budget(line=200, percent=50)`: Bus Line 11(番号 11)。台数の目標を 36 → 18。乗客5、長さ14.2km、pathFailed 0
  - 3本で約101台を減らす。路線は消さない(`remove_transport_line` は使わない)
- 設置条件の確認: 該当なし(建設なし)。`list_transport_lines` で3本の line、乗客、台数、pathFailed を確認した(見たもの)
- 接続工事: 不要
- 予備候補: なし(路線の差し替えはしない。台数の割合だけを変える)
- 中止する条件: 実行の直前に `list_transport_lines` を取り直し、いずれかの路線の乗客が30を超えたら、その路線を外す。pathFailed が1以上になった路線も外す。3本のうち外すものがあっても、残りの分だけ実行する

### 期待する効果

- 改善の見込み: 6-3 の交通の流れ(52)に効く見込み。3本は乗客が少ないのに車両が多く、走らせる車の分だけ道を埋めている。ただし台数は約101で、街全体の車 7,384 台の1%余りなので、流れへの効きは小さいと見る。
- 数値と期限: 流れ 52%(今の値)。予想は 52 → 53 程度で、見積もりの幅は 0〜2。期限は予算を変えてから1か月(月末)。
- 確認方法: `traffic` の flow(街全体)。基準は今月の 52。同時に `list_transport_lines` の 3本の乗客と台数を見る。台数の減りが目標どおりかを確かめる。
- 不確かな点: 効く量は見積もれない。流れの悪さは、止まったトラックが道の上で詰まる形が大きい(見たもの)。バスの台数はその一部にすぎない。乗客が減れば、運賃の収入も少し減る(3本の乗客は合わせて 42)。
- 試し: あり。仮説: 乗客の少ないバス台数を減らすと、道の上の車が減り、流れが上がる。測る数: `traffic` の flow(街全体)。場所: 街全体(3本が走る道の周りも見る)。基準: 今の 52。1か月後に 52 からの変化を見る。編成方針の「分からないこと」の項目には当たらない。6-3 の流れの効き目を測る試し。

### 費用

- 建設費: 0(建設なし)
- 週の維持費の増え分: 約 -1,160(減る見込み。概算)。バスの維持費は週 22,118(`economy_breakdown` の PublicTransportBus の支出)。バスの台数は約1,920(路線の台数の合計)。1台あたり約11.5/週で割った見積もり。道具で3本の分を直接は確かめられていない

### 戻せるか

戻せる。台数の割合を 100% や 200% に戻せば、もとに戻る。路線は消さない。

## 判断の根拠

8-1 は、駅・港の敷地で止まったトラック 511 が目標 250 を大きく超え、見回りを通じて 490 前後で動いていない。隣の 13893 が車を出さず、道の混みも小さいため、止まりの原因は駅の出口の数だと見るが、確証はない。出口を増やす案は、接続の道具で確かめられていないため出せない。そこで、8-1 の原因を見分ける調査を1件出す。施策は、6-3 の流れに効く見込みのあるバス台数の削減を1件出す。乗客が少なく車両が多い3本に絞り、前月の非採択理由(測る数の重なり、経路の未確認)を手当てした。案の数は1件にした。8-1 の施策は確証がないため案にできず、2件目を埋めるための案は作らない。
