# m08 保健環境局の案

## 案1: 埋立地を(-1700,-1700)に新設し、事務所2棟を取り壊す

### 施策

- 案の id: health-1
- 施策: 満杯の埋立地10のため遠くまで走るごみ収集車を減らす。(-1700,-1700) に埋立地(Landfill Site)を1棟置き、入口(-1700,-1668)から道路(Basic Road)を(-1640,-1662)へつなぐ。置く前に、同じ場所の事務所2棟(id 11772、34876)を取り壊す
- 議決: 取り壊し

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `preview_bulldoze` x=-1690, z=-1690, radius=45 で、取り壊す対象を確認する(確認済み。対象は事務所2棟だけ。失う働き口35、家0、区間0、電気の線0)
  2. 議決のあと、`bulldoze` で同じ円(x=-1690, z=-1690, radius=45)の事務所2棟(id 11772 H2 4x3 Office06、id 34876 H2 4x4 Office11)を取り壊す
  3. `build_line` prefab "Basic Road"、points [[-1700,-1668],[-1640,-1662]]。道路は既存の節点(-1640,-1662、区間 34946 の端)につながる
  4. `place_building` prefab "Landfill Site"、x=-1700、z=-1700、facing "north"(angle 0)。入口は(-1700,-1668)で、手順3の道路の端になる
- 設置条件の確認:
  - `test_place_building` Landfill Site、x=-1700、z=-1700、facing north、assume_removed_buildings [11772, 34876] で ok(angleUsed 0、費用 4,000、所持金は足りる、電気・水・下水は不要)。取り壊しを前提に通った
  - 取り壊しを前提にしないと、ObjectCollision で置けない(事務所2棟と重なる)
  - `test_place_building` の入口は(-1700,-1668)、road は null。道路を引くまでは入口が道路につながらない
  - `test_build_line` Basic Road、points [[-1700,-1668],[-1640,-1662]]、assume_removed_buildings [11772, 34876] で ok(segments 1、費用 320、overlaps なし)
  - 取り壊しを前提にしない `test_build_line` は、事務所34876 と重なり、通らない
  - `net_near` x=-1700, z=-1700, radius 150、service Road で、道路の端の節点 22041(-1640,-1662)と 30462(-1640,-1730)を確認。区間 34946(-1640,-1662〜-1640,-1730)が既存
  - `preview_bulldoze` の結果は、取り壊しで道路の区間を壊さない
  - 電気・水・下水は埋立地に要らない(`test_place_building` の needs が全部 false)
- 接続工事: 基本道路 60m を1本(入口(-1700,-1668)から節点(-1640,-1662)まで)。費用 320(`test_build_line`)、週の維持費 約2.4(40 × 0.06km、`list_net_types` の Basic Road)。取り壊しは議決が要る
- 予備候補: なし(確認できた候補は(-1700,-1700)だけ)。試した他の候補は、捨てたものに書く
- 中止する条件: 実行直前の `test_place_building` で、(-1700,-1700)が ObjectCollision になる、または wouldDemolish の建物が id 11772、34876 以外になる場合。`test_build_line` で overlaps が出る場合。取り壊し議決が通らない場合。議決が通らなければ、道路と埋立地は置かない

### 期待する効果

- 改善の見込み: 満杯の埋立地10のため、ごみ収集車が500〜2,700m先の埋立地へ走っている(m07 survey と今月の `vehicles_stuck`)。近くに埋立地を1つ足すと、ごみの運び先までの距離が短くなり、収集車の渋滞と取り残しが減ると予想する。新しい埋立地から収集車19台が出るので、収集の台数も増える。ごみの収集先の距離は、(-2119,-1581)のごみの印の塊から約436m(6816 は約523m)。
- 数値と期限: 対象は保健環境局の数字。`complaints` の Garbage の印 262(今月の値、街全体)を、見回り2・翌月末までに 262 より減らす。ごみの印が0になる目標は、12か月後の目標(0)。予想値は数値で見積もれない
- 確認方法: `complaints` problem Garbage の印の数(街全体)、`services` garbage の full(満杯の数)と埋立地の used、`vehicles_stuck` kind garbage の byState(Congestion、Blocked の台数)。今の値は、Garbage 262、満杯10、garbage 収集車の Congestion と Blocked が多い状態。比べる範囲は街全体と、ごみの塊(-2119,-1581)の半径300m(`buildings_near` problem Garbage、今の値 total 2)
- 不確かな点: 埋立地を置いても、ごみの印が減るとは限らない。収集車の台数の上限、渋滞、ごみの発生量が効く。効くかどうかは、埋立地6816 の効きを m09 で見た結果と合わせて判断する。取り壊しで失う働き口35(0.04%)は、6-4、7-1 の目標に小さく効く
- 試し: 試し。仮説: 近くに埋立地を足す → 収集車の運び先が近くなる → 収集車の渋滞と取り残しが減る → ごみの印が減る。測る数は `complaints` の Garbage の印の数(街全体)と、`services` の満杯数、`vehicles_stuck` の garbage の Congestion と Blocked。場所は(-1700,-1700)。基準は、ごみの印262、満杯10、収集車の止まりは今の `vehicles_stuck`。編成方針の「分からないこと」の「ごみの印262。埋立地6816の効きは m09 月末に比べる」に当たる
