# m03 港湾空港局の案

## 案1: バスの予算を150%から130%に下げて、路線の台数を減らす

### 施策

- 案の id: port-1
- 施策: 公共交通のバスの予算(bus)を、昼夜とも150%から130%にする。街全体のバス路線が対象。台数の多さが、道の上のバスの詰まりを増やしていると見て、台数を1割強減らす。6-3 の流れを上げるため。
- 議決: 予算

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `economy` で、bus の昼夜の予算が 150 であることを確かめる(確認済み: day 150 / night 150)。
  2. `set_budget(target="bus", percent=130)`。昼と夜を同じ 130 にする。
  3. `economy` で、bus が day 130 / night 130 になったか確かめる。
  4. 見回り1・見回り2・月末で、確認方法の道具を見る。
- 設置条件の確認: 該当なし(建設なし)。引数は `tool-reference.md` の `set_budget` と合う(target は bus、percent は 50〜150 の範囲内。今は 150 から 20 下げる。予算の上限 ±20 の内)。
- 接続工事: 不要
- 予備候補: 路線ごとの台数の割合(`set_transport_line_budget`)で乗客の少ない路線だけ減らす手は、ほかの同じ路線の台数を変えないため、効きが小さくなる。この案が不採択のときの次の候補にする。乗客が 3 以下の路線を消す(`remove_transport_line`)も同じ手(バスの台数を減らす)なので、別案にしない。
- 中止する条件: 実行の後、`list_transport_lines` の乗客の合計(passengersLastPeriod の合計)が、基準の約4,715から 4,000 を下回ったら、`set_budget(target="bus", percent=150)` で戻す。

### 期待する効果

- 改善の見込み: 止まった車 673 のうち、バスの Blocked が 669 あり、詰まりの大半はバスと見られる(見たもの)。乗客の少ない路線に台数が多く、乗客の合計 約4,715 に対してバスが 1,839 台ある。台数を減らせば、道の上の詰まりが減り、6-3 の流れが上がると予想する。
- 数値と期限: 6-3 の `traffic` の流れは今 54(目標 60)。バスの Blocked は今 669、バスの全数は今 1,839。乗客の合計は今 約4,715。期限は次の月例(4か月目)の前、30日後。
- 確認方法: 見回り1(10日目)と月末(30日目)に、`traffic`(街全体の流れと blocked)、`vehicles_stuck`(kind="bus" の Blocked と全数)、`list_transport_lines`(乗客の合計)を見る。今の値と同じ道具で比べる。
- 不確かな点: 台数が何%減るか、流れがどれだけ上がるかは見積もれない。乗客が減れば効きは小さくなる。詰まりの場所が、台数の多い路線と関係なければ効かない。
- 試し: 試し。仮説: バスの台数を減らすと、道の上で止まるバスが減り、東の詰まり(3302,-277 付近)の車の流れが上がる。測る数: `traffic`(x=3200, z=-300, radius=500)の blocked(今 154)と、`vehicles_stuck`(kind="bus")の Blocked(今 669)。場所: 東の詰まり(x=3200, z=-300, 半径500)と街全体。基準: 上の今の値。分からないことの一覧の項目には当たらない(6-3 の詰まりの原因を確かめる試し)。

### 費用

- 建設費: 0
- 週の維持費の増え分: 約 −2,950(減る)。見積もりは、`economy_breakdown` の Bus の支出 22,120 / 週を、予算 150 から 130 に下げた割合(20/150)で割り引いた額。

戻せる。`set_budget(target="bus", percent=150)` で元に戻る。台数は予算に合わせて増える。

## 判断の根拠

道の上の詰まりは、止まった車 673 のうちバスの Blocked 669 とほぼ重なる。バスは全数 1,839 台に対し、乗客の合計は約4,715で、1台あたりは2〜3人しかない。台数を減らせる余地が大きいため、バスの予算を 150 から 130 に下げる案(port-1)を出す。予算の動かせる幅 ±20 の内で、建設費も増えない。

貨物駅28755の待ちは、出口の道ではなく敷地の中で起きている。原因の見分けが付かないので、案は出さず、調査を1件出す。13893 は ports が空で、トラックが使えないと見たため、同じ駅を増やす手は今は採らない。

案を1件にしたのは、残りの手が次のとおりだから。路線ごとの削減は予算案と同じ手で、効きを分けられない。路線の削除も同じ手(台数を減らす)。FreeTransport と HeavyTrafficBan は、今月の数字に悪い方へ働く。今の数字で確かめられる手は、予算の1件だけ。
