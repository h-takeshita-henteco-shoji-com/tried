# m06 査定調書

## 案ごとの査定

### urban-1(住宅都市みどり局): 南西の空きに広場 Regular Plaza を1棟

- 査定: 可
- 理由: 建設費 2,500(`list_building_types` の Regular Plaza の cost と一致)。週の維持費の増え 32(同じく upkeepPerWeek)。建設費の枠 100,000 と維持費の幅 4,000 に収まる。
- 減らした形: なし

### roads-1(道路下水道局): 渋滞する Basic Road を Small 4 Lane Road に差し替える(3群、取り壊しなし)

- 査定: 可
- 理由: 建設費 0(案の試し `test_upgrade_road` の cost 0 を、財政で採用)。週の維持費の増え 0。`list_net_types` で Basic Road と Small 4 Lane Road はどちらも 5,000/km、40/km/週で同じ。建設費の枠と維持費の幅に収まる。
- 減らした形: なし

### economy-1(経済観光文化局): 東の住宅・商業地に名所(Official Park)を1棟置く

- 査定: 可
- 理由: 建設費 45,000(`list_building_types` の Official Park の cost と一致)。週の維持費の増え 128(同じく upkeepPerWeek)。建設費の枠 100,000 と維持費の幅 4,000 に収まる。取り壊し(放棄の H3 Shop、25933)の費用は道具で確かめられず、案にも含まれていない。取り壊しの議決は議会の判断で、財政の上限には当たらない。
- 減らした形: なし

### health-1(保健環境局): 西の空き地に埋立地を1か所足す(基本道路 約80m を延ばす)

- 査定: 可
- 理由: 建設費 4,400(Landfill Site 4,000 と Basic Road 400。Landfill Site は `list_building_types` の cost と一致。Basic Road は 5,000/km × 約80m)。週の維持費の増え約 164(Landfill Site 160 と Basic Road 約 3〜4)。建設費の枠と維持費の幅に収まる。
- 減らした形: なし

### 港湾空港局(port)

案なし。査定しない。

### 経済観光文化局の案以外の案(education、fire)

- education: 案なし。査定しない。
- fire: 案なし。査定しない。

## 合わせた費用と上限

- 「可」と「減額」の案を合わせた建設費: 51,900(urban-1 の 2,500 + roads-1 の 0 + economy-1 の 45,000 + health-1 の 4,400)
- 合わせた週の維持費の増え分: 324(urban-1 の 32 + roads-1 の 0 + economy-1 の 128 + health-1 の 164)
- 市長が選ぶときの建設費の上限: 100,000(要領の枠。所持金 2,197,627 の半分は上限だが、守る線で狭めた枠に従う)
- 市長が選ぶときの週の維持費の上限: 4,000(要領の枠。週の収支 +8,944 の範囲内)

全部を選んでも、所持金は 2,145,727 程度に残り、出発点 2,082,287 を下回らない。週の収支は +8,620 程度で、黒字を保つ。

## 税の案

なし。週の収支は黒字で、所持金も守る線の内側にある。税を動かす理由がない。

## 判断の根拠

4つの案の建設費の合計は 51,900 で、建設費の枠 100,000 に収まる。週の維持費の増えは合計 324 で、幅 4,000 に収まる。所持金は、全部を選んでも出発点 2,082,287 を下回らず、週の収支も黒字を保つ。案の費用は、各局の調書の数字と道具の値が一致した。税と予算の変更は、今月の守る線から必要がない。
