- 議決: 取り壊し

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `bulldoze` x=3125, z=-836, radius=6, what="building"(5804 Elementary School)
  2. `bulldoze` x=2184, z=-918, radius=6, what="building"(12882 H3 2x2 Bigfactory06)
  3. `bulldoze` x=2812, z=-836, radius=6, what="building"(23671 L4 2x2 Villa07)
- 設置条件の確認: `preview_bulldoze` を radius=6 で3棟それぞれに実行した。5804 は 0 働き口・0 家、12882 と 23671 も 0 働き口・0 家(前回の確認)。3棟とも電気・水・道路の線は壊さない(segments 0、powerLineSegments 0)
- 接続工事: 不要
- 予備候補: なし
- 中止する条件: 実行前の `preview_bulldoze` で、いずれかの棟が 0 でない働き口・家を持つ、または区域に別の建物がかかる場合は、その棟を外す

### 期待する効果

- 改善の見込み: 火事の印が付いたまま残る放棄棟(FatalProblem)が3-4の火事の数の一部になっている。取り壊せば、その3棟の火事の印は消える。残りの火事は、消防車の出動が遅い地域(2556,-759 付近の火事が3棟)が中心になる。

- 確認方法: `complaints` の Fire 件数と、`buildings_near` problem="Fire" の一覧。今の値と同じ範囲(全市)で比べる
- 不確かな点: 取り壊した後に新しい火事が出れば、件数は増える。3棟を消しても、残り4棟の火事が残るなら目標に届かない。数値の予想は、取り壊し後の残数で判断する。
- 試し: なし

- 週の維持費の増え分: 0(取り壊しで減る。増えない)

## 案2: 火事の多い地区に消防署を1棟足す(試し)

### 施策

- 案の id: fire-2
- 施策: 火事の多い地区(hotspot (2556.7,-759)、火事3棟)の北西側に、消防署(Fire House)を1棟足す。道路は、既存の道路(2520,-660)〜(2580,-660)の端から引く
- 議決: 予算

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `build_line` prefab="Basic Road"(道路の名前は `list_net_types` の Basic Road)、points=[[2600,-688],[2580,-660]], pay=true。既存の道路の端 (2580,-660) につながる、支線の道路
  2. `place_building` prefab="Fire House"(Fire House の種類名は `list_building_types` の FireDepartment)、x=2600, z=-705, angle=0, facing="north"。入口は (2600,-693)、道路 (2600,-688)〜(2580,-660) につながる
- 設置条件の確認:
  - `test_place_building` Fire House (2600,-705) facing north: ok。費用 12,000、wouldDemolish 0、入口 (2600,-693)、入口から16m以内の道路 road は null(支線を先に引く必要がある)
  - `test_build_line` Basic Road [[2600,-688],[2580,-660]]: ok、segments 1、費用 160、overlaps []
  - `net_near` (2590,-690) r60 Road: 既存の道路 segment 3950 (2520,-660)〜(2580,-660)、端 node 15240 が (2580,-660)。支線の端と一致
  - `water_trace` (2600,-705) 付近: 水・下水は届く(2560,-726 で水 true、下水 true、電気 true)
- 接続工事: 支線の道路 Basic Road 1区間、費用 160。道路の維持費は `list_net_types` で未確認。
- 予備候補: なし
- 中止する条件: `test_place_building` が断る、または入口の道路が見つからない場合は、支線を引き直す。支線が既存道路に届かなければ見送る。

### 期待する効果

- 改善の見込み: 火事の多い地区から最寄りの消防署までの距離が縮み、火が広がる前に消防車が着くと見込む。火事の印は、消防車が着くまでの時間に比例して減ると予想する。
- 数値と期限: `complaints` の Fire 件数(全市と hotspot 周辺)。今の値 7(全市)、3(hotspot (2556.7,-759))。予想は数値では見積もれない。期限は12か月目の終わり(月末)。
- 確認方法: `map_layer` type="fire" を、(2600,-705) 周辺 r150 n=3 で測り、今の値 average 87、min 49、max 117 と比べる。`buildings_near` service="FireDepartment" で、新しい消防署の使用中の車の数(Fire engines in use)を見る。
- 不確かな点: 建った消防署が実際に出動するかは、建った後にしか分からない。火事の印が消えるまでの時間も不明。12か月目に間に合うかは分からない。数値は見積もれない。
- 試し: あり。仮説: 消防署を火事の多い地区に近づけると、消防車の到着が速くなり、火事の印が減る。測る数: `map_layer` type="fire" の average(範囲 (2600,-705) r150)と、`complaints` の Fire 件数。場所: (2600,-705)。基準: average 87、Fire 件数 7(全市)。編成方針の「分からないこと」にある「火事の印が3→7に増え、消防車が出ない理由」の確かめに当たる。

### 費用

- 週の維持費の増え分: 560(消防署の `upkeepPerWeek`)。道路の維持費は未確認で、小さい見込み
