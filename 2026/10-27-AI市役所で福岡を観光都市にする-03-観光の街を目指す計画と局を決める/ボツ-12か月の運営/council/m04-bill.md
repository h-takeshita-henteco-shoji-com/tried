  2. `place_building(prefab="Regular Park", x=2795, z=1180, facing="east", pay=true)`
  3. `place_building(prefab="Regular Park", x=2795, z=1260, facing="east", pay=true)`

### m04-2 北からの基本道路(x=2668)を4車線に差し替える(試し)

- 元にした局の案: roads-1。手直しした点: なし
- 議決: 要らない
- 採択理由: 交通の流れは 53(目標 60)で、blockedSpots の最大は (2719,326) の 52 である。北からの基本道路 7468 と 6704 は density 100 で、差し替えは費用 0、維持費の増え 0、取り壊し 0 と確認済みである。
- 今月選んだ理由: 6-3 の流れが目標から遠く、確認済みで費用のかからない手がこれだけだった。測る場所が (2719,326) の近くに限られ、ほかの施策と重ならない。
- 公約: どれにも直接つながらない。6-3 の流れを上げるための手で、交通は採点の6項目の1つである。
- 市の計画: 6-3 公共交通を主軸とした交通体系
- 操作:
  1. 直前に `test_upgrade_road(prefab="Small 4 Lane Road", points=[[2668,330],[2668,407],[2668,483]], tolerance=20)` を取り直す。
  2. `upgrade_road(prefab="Small 4 Lane Road", points=[[2668,330],[2668,407],[2668,483]], tolerance=20, pay=true, demolish=false)`
  3. 実行の前に `traffic(x=2719, z=326, radius=60)` の blocked を取り、実行の後に同じ引数で見る。
- 実行計画: 対象は segment 7468(2668,330→407)と 6704(2668,407→483)。`test_upgrade_road` で matched 2、upgraded 2、skipped 0、cost 0、demolishedBuildings 0。中止する条件は、直前の試しで skipped が1件でも出ること、または demolishedBuildings が1件でも出ること。予備候補はなし。
- 費用: 建設費 0、週の維持費の増え分 0
- 予想: (2719,326) 付近の blocked は基準 52(半径200m の集計)。下がれば効いた、上がれば詰まりが動いた、変わらなければ交差点 9244 が制約である。量は見積もれない。街全体の流れ 53 は数ポイントも動かない可能性が高い。判定は見回り1・見回り2・月末の3回と、翌月の月例。
- 試し: 仮説は「北の基本道路の狭さが交差点 4025 の入口の詰まりを通じて、交差点 9244 の止まりを増やしている」。測る数は `traffic`(x 2719、z 326、radius 60)の blocked。場所は (2719,326) の半径60m。基準は blocked 52(r200 の集計)。実行前に r60 で取り直して基準を置き直す。街全体の流れは参考値とし、判定には使わない。分からないことの一覧の項目ではなく、交通の流れの原因を確かめる試しである。
- ほかの局への響き: 北からの入口が広がると、交差点 9244 に流れ込む車が増え、詰まりが東へ動くかもしれない。維持費は変わらない。
- 戻せるか: 戻せる。同じ区間を Basic Road に差し替え直す(戻す操作は未確認)。
- 取り壊しのとき: 該当なし

### m04-3 満杯の埋立地 25590 を空にし、工場群のごみを近くで受ける(試し)

- 元にした局の案: health-1。手直しした点: なし
- 議決: 要らない
- 採択理由: ごみの印は 14 から 28 に増え、満杯の埋立地は 8 棟になった。25590 は工場群(3512,-600)の近くで満杯のまま、`empty_building` は費用 0 である。
- 今月選んだ理由: 重点3(4-4)に当たり、分からないことの一覧の「満杯の埋立地を空けると、なぜごみの印が増えたのか」を確かめる試しになる。中止条件があり、費用がかからず戻せる。今月の試しはこれ1件に絞る。
- 公約: どれにも直接つながらない。4-4 のごみの印を減らす手で、暮らしの基盤に当たる。
- 市の計画: 4-4 資源循環
- 操作:
  1. 実行の前に `buildings_near(x=3512, z=-600, radius=300, problem="Garbage", brief=true)` と `complaints` の Garbage を取り、基準(8棟、街全体 28)を確かめる。
  2. `empty_building(id=25590, active=true)`
  3. 見回り1・見回り2で `services` の garbage.full、`buildings_near`(同じ引数)、`vehicles_stuck(kind="garbage", limit=10)` を見る。
  4. 月末に `empty_building(id=25590, active=false)` で戻す。
- 実行計画: 25590 (3900,-575) は `buildings_near` で LandfillFull を確認済み。中止する条件は2つ。(a) `complaints` の Garbage が 28 より増える、または工場群 r300 の Garbage が 8 より増えたら、月末を待たず active=false で戻す。(b) `vehicles_stuck` の garbage で (3631,-254) 付近の台数が増えたら戻す。予備候補はなし。

- 予想: 工場群 r300 の Garbage 8 → 3 以下(量は見積もれない)。街全体 28 は同時に悪くならない見込み。ただし m01-4 では、空けた中身が遠い焼却場へ運ばれて渋滞し、15 から 26 に増えた。今回も同じ形で悪化する可能性がある。期限は月末。
- 試し: 仮説は「工場群の近くの満杯の埋立地が受け入れを止めているため、工場のごみが収集されない」。測る数は `buildings_near` の problem=Garbage の棟数(x 3512、z -600、radius 300)。街全体の Garbage は悪化の歯止めの監視に使う。基準は 8棟、街全体 28。分からないことの一覧の「満杯の埋立地を空けると、なぜごみの印が増えたのか」の項目。この範囲には、ほかの施策を重ねない(health-2 の Recycling は街全体に効くため採らない)。
- ほかの局への響き: 運び先の道が詰まると、交通の流れ(6-3)と貨物の動き(8-1)に響く。中止条件(b)で監視する。
- 戻せるか: 戻せる(active=false)
- 取り壊しのとき: 該当なし

## 採らなかった案

- economy-1: 名所 StatueOfWealth の案。査定の対象外で、実行計画も「未確認」である。送電線の網が発電所につながるかが未確認で、置いてから確かめる形になる。電気の接続を判定できる根拠(発電所までの経路)が出れば、来月に再提出してほしい。
- port-1: バス路線2本の台数を 180% に下げる試し。測る数が街全体の流れで、m04-2 の測る数(同じ流れ)と重なり、効きを分けられない。測る範囲を路線の沿線に絞った形(沿線の blocked と乗客)で出し直してほしい。
- health-2: Recycling と住宅(低)の税率+1。Recycling は街全体のごみを変えるため、m04-3 の測る数(工場群のごみの印)と重なる。局の週の収支の見込みも、査定で書き直された。m04-3 の判定の後に出し直してほしい。
- fire-1: Fire House を (3330,-735) に置き、住宅3棟(家 11)を取り壊す案。戻せない取り壊しに対し、署に消防車が出ない原因(学校 5804 に 0 台、署は 8 台中 1 台)が分からず、署を足して効く根拠がない。(3330,-735) は m04-3 の測る範囲(工場群 r300)にも近い。出動の不具合の原因を調べる調査と、取り壊しのない場所の候補を添えて出し直してほしい。
- education: 案なし。目標を満たしており、採る案がない(局の役割として妥当)。
