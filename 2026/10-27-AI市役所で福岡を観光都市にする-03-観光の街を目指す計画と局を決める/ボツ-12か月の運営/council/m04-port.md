# m04 港湾空港局の案

## 案1: 乗客の少ないバス路線2本の台数を、予算を20下げて減らす(試し)

### 施策

- 案の id: port-1
- 施策: バス路線の台数の割合を、路線136(Bus Line 28)と路線139(Bus Line 38)で200%から180%に下げる。どちらも街全体の交通の流れを増やすための台数の削減。道具は `set_transport_line_budget`
- 議決: 予算

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `set_transport_line_budget(line=136, percent=180)`。路線136(画面の番号 28、Bus Line 28)。現在 budget 200、vehicles 190、passengersLastPeriod 99、lengthKm 37.91
  2. `set_transport_line_budget(line=139, percent=180)`。路線139(画面の番号 38、Bus Line 38)。現在 budget 200、vehicles 102、passengersLastPeriod 30、lengthKm 20.31
  3. 変えるのは路線ごとの台数の割合だけ。サービス全体の予算(`set_budget`)は動かさない
- 設置条件の確認: 該当なし(建設なし)。路線の番号(line)は `list_transport_lines` で確かめた。割合 180 は 10〜300 の範囲内で、予算の±20の枠(200→180 は -20)に収まる
- 接続工事: 不要
- 予備候補: なし(路線の変更だけで、場所の候補はない)
- 中止する条件: 実行前に `list_transport_lines` で line 136 か 139 の budget が 200 でない、または路線の名前・台数が今と違えば見送る。実行後に、路線の pathFailed が 1 以上に増えたら、180 から戻すかを次の月に判断する

### 期待する効果

- 改善の見込み: 6-3 の交通の流れは、街全体で53(目標60)。路線136と139は、台数に対して乗客が少ない(136 は 190 台で乗客 99、139 は 102 台で乗客 30)。台数を減らすと道の上を走るバスが減り、道の混みが少し下がると予想する。ただし減る量は10%なので、流れを目標の60まで上げる効きは見込めない。
- 数値と期限: 街全体の `traffic` の流れ(今の値53)。予想値は見積もれない(効きは小さいと見ており、数ポイント以内と推測するが、根拠の数値はない)。期限は月末(30日目)と、翌月の月例。
- 確認方法: `traffic`(引数なし、街全体)の flow と blocked。`list_transport_lines`(type=bus)の、line 136 と 139 の vehicles と passengersLastPeriod。基準は今の値(flow 53、136 は vehicles 190、139 は vehicles 102)。乗客が大きく減れば(136 の passengersLastPeriod が 99 から半分以下)、案の効きを悪いとして戻す。
- 不確かな点: バスの台数が減っても、流れが上がるかは分からない。乗客が減ると、ほかの路線への移りの効果も分からない。路線の運賃収入(バス全体で 5,144/週)は、乗客が減った分だけ減る。バスの週の支出(22,113)が減る額は、道具で確かめられない(数値は見積もれない)。
- 試し: 試し。仮説: 路線136と139の台数を10%減らすと、道の上のバスが減り、街全体の交通の流れが上がる(バス → 道の混み → 流れ)。測る数: `traffic` の flow(街全体)と、`list_transport_lines` の該当路線の passengersLastPeriod。場所: 街全体。基準: flow 53、路線136の乗客99、路線139の乗客30。編成方針の「分からないこと」の項目には当たらないが、6-3 の流れが 53 のまま動かない原因の一部を確かめる試し。

## 判断の根拠

- 8-1: 駅・港の敷地で止まったトラックは518(目標250)。うち517台が貨物駅28755の敷地内で WaitingSpace。道の上の詰まりではない(`traffic` の blocked 0)。前の月の調査 s03-1 と同じ結果。原因は敷地内の連絡路と見られるが、確かめていない。施策にする前に、調査で連絡路の詰まりを確かめる。道路や駅の新設は、接続と敷地の確認がないため案にしない
- 6-3: 流れ53(目標60)。台数に対し乗客が少ないバス路線(136と139)を、20ポイント下げる。予算の変更なので議決が要る。効きは小さいと見て、試しとして出す。測る数は街全体の流れ
- 案の数を1件にした理由: 8-1 の原因が確かめられていないため、施策にできる手が確認できたのは 6-3 の路線の台数だけ。件数を埋めるための案は出さない
- 調査を1件出した理由: 8-1 は原因が分からないまま3か月続いている。敷地内の待ちの動きを、見回りと月末で見れば次の手が決まる
