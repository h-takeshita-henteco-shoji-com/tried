# m11 保健環境局の案

## 案1: 埋立地を (-390,-1920) に新設する(取り壊し3棟を含む)

### 施策

- 案の id: health-1
- 施策: 埋立地(Landfill Site)を座標 (-390,-1920) に、向き south(入口 (-390,-1952))で新設する。ごみ収集車の行き先を、満杯の埋立地から近い受け入れ先に増やす。先に住宅3棟(id 2229、10902、48232)を取り壊し、その跡に建てる
- 議決: 取り壊し

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `bulldoze`(x -390、z -1920、radius 50、what building)で、住宅3棟を取り壊す(id 2229 H4 3x4 Tenement11、10902 H3 4x3 Tenement04a、48232 H4 2x3 tenement04)。取り壊しの議決を要する
  2. `place_building`(prefab Landfill Site、x -390、z -1920、angle 180、facing south)で埋立地を建てる。入口は (-390,-1952)、道路は Basic Road(segment 17494、-346〜-420 の z -1960 の区間)に面する
- 設置条件の確認:
  - `test_place_building`(Landfill Site、-390、-1920、south、取り壊しの3棟を assume_removed_buildings に入れて)は ok。費用 4,000、所持金は足りる、入口の道路 segment 17494 の距離 0
  - `test_place_building`(同じ座標、取り壊しなし)は ok。wouldDemolish は3棟(2229、10902、48232)、失う家 51、働き口 0
  - `net_near`(-390、-1950、半径60、Road)で、入口の道路は segment 7241 と 17494(Basic Road、各1車線×2方向)。入口の道路がつながる
  - `preview_bulldoze`(-390、-1920、半径50、building)で、取り壊しは3棟、失う家 51、働き口 0、電気が切れる建物 0、水の施設 0、駅・港 0
  - 埋立地は電気・水・下水が要らない(needs 全部 false)
- 接続工事: 不要(道路の接続は入口で確認済み)
- 予備候補:
  - (-300,-1915)、south: test ok。取り壊し4棟、失う家 66(案1より多い)
  - (-340,-1920)、south: test ok。取り壊し4棟、失う家 72
  - (-260,-1915)、south: test ok。取り壊し5棟、失う家 84
  - 以上は再確認が必要。使うなら、取り壊しの議決を取り直す
- 中止する条件:
  - 取り壊しの議決が否決されたら、この案は見送る
  - 実行前の `test_place_building` が ok でなくなった(入口の道路が変わった、ObjectCollision が出た)ら、予備候補のいずれかを同じ手順で試す。いずれも ok でなければ見送る
  - 取り壊し後の `preview_bulldoze` で、取り壊す数が3棟を超えたら、取り壊しを止めて見送る

### 期待する効果

- 改善の見込み: ごみの印(505棟)のうち、ごみの集まる場所の近くに受け入れ先がないため、収集車が満杯の埋立地を越えて遠くへ行く。新しい埋立地(容量 8,000,000、処理 160/週)が近くに入れば、運搬の距離が短くなり、ごみの印が減ると予想する。効果は限られる見込み。収集車の停滞は主に道路の渋滞(318台、216台は7日超)によるため、この案だけでは止まらない可能性がある
- 数値と期限: `complaints` のごみの印(街全体)は今 505棟。ごみの集まる場所(hotspot)の印は今 111棟(-108,-1629 付近)。予想は、30日後(月末)に hotspot の印が 111 から 80 以下、街全体が 505 から 400 以下。数値は見積もれない部分がある
- 確認方法: `complaints`(type Garbage の buildings と hotspot)、`vehicles_stuck`(kind garbage、limit 30)で埋立地に向かう車の数。今の値と同じ条件で、建った日と月末を比べる。埋立地の受け入れは `services` の garbage(満杯の数)で見る
- 不確かな点:
  - 過去の埋立地(m07-1 の (-1775,-1975))は局所の効果だけで、街全体のごみの印は 262 から 324 に増えた。新設が同じ結果になる恐れがある
  - 取り壊しが必要で、失う家は 51(空きの家は 4,877 あるため、人口への影響は小さい見込み)
  - 数値は見積もれない
- 試し: 効き目が分からないため試しとして出す。仮説は「ごみの集まる場所の近くに受け入れ先が増えると、収集車の行き先が近くなり、ごみの印が減る」。測る数は `complaints` の Garbage の buildings(街全体と hotspot 周辺)と、`services` の満杯の埋立地の数。場所は (-390,-1920)。基準は街全体 505、hotspot 111。編成方針の分からないこと「ごみの印が埋立地や道路を直しても増え続ける原因」に当たる

## 判断の根拠

- 4-4 資源循環(ごみ 505)は重点2で、目標 0 から最も遠い。ごみの集まる場所の近くに受け入れ先がなく、満杯の埋立地 11 が近くにあるため、近くに新しい受け入れ先を置く案を1件出した
- 埋立地 (-390,-1920) は、test_place_building で入口の道路と取り壊しの範囲を確かめた。取り壊しは住宅3棟、失う家 51 で、空きの家 4,877 に対して小さい
- 焼却場(Combustion Plant)は、道路の接続が未確認で、週 1,440 の維持費も大きいため、今月は案にしない
- 4-3 脱炭素社会(汚染 32)は、汚染源が (700,-640) 付近の住宅の外にあり、建物が見つからない。原因が分からないため、案は出さず、調査を1件出した
- Recycling(4-4)は、住宅の税の収入が減るため、税の議決の見込みが薄い。今月は出さない
- 案は1件にした。確認できた埋立地の候補は1つだけで、効き目の見込みも限られるため、件数を埋めない
