## 案1: 渋滞の大きい路線バス5本の台数を減らす

### 施策

- 案の id: port-1
- 施策: バス5路線の予算(台数の割合)を、20ポイント下げる。対象は、道路で止まったバスが多く、乗客が台数に比べて少ない路線。路線の番号(画面の番号)は 28、38、37、41、39。
- 議決: 予算

### 実行計画

- 実行可否: 確認済み
- 対象と操作順(`set_transport_line_budget` を5回。引数は list_transport_lines の line と percent):
  1. 路線 136(画面の番号 28)。現在 180 → `set_transport_line_budget(line=136, percent=160)`。台数 170 → 約 151。
  2. 路線 139(番号 38)。現在 180 → `set_transport_line_budget(line=139, percent=160)`。台数 92 → 約 82。
  3. 路線 127(番号 37)。現在 180 → `set_transport_line_budget(line=127, percent=160)`。台数 51 → 約 45。
  4. 路線 126(番号 41)。現在 200 → `set_transport_line_budget(line=126, percent=180)`。台数 50 → 約 45。
  5. 路線 21(番号 39)。現在 200 → `set_transport_line_budget(line=21, percent=180)`。台数 65 → 約 58。
- 設置条件の確認: 該当なし(建設なし)。各路線の現在の予算と台数は `list_transport_lines`(type=bus)で確認済み。どの路線も予算は 10〜300% の範囲内で、今月の幅 ±20 に収まる。
- 接続工事: 不要
- 予備候補: なし(予算の変更で足りる)。
- 中止する条件: 議決前に、5路線のどれかの予算が上の値と違っていた場合(他の操作で変わっていた場合)は、その路線を外して残りだけ行う。

### 期待する効果

- 改善の見込み: 対象の5路線は、乗客が台数に比べて少なく、道路で止まったバスが多い。台数を約45減らすと、止まったバスの一部が減り、その周りの車の流れが少し良くなると予想する。流れ 50 を 60 にするには、この案だけでは足りない見込み。
- 数値と期限: 対象の路線の台数(`list_transport_lines`)は、実行の直後に 151 / 82 / 45 / 45 / 58 へ向かう(合計 428 → 約 383)。道路の止まった車は、基準 155 台(半径300m、中心 (2288, -930))。期限は翌月の月末(30日目)。
- 確認方法: `traffic`(x=2288, z=-930, radius=300)の blocked と congestion を、基準と同じ範囲で比べる。`vehicles_stuck`(kind=bus)で、今の止まったバスの数を比べる。流れは `traffic` の街全体の flow を見る。
- 不確かな点: 前月に似た手(m05-port-1、5路線の予算を下げた)を行った。その結果は、止まった車が 757 → 704 に減ったが、流れは動かなかった(m05-4 の記録)。今月は、台数に比べて乗客が少ない路線に絞ったが、効く量は見積もれない。止まったバスの場所が、対象路線の経路と重なるかは未確認。
- 試し: あり(効きは見積もれないため、試しとして扱う。測る数は、担当の範囲の数にする。街全体の流れは補助に使う)。
  - 仮説: 乗客の少ないバスを減らすと、道路を塞ぐバスが減り、周りの止まった車が減る。
  - 測る数: `traffic`(x=2288, z=-930, radius=300)の blocked(基準 155)、`vehicles_stuck`(kind=bus)の Congestion+Blocked on road(基準 734)。
  - 場所: 止まった車が多い (2288, -930) の周り。
  - 基準: 今の値(blocked 155、bus Congestion+Blocked on road 734)。

### 費用

- 建設費: 0(予算の変更のみ)
- 週の維持費の増え分: 0 から減る方向。バスの車両の費用が下がると見込むが、道具では額を確かめていない。バス全体の週の支出は 21,827(`economy_breakdown`)。

## 案2: 乗客がほぼない路線バス3本を廃止する

- 施策: 乗客がほぼ0で台数の多い路線 3 本を消す。路線の番号(画面の番号)は 9、19、63。路線の番号(line)は 46、131、153。

### 実行計画

- 実行可否: 確認済み
- 対象と操作順(`remove_transport_line` を3回。引数は list_transport_lines の line):

- 設置条件の確認: 該当なし(線と車両を消すだけで、建物は消さない)。3本とも `list_transport_lines`(type=bus)で、乗客が 0〜3 と確認済み。`preview_bulldoze` は建物と区間を消す道具のため、この操作には使わない。失う働き口と家は 0 と見込む(バスの路線は建物でなく、働き口も家も持たない)。
- 接続工事: 不要
- 予備候補: なし。
- 中止する条件: 議決前に、3本のどれかの乗客が 20 を超えていた場合(急に増えた場合)は、その路線を外す。残りの路線だけ行う。

### 期待する効果

- 改善の見込み: 3路線の台数 35(18+12+5)が道路から消える。乗客は合計 4 人で、ほかの路線に移ると見込む。乗客がほとんど乗らない車が道を使わなくなり、周りの止まった車が少し減ると予想する。
- 数値と期限: 路線の台数は 35 減る(確定)。道路の止まった車は、基準 155 台(半径300m、中心 (2288, -930))。期限は翌月の月末(30日目)。
- 確認方法: `list_transport_lines`(type=bus)で3本が消えたことを確かめる。`traffic` の blocked を、基準と同じ範囲で比べる。`vehicles_stuck`(kind=bus)の Congestion+Blocked on road の数を、基準 734 と比べる。
- 不確かな点: 3路線が止まったバスの多い場所を通っているかは未確認(経路の確認は未実施)。街全体の流れ 50 への効きは、見積もれない。道路の止まった車への効きも、数値は見積もれない。
- 試し: なし(台数が減ること自体は確かなので、本採用の案として出す)。

### 費用

- 週の維持費の増え分: 0 から減る方向。バスの路線の維持費は 0(`list_net_types` の Bus Line)。車両の費用の減りは、道具では確かめていない。

## 判断の根拠

- 6-3 の流れは 50(目標 60)で、止まった車は 1,238。そのうち、止まったバスは 734(道の上で Congestion+Blocked)で、大きな割合を占める。
- 止まったバスの多い路線の中で、台数に比べて乗客が少ないのは 136、139、127、126、21 の5本。予算を 20 ポイント下げるのは、今月の予算の幅 ±20 の範囲で、道具(`set_transport_line_budget`)が受け付ける範囲。案1 は、この5本を選んだ。前月の予算の引き下げ(m05)より対象を絞り、効きは試しとして測る。
- 乗客がほぼ0の3本(46、153、131)は、台数だけを道路に使っている。案2 は、この3本を消す。消す量(台数35)は確かに減るが、道路の流れへの効きは数値で見積もれない。
- 案1 と案2 は、どちらも 6-3 の施策。手の種類が違う(予算、廃止)ので、2件に分けた。
- 8-1 は、28755 の空き待ち479台が、道路の混みでなく駅の中で止まっているため、原因が分からない。確かな手が見つからないので、案は出さず、調査 1件にした。
- 地下鉄は、Metro Line 1 が乗客 0 で、乗り場 19036 と 25106 が外とつながっていない。接続の手は確かめられず、建設費も大きいため、案にしなかった。
