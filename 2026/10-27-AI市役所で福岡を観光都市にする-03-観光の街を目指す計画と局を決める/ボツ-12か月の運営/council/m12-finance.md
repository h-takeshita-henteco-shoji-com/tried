# m12 査定調書

## 案ごとの査定

### urban-1(住宅都市みどり局): 取り壊しの跡に遊び場を2か所置く(4-2 の公園などを +2)

- 査定: 可
- 理由: 建設費は遊び場 1,250 × 2 = 2,500。`list_building_types` の Regular Playground と一致し、要領の建設費の上限 250,000 に収まる。維持費の増え分は 24 × 2 = 48 / 週で、黒字の幅 4,000 に収まる。取り壊しは議決の型で、財政の費用の上限には当たらない。
- 減らした形: なし

### roads-1(道路下水道局): 南北の幹線と東西の2区間を4車線に差し替える

- 査定: 可
- 理由: 差し替えの建設費は 0(案の `test_upgrade_road` の cost 0 の合計)。`list_net_types` で Basic Road と Small 4 Lane Road は、どちらも 5,000/km・維持費 40/km/週で同じ。維持費の増えは 0。
- 減らした形: なし

### roads-2(道路下水道局): 政策 HeavyTrafficBan を街全体にかける

- 査定: 可
- 理由: `list_policies` で HeavyTrafficBan は無効、costPerWeek 0(costBasis は「no direct cost」)。建設費も維持費の増えも 0。政策の変更は月1件で、今月の案で政策を変えるのはこの案だけ。
- 減らした形: なし

### roads-3(道路下水道局): 交差点 (-1070,-650) の南の流入に譲れの標識を付ける

- 査定: 可
- 理由: 譲れの標識の費用は道具の一覧にない。案の前例(m09-roads-1、m11-roads-2)では cost 0 だった。`list_net_types` と `list_policies` のどちらにも、維持費の増えを示す項目はない。建設費と維持費の増えは 0 と見る。
- 減らした形: なし

### port-1(港湾空港局): バス28番(line 136)の予算を 140 から 120 に下げる

- 査定: 可
- 理由: `list_transport_lines` で line 136 の予算は 140、台数 133、前期の乗客 68 を確認(案の記述と一致)。予算を下げるので、建設費も維持費の増えも 0 以下。変更幅 -20 は要領の枠 ±20 に収まる。
- 減らした形: なし

### port-2(港湾空港局): 乗客0のバス11番(line 200)の予算を 100 から 80 に下げる

- 査定: 可
- 理由: `list_transport_lines` で line 200 の予算は 100、台数 36、前期の乗客 0 を確認(案の記述と一致)。予算を下げるので、費用は増えない。変更幅 -20 は枠 ±20 に収まる。port-1 と同じ bus の路線の予算を動かすが、サービス全体の予算(`economy` の bus は 150 のまま)は動かさない。
- 減らした形: なし

### fire-1(消防局): 燃えたまま放棄された3棟を取り壊す

- 査定: 可
- 理由: 取り壊しで建設費は増えない。維持費は減る方向。案が挙げた3棟は、どれも働き口と家を持たない(案の `preview_bulldoze` の記録)。取り壊しは議決の型で、費用の上限には当たらない。取り壊しの支払いは道具の一覧にないため、0 として扱った(この調書では確かめていない)。
- 減らした形: なし

### fire-2(消防局): 火事の多い地区に消防署を1棟足す(試し)

- 査定: 可
- 理由: `list_building_types` の Fire House は建設費 12,000、維持費 560 / 週で、案の記述と一致。支線の道路 160 を足し、建設費は計 12,160。維持費の増えは 560 + 道路の分(約 1)で、黒字の幅 4,000 に収まる。建設費は要領の上限 250,000 に収まる。
- 減らした形: なし

## 合わせた費用と上限

- 「可」と「減額」の案を合わせた建設費: 14,660(urban-1 の 2,500 + fire-2 の 12,160。ほかは 0)
- 合わせた週の維持費の増え分: 約 610 / 週(urban-1 の 48 + fire-2 の 560 + 道路の約 1。port-1、port-2、fire-1 は減る方向のため数えない)
- 市長が選ぶときの建設費の上限: 250,000(要領の建設費の上限のまま。合わせた 14,660 は収まる)
- 市長が選ぶときの週の維持費の上限: 4,000(要領の幅のまま。合わせた約 610 は収まる)

- economy(経済観光文化局): 案なし(調査のみ)。調査は費用を持たないため、査定しない。
- education(教育委員会): 案なし。

## 税の案

なし。週の収支は +5,111 で黒字、所持金は合わせた建設費を引いても出発点 2,082,287 を上回る(2,359,826 − 14,660 = 2,345,166)。税を動かす必要がない。

## 判断の根拠

各案の建設費と維持費は、道具の一覧(`list_building_types`、`list_net_types`、`list_policies`)で確かめた。合わせた建設費 14,660 は要領の上限 250,000 に、維持費の増え約 610 は黒字の幅 4,000 に収まる。週の収支は +5,111 のまま残り、所持金は出発点 2,082,287 を下回らない。税と融資は動かさない。
