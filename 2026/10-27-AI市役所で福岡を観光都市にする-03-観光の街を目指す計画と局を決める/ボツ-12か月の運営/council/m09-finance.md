# m09 査定調書

## 案ごとの査定

### urban-1(住宅都市みどり局): (3190,-345) に Regular Playground を1棟

- 査定: 可
- 理由: 建設費 1,250 は、予算編成要領の建設費の上限 500,000 に収まる。週の維持費の増え分 24 は、上限 5,000 に収まる。`list_building_types` の Regular Playground が、建設費 1,250、維持費 24/週と一致する。
- 減らした形: なし

### roads-1(道路下水道局): 交差点 (2700,330) の南の流入 19421 に譲れの標識を付ける(試し)

- 査定: 可
- 理由: 標識は建設費も維持費も、道具の一覧にない。`list_net_types` や `list_building_types` では費用を確かめられなかった。案は費用 0 と見込む。上限に当たる額が出ないため、実行後に `economy_breakdown` と `city_info` の所持金・週の収支で確かめる。
- 減らした形: なし

### health-1(保健環境局): 政策 Recycling をかけ、住宅低密度の税を 9% から 11% に上げる

- 査定: 不可
- 理由: 政策 Recycling の週の費用は 0 だが、住宅の税収が 5% 減る。`economy_breakdown` の Residential の週の収入 269,285 の 5% で、約 13,464/週の減りになる。週の収支は +10,058 のため、税の手当てなしでは約 -3,406 になり、守る線(週の収支を黒字に保つ)を破る。案は税で埋める見込みだが、埋まる額は確かめられていない。確かめられない前提で守る線を越える案は、通せない。
- 減らした形: なし(政策だけの形では、税収の減りを埋められず、守る線を越える)

### health-2(保健環境局): 道路 x=-1820(z=-1224 から -1800)の Basic Road を Small 4 Lane Road に差し替える

- 査定: 可
- 理由: 差し替えの費用は 0(案の test の結果)。維持費の単価は、`list_net_types` で Basic Road と Small 4 Lane Road がどちらも 40/km/週のため、増え分は 0 と見込む。取り壊しは 0 件。`economy_breakdown` の道路の実績単価には差があるが、差し替える長さは数百 m のため、増えても数円/週に収まる。
- 減らした形: なし

### 査定対象外(記録のみ)

- port-1(港湾空港局): バス路線11番の予算を 100 から 80 に下げる案。案の中に「実行可否: 未確認」「停留所の座標が未確認」とあり、実行条件が確かめられていないため、呼び出しの指示に従い査定対象外とした。
- 経済観光文化局、教育委員会、消防局: 案なし。査定しない。

## 合わせた費用と上限

- 「可」と「減額」の案を合わせた建設費: 1,250(urban-1 の 1,250。roads-1 と health-2 は 0)
- 合わせた週の維持費の増え分: 24(urban-1 の 24。roads-1 は 0 と見込み、health-2 は 0)
- 市長が選ぶときの建設費の上限: 500,000(予算編成要領の上限のまま)
- 市長が選ぶときの週の維持費の上限: 5,000(予算編成要領の上限のまま)

## 税の案

なし。health-1 の税の手当ては、税収の減りを埋める見込みが未確認のため、財政局の税の案にはしない。残りの税の案も、今月の週の収支が黒字(+10,058)で、税を動かす理由がない。

## 判断の根拠

urban-1 と health-2 は、建設費と維持費が上限と枠に収まり、査定は可とした。合わせた建設費は 1,250、維持費の増えは 24 で、どちらも上限の内に余る。health-1 は、政策の費用は 0 でも税収の減りが 13,464/週あり、今の黒字 10,058 を超える。税で埋める見込みは確かめられず、守る線を破るおそれがあるため不可とした。roads-1 は費用を道具で確かめられないが、標識は費用の見込みが小さい。実行後の `economy_breakdown` で確かめる。

## 捨てたもの

- health-1 の減額形(政策 Recycling だけ、税は据え置き): 週の収支が約 -3,406 になり、守る線を破るため採らない。
- health-1 の税の +1(10%)の形: 税収の埋めは +1 では半分にも届かない見込みで、確かめられない。今月は採らない。
- health-1 の税を財政局の税の案として添える形: 埋まる額が未確認のまま守る線を賭けにするため、添えない。
- port-1(バス路線11番の予算 80): 実行可否が未確認のため、査定対象外。
- roads-1 の費用の確認の代わりに「不可」とする案: 標識の費用は 0 の見込みで、確かめる手は実行後の `economy_breakdown` にある。上限を超える根拠がないため、不可にしない。
