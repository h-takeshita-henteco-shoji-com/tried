# m09 港湾空港局の案

## 案1: バス路線11番の台数を減らす(予算 100 → 80)

### 施策

- 案の id: port-1
- 施策: バス路線11番(line 200、14.4km、停留所8)の路線予算を 100 から 80 に下げ、走る台数を 36 から減らす。乗客は前の集計期間 0、今 7。
- 議決: 予算

### 実行計画

- 実行可否: 未確認
- 対象と操作順: 1. `list_transport_lines`(type=bus, number=11)で路線を確かめる(確認済み: line 200、停留所8、台数36、予算100、乗客 0 → 7)。2. `set_transport_line_budget`(line=200, percent=80)。議決後に実行する。
- 設置条件の確認: 路線の場所(停留所の座標)と、`m08-2` で予算を下げた範囲(2288,-930 の半径300m)との重なりは未確認。停留所の座標は `list_transport_lines` の出力に無く、`net_near` や `buildings_near` で確かめていない。
- 接続工事: 不要
- 予備候補: なし
- 中止する条件: 路線の停留所が (2288,-930) 半径300m に入る、または予算を下げた後も乗客が 0 のままで、台数の減りが見えない場合は見送る。

### 期待する効果

- 改善の見込み: 乗客がほぼない路線の台数を減らすと、道を走るバスの台数が減り、6-3 の流れを少し上げる見込み。効果の量は見積もれない。前月の `m08-2`(バス予算の削減)は流れを 50→52 にしたが、Blocked系は約750のまま残った。今回の案は、その効きを大きくするものではない。
- 数値と期限: 6-3 の流れ 52(目標60以上)。Blocked系は 704。期限は見回り1、見回り2、月末(約30日)。
- 確認方法: `traffic`(x, z を路線の周り、半径 500)で flow と blocked。`list_transport_lines`(number=11)で台数と乗客。今の値 flow 52、台数 36、乗客 0 と比べる。
- 不確かな点: 路線の場所が (2288,-930) の範囲と重なると、m08-2 の効果と混ざる。乗客 0 の路線の台数を減らしても、流れがほとんど動かないおそれがある。
- 試し: 効き目が分からないため試し。仮説: 乗客の少ないバス路線の台数を減らすと、道の混みが減り流れが上がる。測る数: `traffic` の flow と blocked、`list_transport_lines` の台数と乗客。場所: 路線11番の周り。基準: flow 52、台数 36、乗客 0 → 7。編成方針の「分からないこと」にはない。6-3 の流れの原因確認。
