# 米価の予測の設計(#184)

米価の予測を、手軽な方法から準備の要る方法まで、段に分けて比べる。
この版は、別のエージェントに反証させたあとに直したもの(2026-11-22)。

## 1. 何を予測するか

米の値段は、新米が出る9月に段差がついて変わる。そのあとの1年はほぼ横ばいになる。
そのため、毎月の細かい動きではなく、年産ごとの水準を予測する。

- 予測する値: 農水省「米の相対取引価格」の全銘柄平均(円/玄米60kg)
- 主な答え: 新米の出回り初期(9〜10月の平均)。答え合わせが2か月で済み、平年なら年産平均とほぼ同じになる
  - 2008〜2023年産では、9〜10月の平均と年産平均の比は0.98〜1.03だった。値段が荒れた年は外れる(2024年産0.901、2025年産1.076)
- 年産平均も参考に出す。その場合は±10%の幅を添える
- 福岡の銘柄は、全国との比で出す。比は年産平均どうしでとり、月の比は使わない(取引の薄い月の値が荒れるため)
- 予測の時点: 3月・7月・8月末。今日は8月末だけを扱う

## 2. 値段の直し方

- 消費税を月ごとに抜く。2014年3月分までは5%、4月分からは8%(H25の表の注記で確認)
  - 米は飲食料品なので、2019年10月以降も軽減税率の8%のはず。農水省の注記で確かめる
- 消費者物価指数で割った実質価格も見る
- 大きな変化の印を記録する: 2018年の生産調整の廃止、2025年の備蓄米の放出と増産への方針転換
- 2009年産(2009年9月〜2010年8月)は月ごとの表がない。年産平均だけを使う

## 3. 段と試験

### 段

段を上がるごとに、1つだけ足す。Claude を使う段は、「知識を伏せるか」と「需給の表を渡すか」の2×2で組む。

| 段 | 方法 | 渡す情報 | 今日 |
|---|---|---|---|
| 0 | 前の年と同じ(前の年産の平均、または8月の値) | 価格 | する |
| 2 | 年産平均の対数のランダムウォーク、AR(1) | 価格(年ごと) | する |
| 1a | Claude。2026年の出来事を使わせない | 価格 | する |
| 1b | Claude。知識を使ってよい | 価格 | する |
| 3 | Claude。需給の表を足す | 価格+需給3つ | する |
| 4 | 在庫率の回帰(対数か逆数で入れる) | 価格+在庫+需要 | 次 |
| 5 | 作付意向・天候・品質を足し、3時点で予測 | さらに足す | 次 |
| 6 | Claude にニュースだけを足す | 価格+ニュース | 次 |

- 月ごとの SARIMA と Chronos は使わない。9月の段差を学べず、ランダムウォークに近づくため
- 段3の需給3つ: 6月末の民間在庫、作付意向、2025年産の生産量
- Claude は回すたびに答えが変わる。各条件を5回以上回し、答えのばらつきを出す
- 段1は、答える前に「この時点で何を知っているか」を書かせ、知識の中身を記録する

### 試験

- **A. 2026年産(8月末の時点で予測)**: Claude が知らない唯一の問題。答えは9〜10月の平均(21,293円と21,434円)
  - 1問だけなので、偶然の当たり外れが大きい。結論は事例として書く
- **B. 過去の年産を1年ずつ(段0・2・4・5)**: 2016〜2025年産の10問。集計の指標(的中率、区間に入った割合)は10問では偶然と区別できない。年産ごとの予測・幅・実績を表で示す
  - 2016〜2023年(平年)と2024〜2026年(急変)を分けて示す
- **C. 年・単位・品目を伏せて Claude に渡す(次の子テーマ)**: 先に「これは何のデータか」を当てさせ、当てたら無効にする。比べるために、作り物の系列を置く
- **前向き試験**: 2026年11月〜2027年8月の予測を今日固定し、農水省の発表ごとに答え合わせする。年の数が少ない弱さを補う唯一の方法なので、優先する

### 答えを見たあとの調整を防ぐ

試験Aの答えは、作業者も作業中の Claude もすでに見ている。そのため、次のように防ぐ。

- 回す前に、指示文の全文・モデル・入力ファイルを log.md に書き、ファイルのハッシュを残す
- 入力ファイルから、2026年9月以降の行を消す
- Claude は、リポジトリを読めない新しい会話で呼ぶ(サブエージェントは答えの表を読めてしまう)
- 指示文は、一度回したら直さない。直す場合は、直したことと理由を記録する

## 4. 比べる相手

- 「前の年と同じ」(段0)
- 堂島取引所のコメ指数先物(堂島コメ平均): 上場は2024年8月13日。試験Aの1点だけで比べる
  - 対象は全国の銘柄の現物価格で、相対取引価格と定義が違う。重なる期間で差を測ってから比べる
- 米穀機構「米取引関係者の判断に関する調査」の見通しDI: 水準ではないので、上がるか下がるかの向きだけを比べる

## 5. データ

### 使ってよいデータ

公開統計に限らず、著作権の点で使えるものは使ってよい(2026-11-22 に作業者が決定)。

- 統計の数字や価格などの事実は、著作物ではない。出典を書いて使う
- 官公庁のデータは、政府標準利用規約などに従い、出典を書く。元のファイルもリポジトリに残す
- 報道や JA の資料は、数字(概算金など)だけを抜き出し、出典を書く。記事の文章は転載しない
- 有料のデータや、利用規約で再配布を禁じたデータは、リポジトリに置かない

### 説明に使うデータの候補

| 分け方 | データ | 出どころ | 備考 |
|---|---|---|---|
| 量 | 民間在庫(月ごと) | 農水省「米穀の民間在庫の推移」 | 6月末の値が中心 |
| 量 | 主食用米の生産量・作付面積 | 農水省 作物統計 | |
| 量 | 需要量 | 農水省 基本指針 | |
| 量 | 備蓄米の買い入れ・放出、MA米・SBS | 農水省 | |
| 前もって | 作付意向 | 農水省(1月末・4月末・6月末) | 1月末は未確認 |
| 前もって | 7〜8月の気温・日照・台風 | 気象庁 過去の気象データ | |
| 前もって | 1等米の割合 | 農水省 農産物検査結果 | |
| 前もって | 作況単収指数 | 農水省 | 作況指数は2025年に廃止。古い指数とつなげず、収穫量の実数を使う |
| 見通し | JA の概算金 | 各JA・報道 | 8月末の予測で最も効くはず |
| 見通し | 先物、見通しDI | 堂島取引所、米穀機構 | 4を参照 |
| 需要 | 小売物価、家計調査、訪日客数 | 総務省、日本政府観光局 | |
| コスト | 米生産費、肥料・燃料 | 農水省 | |

- 17年分では、回帰の説明変数は1〜2個が上限。段5は、過学習しないよう変数を絞る
- 在庫と値段の関係は2023年産までのデータで求め、2024〜2026年は当てられるかの試験に使う。値段が上がると備蓄米が放出されて在庫が増えるため、2024年以降は関係が崩れている可能性がある
- 発表日は、在庫と作付意向について記録する。価格は直したあとの版しか取れないので、発表時点の値は記録しない

## 6. 道具

- statsmodels(年ごとの時系列、回帰)、pandas
- Claude: 新しい会話で呼ぶ(3を参照)
- 使わない: 月ごとの SARIMA、Chronos・TimesFM(今日は外す)、Prophet、LSTM。PyMC は、予測の幅が足りないと分かったら使う

## 7. 書き方

- 予測は幅をつけて示す。特定の政策の主張にはしない
- 2024〜2026年は、事例として書く
