## 試したこと

#57 の素材メモ から、3種類のプロンプトでAIに文章を書かせる。
- 素朴な指示: 「面白く書いて」とだけ頼む
- 役割を与える: 書き手の役割を渡す
- 技法を名指しする: 起承転結、問い先行などの技法名を渡す

試す前に、プロンプトごとの予想を1行ずつ書く。
書いた文章を、#52 で残した物差しで測る。指標は、文の長さの変動係数と平均、AIの読者の驚き率、文の役割の数である。
成果物は、予想、プロンプト、生成した文章、計測の表、予想との当たり外れ。

### 条件

- 時間の上限は60分
- 素材と共通条件は #57 のものを使う(`2026/10-13-AIが書いた文章はなぜ面白くないのか-06-交絡のない素材メモを作る/assets/`)
- 基準線は、書き方の指示なしの #57 の v3(seed 1〜3)
- プロンプトは3つ(`assets/prompts/`)。共通の指示文の後に足す。2と3は、1の素朴な指示を含む。1との差で、役割と技法の効果を見るため
  - 1. 素朴な指示: 「読者が面白いと感じる随筆にしてください。」
  - 2. 役割を与える: 「あなたは新聞で長く随筆欄を担当してきた名文家です。」+ 1
  - 3. 技法を名指しする: 「起承転結で構成してください。」+ 1
- 各プロンプトを seed 1〜3 で3本ずつ書かせる
- 原文「線香の火」は、計測が終わってから読む

### 予想(生成の前に、やってみ太郎が書いた)

指示なしの文章と比べた変化の予想。原文も生成文も読まずに書いた。

- 1. 素朴な指示: なるべく冗談をまぜ、笑いを誘うような文章になる
  - 承の量: 変わらず / 先出し: なし / 驚き: なし / 緩急: あり / 結びの比喩: あり
- 2. 役割を与える: 関連する科学的なトピックを織り交ぜた文章になる
  - 承の量: 変わらず / 先出し: なし / 驚き: あり / 緩急: あり / 結びの比喩: 不明(50%)
- 3. 技法を名指しする: 2に合わせてストーリーの要素が追加された文章になる
  - 承の量: 増える / 先出し: 不明(50%) / 驚き: あり / 緩急: あり / 結びの比喩: 不明(50%)

### 実際にやったこと

- 3つのプロンプトで、seed 1〜3 の9本を書かせた(`assets/texts/`)。基準線の3本は #57 の v3 から写した(`assets/texts/0-none/`)
  - 分量が外れたのは役割の seed 3 の1本(952字)で、生成し直した。外れた1本は `assets/texts/2-role/rejected/` に残した
- 12本を素材メモと照合した(`code/material-memo/check_memo.py`、Opus 5.5)。結果は各文章の `.check.json`
  - P1(筆者の名前と肩書き)は12本中11本で「抜け」と出た。一人称の語り手は名乗らないので、P1 は語り手の設定として照合から外した
  - 足しのある文章は、生成し直さずに数えることにした(やってみ太郎の判断)。生成し直すと、指示の効果そのものを消すため
- #52 の物差しで測った(`assets/measure/`)
  - 文の長さ: `sentence-length.md`
  - 文の役割と関連: Opus 5.5 が1回見分けた(`labeling/run1`)。数えた結果は `role-counts.md` と `graph-metrics.md`
  - AIの読者: Haiku 4.5 が1本につき5回読んだ(`reader/`)。#52 は10回だったが、60分に収めるため減らした。指標は `reader-metrics.md`
- `code/yardstick/reader_metrics.py` を直した。#47 の判断との照合は、原文と書き直しの組があるときだけ出す。見出しの回数を実際の回数にした
- 物差しのスクリプトは、uv で一時的にライブラリを入れて動かした(krippendorff、sentence-transformers)。#52 の環境は残っていなかった

- 1. 素朴な指示
  - 冗談をまぜる: 外れ。冗談はなかった
  - 承の量 変わらず: 外れ。減った(9.0 → 6.3)
  - 先出し なし: 一部。3本中1本は題からの先出しが0になったが、2本は残った
  - 驚き なし: 外れ。驚き率は少し上がった(0.53 → 0.67)。ただし幅の中
  - 緩急 あり: 当たり。4条件で一番上がった
  - 結びの比喩 あり: 当たり
- 2. 役割を与える
  - 科学の話題を織り交ぜる: 外れ。足したのは知識ではなく、筆者の体験の作り話だった
  - 承の量 変わらず: 当たり(9.0 → 8.7)。ただし3本の幅が1〜17と大きい
  - 先出し なし: 一部。0になったのは3本中1本
  - 驚き あり: 一部。驚き率は幅の中だが、予想が外れた割合は3本とも0.60で、4条件で一番高かった
  - 緩急 あり: 少し上がった(0.393 → 0.423)
  - 結びの比喩 50%: 12本とも残った
- 3. 技法を名指しする

  - 結びの比喩 50%: 12本とも残った

## 学び

- 「面白く」と頼むと、AIは内容を足しに行った。足したのは冗談や知識ではなく、筆者の体験の作り話だった。役割や技法で指示を強めるほど、足しは増えた(2件 → 3件 → 6件)
- 起承転結と名指しすると、承は増えたが、驚きは減った。形を整えることと、読者の予想を裏切ることは別のようだ
- 結びの比喩は、どの指示でも消えなかった。指示で直らない欠点の候補になる。#59 の「禁止する」で消えるかを確かめたい
- 題は12本とも「線香の火」系で、ほぼ動かなかった。題での先出しも、どの指示でも3本そろっては消えなかった
- 同じ条件の3本の幅が、条件どうしの差より大きい指標が多かった(承の数、驚き率)。3本ずつ、読み5回では、傾向を示すのがやっとである
- 照合の決まりは、AIの癖とぶつかった。決まりどおりに生成し直すと、指示の効果を消してしまう。照合は「直すための関門」ではなく「数える指標」として扱う方がよい
