# m01 予算編成要領

## 今月の枠

- 建設費の上限: 300,000(所持金 2,082,287 の半分は 1,041,143 まで。ここでは約14%に絞る)
- 週の維持費を増やせる幅: 4,000(週の収支 +9,965 の黒字の範囲。その約4割)
- 税を動かせる幅: ±2
- 予算を動かせる幅: ±10

## 局への伝え

- 建設費と維持費を、型の上限より狭くした。週の収支が +9,965 で薄いため。所持金も大きく減らさない。
- 予算の幅は ±10 にする。バスの予算は今 150%、維持費は 22,051 / 週。+20 だと、比例の概算で約 +2,900 / 週になる。維持費の枠の大半を使うため。
- 融資は借りない。融資の枠は3つとも解禁済みだが、所持金が十分。借りると週の返済が増え、週の収支を下げる。

## 見たもの

- `city_info`: 人口 178,872、所持金 2,082,287、週の収入 342,140、週の支出 332,175(差し引き +9,965)、dialog なし
- `economy`: 税は住宅(低)9、住宅(高)7、商業(低)9、商業(高)3、工業3、事務所3。予算はバス・警察・医療・公園 150、消防 140、教育 120
- `economy_breakdown`: 政策の費用は週 10,665(かかっている分)。維持費は医療 75,840、電気 35,392、教育 48,120、公共交通 38,172(バス 22,051)、警察 34,800、消防 31,920、水 19,351
- `list_loans`: 融資の枠は3つ(20,000 / 60,000 / 200,000)とも未借入。融資の週の支出は 0

## 判断の根拠

所持金は約208万で、建設費の上限の型では約104万まで使える。ただ週の黒字は +9,965 しかなく、黒字を保つ守る線と、赤字を2回続けない公約がある。そのため維持費の増えは黒字の約4割に抑え、建設費は試しの規模の 300,000 に絞る。予算の幅も ±10 に狭め、予算を上げても黒字が消えないようにする。

## 捨てたもの

- 建設費 1,041,143(所持金の半分): 所持金が半分になり、大きく減らさない守る線に反する。
- 維持費 9,965(黒字の全部): 黒字がゼロになり、黒字に保つ守る線を満たせない。
- 予算 ±20: バスを +20 すると、維持費の枠の大半を使う。
- 融資: 所持金が十分で、借りると週の返済の分だけ黒字が減る。
