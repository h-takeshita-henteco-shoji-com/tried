## 案1: 地下鉄ネットワークの拡張で交通流を改善する

### 施策

- 案の id: port-1
- 施策: 地下鉄路線を新設し、駅3か所を建設。駅位置は(2910, 44)、(3100, 46)、(700, 700)。駅を配置してから路線を引き、停留所を3か所以上経由する環状路線を作る
- 議決: 不要

### 実行計画

- 実行可否: 未確認
- 対象と操作順:
  1. `place_building` で Metro Entrance を (2910, 44) に配置(既存駅 19036 の近く、外部つながり2)
  2. `place_building` で Metro Entrance を (3100, 46) に配置(既存駅 25106 の近く、外部つながり2)
  3. `place_building` で Overground Metro Station 01 を (700, 700) に配置(人口集中地区)
  4. `create_transport_line` で metro 路線を作成し、上記3駅と既存駅をつなぐ環状線とする
- 設置条件の確認: 未確認。既存の駅と重なる可能性、周辺建物との衝突、地形を確認する必要あり
- 接続工事: 不要(駅の周辺に既に道路あり)
- 予備候補: (1000, 1000)、(1500, -500)。同じ条件で確認が必要
- 中止する条件: 駅の配置に失敗した場合。駅建設後に路線を試す

### 期待する効果

- 改善の見込み: 交通の流れが 51%で目標 60%に遠い。地下鉄は乗用車の需要を減らし、地上の道路を空ける。現在の地下鉄利用は 0 名/週でほぼ機能していないため、ネットワークを拡張すれば大幅な改善が期待できる
- 数値と期限: 交通の流れ 51%(目標 60%以上)。確認は月末と2か月目の月例で、複数月かけて効果を測定する
- 確認方法: `traffic` の flow を同じ条件で測定。閾値は 60%以上
- 不確かな点: 数値は見積もれない。地下鉄利用者数と流れの関係、建設による周辺への影響が不明。試しとして実施し、複数月で効果を確認する
- 試し: あり。仮説は「地下鉄網の拡張が地上の乗用車を減らし、交通流を改善する」。測る数は `traffic` の flow と blocked の数(同じ範囲)。場所は街全体。基準は現在の flow 51%、blocked 1,008

### 費用

- 建設費: Metro Entrance × 2 = 30,000、Overground Metro Station 01 = 10,000、路線費用は未確認。概算 50,000(試しで正確値を確認)
- 週の維持費の増え分: Metro Entrance × 2 = 480、Overground Metro Station 01 = 160、概算 640(試しで正確値を確認)

### 戻せるか

戻せる。路線を削除し、駅を取り壊すことで復元可能。

## 案2: FreeTransport 政策の有効化で公共交通利用を促進する

### 施策

- 案の id: port-2
- 施策: FreeTransport 政策を有効にし、公共交通のチケット収入を 0 にして、利用者を大幅に増やす
- 議決: 不要

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: `set_policy` で FreeTransport を有効化(active=True)
- 設置条件の確認: `list_policies` で確認済み。FreeTransport は costPerWeek = 0(直接費用なし)、costBasis = "no direct cost. Public transport ticket income becomes 0"
- 接続工事: 不要
- 予備候補: なし
- 中止する条件: 週の支出が 332,175 から上昇し、黒字(+9,965)が保てなくなる場合

### 期待する効果

- 改善の見込み: 現在のバス路線の乗客は週約 2,800 名(運賃 1.0/人で収入 2,800)。チケット料金を 0 にすることで、利用者が大幅に増加すると予想される。これは交通の流れ 51%(目標 60%)の改善に寄与する
- 数値と期限: バス乗客数の増加(目前の週 2,800 名から)。確認は月末で、初月の効果を測定。流れの改善は複数月必要と予想
- 確認方法: `list_transport_lines` の passengers を同じ路線で測定。`traffic` の flow でも確認
- 不確かな点: 利用者増加の量を見積もれない。現在のバスの容量を考えると、著しい増加は起きない可能性もある。数値は試してから確認する
- 試し: あり。仮説は「無料公共交通が利用者を増やし、地上交通を減らす」。測る数は `list_transport_lines` の passengers 合計と `traffic` の flow。場所は街全体。基準は passengers 2,800/週、flow 51%

### 費用

- 建設費: 0
- 週の維持費の増え分: 0(政策の直接費用なし。ただしチケット収入 −2,800/週)

### 戻せるか

戻せる。政策を無効化すれば復元。

### 前の月の答え合わせ

### 市の計画

## 案3: 貨物センター周辺の代替ルート構築で荷物の滞留を軽減する

### 施策

- 案の id: port-3
- 施策: 停止中の貨物センター 3940(2380, -1282)、4740(3955, -1270)を再起動し、貨物センター 28755(3449, -1555)からの荷物流を分散させる。あわせて道路の接続を強化
- 議決: 不要

### 実行計画

- 実行可否: 未確認
- 対象と操作順:
  1. `set_building_active` で Cargo Center 3940 を有効化(active=True)
  2. `set_building_active` で Cargo Center 4740 を有効化(active=True)
  3. これらの施設への道路接続を確認し、必要に応じて道路を接続
- 設置条件の確認: `cargo` で 3940、4740 の vehiclesLeaving / Arriving を確認。現在は 0/0 で機能していない。周辺道路の接続状況を `buildings_near` で確認必要
- 接続工事: 周辺道路への接続確認後、必要なら道路を引く。接続先は transport_reach から既存の外部つながり点
- 予備候補: Cargo Center 13893(3529, -1555)も同様に確認可能
- 中止する条件: 施設の有効化後も vehiclesLeaving が 0 のままの場合。道路接続に失敗した場合

### 期待する効果

- 改善の見込み: 貨物センター 28755 では 492 台のトラックが停止している(目標 250 以下)。複数の施設を同時稼働させることで、流入荷物を複数ルートに分散させ、1施設あたりの停止車数を削減できる。3施設稼働で 3 分の 1 程度に軽減される見込み
- 数値と期限: stoppedInBuildings 506(現在、目標 250 以下)。確認は月末で 250 以下を目指す。複数月かかる可能性あり
- 確認方法: `cargo` の stoppedInBuildings と stoppedInBuildingsTop で確認。同じ条件で 28755 の値を測定
- 不確かな点: 他の施設の有効化と流入荷物の関係を確認できない。施設が有効化されても交通インフラが不足していれば効果が出ない可能性。試してから複数月で確認
- 試し: あり。仮説は「複数の貨物施設の並列稼働が、1施設への荷物集中を軽減する」。測る数は `cargo` の stoppedInBuildingsTop 各施設の stoppedTrucks。場所は各貨物施設。基準は 28755 の 492

### 費用

- 建設費: 0(既存施設の有効化のみ)
- 週の維持費の増え分: 既存の Cargo Center の維持費 1,440/週 × 2 = 2,880(上限 7,000 内)

### 戻せるか

戻せる。施設を無効化すれば停止。

## 案5: 港湾空港局の公共交通予算を増やし、既存バス路線の車両数を大幅に増強する

### 施策

- 案の id: port-5
- 施策: バス予算を現在の 100〜150%から最大 150%に引き上げ、特に低利用路線の台数を増やして利便性を向上させ、乗客を増加させる。これにより交通流 51%(目標 60%)の改善に寄与
- 議決: 要(予算)

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: `set_budget` で bus の percent を 150 に設定
- 設置条件の確認: `list_transport_lines` で確認済み。バス路線 82 本、総台数約 1,500 台。予算増加で台数上限が引き上がる
- 接続工事: 不要
- 予備候補: なし
- 中止する条件: 週の支出が黒字を保てなくなる場合

### 期待する効果

- 改善の見込み: 現在のバス乗客は週約 2,800 名で、多くの路線が低利用。予算を増やすことで、ゲーム内の台数上限が引き上がり、低利用路線での台数を増やせる。乗客が増えれば地上交通から公共交通への転換が進み、交通流が改善される
- 数値と期限: バス乗客数の増加(目前の週 2,800 名から)、交通流 51% → 60%。確認は月末と複数月後
- 確認方法: `list_transport_lines` の targetVehicles と passengers を同じ路線で測定。`traffic` の flow でも確認
- 不確かな点: 予算増加による乗客増加の量が見積もれない。バスの容量が現在のネットワークで十分か不明
- 試し: あり。仮説は「バス台数の増加が、路線の乗客容量を高め、利用者を増やす」。測る数は `list_transport_lines` の passengers 合計と targetVehicles。場所は街全体。基準は passengers 2,800/週

### 費用

- 建設費: 0
- 週の維持費の増え分: 現在のバス予算から 150% への増加。基数から +50% の増分。現在の予算額から未確認。概算 1,000/週(試しで確認)

### 戻せるか

戻せる。予算を 100% に戻す。

- `cargo`: stoppedTrucks 802、stoppedInBuildings 506(貨物センター 28755 が 492)。駅・港の敷地で止まったトラック 506、目標 250 以下から遠い。他の施設は vehiclesLeaving = 0 で機能停止状態

- `traffic`: 流れ 51%、止まった車 1,008。貨物センター周辺 (2309, -925) に 61 台が集中。密度 100 の区間が 10 か所

- `transport_reach`: Cargo Center 14580、16572、48243 が外部未接続で、train line の gap あり。これらの施設は使われていない

## 判断の根拠

編成方針の重点 3 つ(観光・交通・物流)に対応する案を 5 件提示した。

1. 案 1・2・5 は交通流改善(6-3)へ。メトロ拡張、FreeTransport、バス予算増で、地上交通を公共交通へシフト
2. 案 3 は物流改善(8-1)へ。停止中の施設を再起動し、集中を分散
3. 案 4 は観光支援(5-1、5-2)と交通流改善(6-3)の両立を狙い、観光地へのバスアクセスを強化

これらは相互補完的で、複数実施を想定している。案 2(FreeTransport)と案 5(バス予算増)は併用で効果が高まる。予算と週の支出で上限内に収まる。

## 捨てたもの

- 道路拡幅(Medium Road への昇格): 貨物センター周辺の既存道路の拡幅は、周辺建物(High School 48164 など)との衝突で実行不可。別ルートの構築が必要だが、都市計画上の制約で困難
- 新規の駅・港の追加建設: 貨物センター 28755 の容量改善には、敷地内の処理能力向上が先決。新規施設追加では根本解決にならない
- 汚染・ごみ対策(4-3、4-4): 編成方針の重点外のため、月は観光・交通・物流に予算を集中
- 融資: 現在の所持金と黒字で、融資不要
