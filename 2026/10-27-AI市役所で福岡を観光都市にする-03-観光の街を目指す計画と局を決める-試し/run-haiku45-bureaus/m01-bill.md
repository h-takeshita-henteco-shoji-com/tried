# m01 まとめと議案

今月は、費用がかからず、実行条件を確認できた2件を施策に選びました。
建設案と予算案は、必須条件の未確認や、数字の誤りがあるため、理由を添えて局に返します。

## 施策

### m01-1 RecreationalUse 政策を有効にする(観光の試し)

- 元にした局の案: urban-1,economy-4。手直しした点: 同じ政策の案なので1件にまとめた。測る数は両局の分を引き継ぐ
- 議決: 要らない
- 採択理由: `list_policies` で RecreationalUse は costPerWeek 0(直接費用なし)と確認した。観光の数字(今いる観光客 1,646、魅力度の平均 6、Tourism 45)が目標から遠く、費用なしで動かせる手がこれだけだった。
- 今月選んだ理由: 観光は市長の方針で、今月の重点1。週の黒字 +9,965 を減らさず、来月以降の観光施設の維持費の余地も残せる。
- 公約: 4(観光客を増やし、観光で稼ぐ)
- 市の計画: 5-1、5-2 観光、4-2 花や緑による潤い
- 操作: `set_policy(name="RecreationalUse", active=True)`
- 実行計画: 街全体にかける政策で、設置条件はない。ゲームが断ったら中止する。ほかに変える値はない
- 費用: 建設費 0、週の維持費の増え分 0
- 予想: 今いる観光客 1,646 → 1,800〜2,000、訪問 139 → 160〜180(economy 局の見込み。月末に `city_info`)。高密度住宅の地価の平均 58 → 62 以上は urban 局の見込み(`building_stats` の ResidentialHigh、街全体)。政策の効果は説明に書かれておらず、効かない可能性もある。期限は月末と2か月目の月例
- 試し: あり。分からないことの一覧「訪問は多いのに Tourism の収入が 45」の項目に関わる。仮説は「RecreationalUse で観光客と魅力度が増える」。測る数は `city_info` の tourists(now、visits)、`economy_breakdown` の Tourism、`map_layer` の attractiveness の平均、`building_stats` の高密度住宅の地価の平均。場所は街全体。基準は 1,646 / 139 / 45 / 6 / 58。同じ月に観光と地価を動かす施策はほかに重ねない
- ほかの局への響き: 費用 0 なので財政に響かない。公園の効果が上がると地価が動く可能性があり、urban 局の地価の数字にも出る
- 戻せるか: 戻せる
- 取り壊しのとき: 該当しない

### m01-2 交差点(2100, 309)に信号を付ける(交通の試し)

- 元にした局の案: roads-3。手直しした点: 測る範囲を街全体から交差点の周り(半径200m)に絞った。街全体の流れは月の中で他の要因も受けるため
- 議決: 要らない
- 採択理由: `junction_info(2100, 309)` で、40m 以内に節点 30603(2110, 330)があり、3本の Small 4 Lane Road が交わる交差点で canEnableLights が true と確認した。道路下水道局の案は、ここで50台が止まっているとする。
- 今月選んだ理由: 交通の流れ 51%(目標 60%)は重点2。費用 0 で戻せ、実行条件を市長も確かめられた交差点はここだけだった。
- 公約: なし(交通の流れは公約にないが、観光客の移動と物流の下地になる)
- 市の計画: 6-3 公共交通を主軸とした交通体系
- 操作: `set_traffic_lights(x=2100, z=309, active=True)`。ゲームは節点 30603(2110, 330)に信号を付ける。付かなければ座標を (2110, 330) にして1回だけやり直す
- 実行計画: 確認済みの対象は節点 30603 の1つ。予備候補はない。canEnableLights が false になっていたら中止する
- 費用: 建設費 0、週の維持費の増え分 0
- 予想: この交差点周りで止まった車が減る(基準は roads 局の見立ての50台)。街全体の流れ 51% はほぼ動かない見込み(1か所だけのため)。確認は月末に `traffic(x=2110, z=330, radius=200)` の blocked。基準は実行前に同じ引数で測る。不確かな点: 効かないか、かえって詰まる可能性もある
- 試し: あり。仮説は「主要な交差点に信号を付けると、その周りで止まる車が減る」。測る数は `traffic` の blocked(x=2110, z=330, radius=200)。場所は交差点の周り。基準は実行前の測定値。基準を超えて悪くなったら信号を外す
- ほかの局への響き: 道路下水道局の数字だけに影響する。貨物センター周りの物流の数字には響かない見立て(場所が離れている)
- 戻せるか: 戻せる(`set_traffic_lights(2100, 309, False)`)
- 取り壊しのとき: 該当しない

## 採らなかった案

- urban-2: Recycling 政策。`list_policies` の説明は「住宅の税収 -5%」で、`economy_breakdown` の Residential の週の収入 265,121 の 5% は約 -13,256。週の黒字 +9,965 を超え、赤字になる。ごみ削減の別の手と、収入の減りを補う手を添えて出し直してほしい。
- roads-1: 交差点(2309, -950)に信号。`junction_info` では、近くの節点 32208(2280, -950)は道路が2本つながるだけで、Basic Road と Small 4 Lane Road の切り替え点。交差点ではなく、信号の効き目が見込めない。本当の交差点の座標を `junction_info` で確かめて出し直してほしい。

- port-2: FreeTransport 政策。バスの運賃収入 5,179 が0になり、週の黒字 +9,965 が約 4,786 に減る。バスの乗客は週 2,800 程度で、走る車 7,557 に比べて小さく、流れへの効きは小さい見立て。来月以降の観光施設の維持費の余地を優先する。

## 判断の根拠

週の黒字 +9,965 は薄い。Recycling の税収の減り(約 -13,256)だけで赤字になるため、局の案の費用0を、そのまま信じなかった。予算の案は、`set_budget` の範囲が50〜150なのに155、165があり、引数が通らない。バス路線は今の割合が案の値より高く、案のとおりでは台数が減る。
建設案は、道の接続が未確認で、働かない建物になるおそれがある。そのため、費用がなく、条件を確かめられた RecreationalUse と、信号1か所を選んだ。観光は重点なので、economy-1 は直してもらい来月の最優先にする。
