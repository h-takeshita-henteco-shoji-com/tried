# m01 教育委員会の案

## 案1: 高校を1棟新設(東の住宅地の北、電気・水・下水を確認した地点)

### 施策

- 案の id: education-1
- 施策: 高校(High School)を1棟、座標 (1930, -880) に向き north で建てる。道は既存の Basic Road(segment 31882)に入口で接続する。
- 議決: 要らない

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `place_building` で prefab "High School"、x 1930、z -880、facing "north"、pay true(既定)を1回だけ呼ぶ。
  2. 戻り値の entrance で、入口が (1930, -860) の north、road が segment 31882(Basic Road、距離 12 m)になることを確かめる。
  3. 置いた後、`services` の education.high の定員が増えたことを確かめる。
- 設置条件の確認:
  - `test_place_building`(High School, 1930, -880, north): ok。ぶつかりなし、取り壊しなし(wouldDemolish 0)、費用 24,000、所持金は足りる(enoughMoney true)、入口の道路は segment 31882(距離 12 m)。
  - `buildings_near`(1930, -880, 半径 45): 近くの建物は住宅 9863 の1棟だけ。敷地は空いている。
  - `map_layer`(electricity_service、1930, -880、半径 60、n 7): 範囲(x 1870〜1990、z -940〜-820)の49点すべて 1(電気が届いている)。
  - `map_layer`(water_service、同じ範囲、n 5): 25点すべて 1(水が届いている)。
  - `map_layer`(sewage_service、同じ範囲、n 7): 49点すべて 1(下水が届いている)。
  - `water_trace`(1930, -880): 最も近い住宅 9863(1961, -852)は、電気・水・下水がすべて届いている。水の網は取水口と排水口につながっている。
- 接続工事: 不要。入口の道路と、電気・水・下水は既存の網で届いている。
- 予備候補: なし。`test_place_building`(High School, 1880, -880, north)は道路 segment 9422 にぶつかり断られた。`test_place_building`(High School, 1985, -885, north)は入口の道路が16m以内になく(road null)、使えない。
- 中止する条件:
  - 実行時の `place_building` が ok でない、または入口の road が null になったら、置かずに見送る。
  - 戻り値の demolished が 0 でない(住宅が壊れる)なら、見送って市長に返す。
  - 置く直前に `map_layer`(electricity_service、1930, -880)が 0 になったら見送る。
  - 建設費が 24,000 を大きく超える、または所持金が足りないなら見送る。

### 期待する効果

- 改善の見込み: 担当の目標「高校の定員が10代以上を保つ」の余裕を広げる。確認した事実: 高校の定員 24,360、10代 22,372、余裕 1,988(8.9%)。定員の増えは、高校1棟の定員 1,000(予算120%で約 1,200 と見込む)。局の予想では、定員が約 25,560 になり、余裕は約 3,190 になる。
- 数値と期限:
  - 高校の定員(`services`、education.high): 今 24,360 → 建った後 約 25,500〜25,600(局の予想。予算120%の見込み)。
  - 10代(`citizens_summary`、age.teen): 今 22,372。
  - 余裕(定員 − 10代): 今 1,988 → 予想 約 3,190。
  - 期限: 建った月の月末に定員を見る。3か月後(m03)の月例までに、定員が 25,000 以上であることを確かめる。
- 確認方法: `services` の education.high(定員)と、`citizens_summary` の age.teen(10代)を、同じ月の同じ時点で比べる。
- 不確かな点:
  - 10代の増え方は、人口の増え方で決まる。道具では予想できない。局の計算では、人口が月に1%増えると、今の余裕 1,988 は約9か月で0になる。新設すると約14か月で0になる(局の予測)。
  - 建設が終わる日は道具で見えない。
  - 定員が 1,200 になるかは、予算120%が続くかに依る。
  - 小学校と大学の定員は、この案では動かない。
- 試し: なし

## 判断の根拠

- 担当の2つの目標は、今は両方満たしている。小学校は定員 14,268 に対し子ども 11,344(余裕 26%)。高校は定員 24,360 に対し10代 22,372(余裕 1,988、8.9%)。
- 高校の余裕が先に狭まるおそれがある。公約1(人口を毎月増やす)が進むと、10代も増える。余裕が少ない高校を、先に1棟増やす。
- 案は1件だけ出した。小学校の余裕は大きいので、今は増やさない。大学は、大学卒の失業が 6,483 あるため、増やすと失業が増えるおそれがあり、出さない。
- 高校1棟は、建設費 24,000、維持費 560 / 週。建設費は要領の上限 200,000 の内、維持費は要領の増分 5,000 の内に収まる(要領の枠は局の見積もり)。
- 接続と場所は、道具で確かめた。電気・水・下水は、地図の道具で、敷地の49点すべてで届いていることを確かめた。入口の道路は12 m。ぶつかりも、壊す建物もない。
- 案を1件に絞ったのは、目標を今満たしていて、必要なのは1棟だけだから。件数を埋める案は出さない。

## 捨てたもの

- 小学校の新設: 子ども 11,344 に対し定員 14,268 で余裕 26%。今は増やす必要がない。子どもが増えて余裕が 10% を切ったら、次の月に出す。
- 大学の新設: 大学卒の失業が 6,483 ある。大学を増やすと、大学卒がさらに増え、失業が増えるおそれがある。担当の目標にも大学は入っていない。
- 教育予算を 120 から 130 に上げる(`set_budget`、target education、percent 130): 定員が約 8% 増える見込み。ただし、維持費は 48,120 / 週の約 8% 増(約 +4,000 / 週)と見積もれる。要領の増分 5,000 の大半を使い、名所と貨物駅の維持費と競合する。予算は議決も要る。高校1棟(+560 / 週)の方が、定員1棟あたりの維持費が低い。
- EducationBoost の解除(`set_policy`、EducationBoost、active false): 週 7,940 の支出を減らせるが、学校の定員に効くかが道具で確かめられない。担当の数字を動かす根拠がないため、出さない。
- 高校の別地点(東の住宅地、(2250,-400) 付近): 空き地が見つからなかった(建物が詰まっている)。
- 高校の別地点(1880,-880、1985,-885): それぞれ道路と重なる、または入口の道路が遠いため、断られる。
