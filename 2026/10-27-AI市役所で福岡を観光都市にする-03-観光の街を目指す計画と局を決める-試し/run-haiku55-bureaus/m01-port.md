# m01 港湾空港局の案

## 案1: 乗客の少ないバス路線を2つ消して、走る車を減らす

### 施策

- 案の id: port-1
- 施策: 乗客が少なく車両が多いバス路線 2 本を消す。対象は路線 139(画面の番号 38、Bus Line 38)と路線 21(画面の番号 39、Bus Line 39)。道具は `remove_transport_line`。
- 議決: 取り壊し

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `list_transport_lines`(type="bus", number=38)で、line 139 が Bus Line 38 であることを確かめる(確認済み。車両 101、乗客 20、前期 5、長さ 20.31km、停留所 16、pathFailed 0)。
  2. `remove_transport_line`(line=139)を呼ぶ。
  3. `list_transport_lines`(type="bus", number=39)で、line 21 が Bus Line 39 であることを確かめる(確認済み。車両 65、乗客 14、前期 16、長さ 12.82km、停留所 24、pathFailed 0)。
  4. `remove_transport_line`(line=21)を呼ぶ。
  5. 見回り1・見回り2・月末に、`traffic` の flow と blocked を見る。
- 設置条件の確認: 建設以外の操作なので該当なし。路線の番号は `list_transport_lines` の line の値で確かめた。試しの道具は、路線の削除にはない。
- 接続工事: 不要
- 予備候補: なし(路線の削除は建設ではないため、予備の場所はない)
- 中止する条件:
  - 実行の直前に、line 139 か line 21 の名前、または乗客の数が変わっていたら、その路線は消さずに見送る。目安は、乗客がどちらも 50 を超えたら見送る。
  - 実行後に、停留所の周りで公共交通が届かなくなった区域が見つかったら、戻せないため、次の月に別の手で補う。

### 期待する効果

- 改善の見込み: 2 路線は、車両 166 台で乗客は合わせて 34 人しか運んでいない(1 台あたり約 0.2 人)。この車両が道を走るのをやめれば、道路の混みが減り、流れが上がると予想する。確認した事実は、車両数と乗客数、車庫の車両の合計 1,916 台である。
- 数値と期限: 対象は街全体の交通(`traffic`)。今の値は流れ 51%、止まった車 1,008 台。予想の数値は見積もれない。確認の期限は月末(30 日目)。
- 確認方法: `traffic`(街全体)の flow と blocked を、見回り1・見回り2・月末で比べる。`list_transport_lines` で、残りの路線の車両と乗客の数も見る。今の値と同じ条件で比べる。
- 不確かな点:
  - 数値は見積もれない。車両は 7,557 台の一部にすぎず、流れへの効きは小さいかもしれない。
  - 停留所の建物が残るかは確かめていない。停留所の周りの乗客への影響は未確認。
  - 週の維持費の減りは、バスの維持費 22,051 を車両の数で按分した見積もり(約 1,900)で、道具では確かめていない。
- 試し: 試しとして出す。
  - 仮説: 乗客の少ないバス路線の車両を消すと、道を走る車が減り、流れが上がる。
  - 測る数: `traffic` の flow と blocked(街全体)。
  - 場所: 街全体。
  - 基準: 流れ 51%、止まった車 1,008 台。
  - 編成方針の分からないこと: 項目に直接は書かれていない。交通の流れ(6-3)の効き目を確かめる。

## 判断の根拠

6-3 の流れ(51%、目標 60% 以上)に効く手は、車両の多い低乗客路線を減らすことだと判断した。バスは車庫の合計で 1,916 台あり、路線 139 と 21 だけで 166 台を走らせ、乗客は 34 人である。ただし、予算の割合を下げる案は、ほぼ 200 → 190 のような 10 ポイント刻みになり、車両が約 5% しか減らない。編成要領の予算の幅(±10)と型の上限(±20)では、効き目が出る大きさの予算変更ができない。そこで、取り壊しの議決で 2 路線を消す案にした。取り壊しは戻せないため、試しの扱いにし、流れと止まった車で確かめる。案は 1 件にした。乗客を運ぶ路線を減らす手は、ほかに実行条件を確かめられた候補がなかった。8-1 の貨物駅28755 の空き待ちは、道の詰まりではなく敷地の中の出口の問題と見えたが、接続点の座標と入口の向きを確かめられなかったため、案にせず調査にした。

## 捨てたもの

- 貨物駅の増設(Cargo Center 60,000、維持費 1,440/週): 近くの貨物駅 14580、16572、48243 は外の線につながらず、3940、4740 は車両 0 で使われていない。増やしても使われるかを確かめられないため、出さなかった。
- 道路の差し替えや二つ目の出口で貨物駅28755 の出口を増やす案: 敷地の出口の接続点と入口の向きを確かめられなかった(交差点がなく、ports も空)。試しの道具で引数を決められないため、調査にした。
- 政策 HeavyTrafficBan(トラックの通行を止める、無効、費用 0): トラックの通行を止めると、品物がない店 228 への配送も止まるおそれがある。8-1 と 6-4、7-1 に逆向きに効く。
- 政策 FreeTransport(公共交通を無料にする、無効): バスの運賃の収入 5,179/週を失う。乗客がどれだけ増えるかは見積もれない。
- 観光地(attractiveness 157 の (2575, 1224))に新しいバス路線を足す案: 最寄りのバス車庫は (1652, 66) で、約 1.5km 離れる。車両を増やすと流れを悪くするおそれがあり、観光の効きも見積もれない。
- 地下鉄の延伸: 地下鉄は 1 路線、駅 2、車両 1、乗客 1 で、伸ばす先の需要と接続を確かめていない。
- 路線 136(番号 28、車両 186、乗客 58)を消す案: 乗客 58 人の足を奪うため、今月は見送った。台数の減らし方は、次の月に別の手で考える。
