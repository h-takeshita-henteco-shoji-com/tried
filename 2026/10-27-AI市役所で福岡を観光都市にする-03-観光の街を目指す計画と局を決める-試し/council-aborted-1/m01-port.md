# m01 港湾空港局の案

## 施策

- 施策: 乗客の少ない大型バス路線7本の台数の割合を20ポイント下げる(`set_transport_line_budget`)。路線 line 136(Bus Line 28)、139(Bus Line 38)、127(Bus Line 37)、126(Bus Line 41)、21 は line 番号で 21(Bus Line 39)、200(Bus Line 11)、46(Bus Line 9)

  7. line=46, percent=80(今100。車両 18、乗客 1)
- 設置条件の確認: `list_transport_lines` で7本とも complete=true、pathFailed=0、budget が上の「今」の値であることを確認した。建設を伴わないので敷地の確認は該当なし。道具の引数は tool-reference.md の `set_transport_line_budget(line, percent)`(10〜300)で確かめた。
- 接続工事: 不要
- 予備候補: なし
- 中止する条件: 実行前に `list_transport_lines` で上の7本の budget が「今」の値と違うとき、その路線は飛ばす。いずれかの路線の pathFailed が1以上になっていたら、その路線は触らない。

## 期待する効果

- 改善の見込み: 7本の車両は合計 513 台で、乗客は路線ごとに 1〜58 人しかいない。空に近いバスが道を走り、交通の流れ 51% を下げている恐れがあるため、台数を約1割(約 57 台)減らすと道の上の車が減り、バスの維持費も減ると予想する。
- 数値と期限: 対象は `traffic` の flow(今 51%)と `economy_breakdown` の PublicTransport の支出(今 38,172/週)。予想は flow が +0〜1 ポイント、支出が週 500〜1,000 の減。確かめる期限は実行後30日。
- 確認方法: `list_transport_lines` で7本の vehicles と passengersLastPeriod、`traffic` の flow(街全体)、`economy_breakdown` の PublicTransport を、実行前と30日後に同じ条件で比べる。
- 不確かな点: 車両が減っても流れがどれだけ動くかは見積もれない(街の車は 2,111 台の貨物車を含み、バスは一部)。乗客が減る恐れは、7本の passengersLastPeriod で確かめる。
- 試し: あり。仮説は「乗客の少ない路線の台数を減らすと、道の上の車が減って交通の流れが少し上がる」。測る数は `traffic` の flow(街全体、今 51%)と、7本の車両数の合計(今 513)。基準は上の値。編成方針の「分からないこと」とは別の、6-3 の施策の試し。

## 判断の根拠

駅 28755 の周囲の道は空いており、止まるのは敷地の中の 492 台だけで、原因は道の詰まりと言い切れない。そのため調査で追う。一方、6-3 は、乗客がほとんどいない大型バスが多数走っており、台数を下げる予算の変更は費用0で戻せるため、試しとして出す。予算の幅 ±20 の範囲に収めた。

## 捨てたもの

- 貨物駅 28755 の出口の道路の建設や差し替え: 原因が確かめられておらず、Cargo Connection と道路のつなぎ目を試すだけの道具で確かめられない。調査の結果を見てから出す
- 貨物駅 14580、16572、48243 の線路をつなぐ工事: 3か所とも車の出入りが 0 で、止まったトラックの数(8-1)に効かない

- 港の追加: 貨物港で止まるのは 14 台だけで、8-1 の目標との差は貨物駅 28755 にある
- バスの停留所や路線の新設: 乗客の少ない路線が多く、新しい路線を足す根拠がない
