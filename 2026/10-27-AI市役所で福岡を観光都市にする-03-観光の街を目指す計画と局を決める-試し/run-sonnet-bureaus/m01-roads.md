# m01 道路下水道局の案

## 案1: 東西路(z=-950)の2つのT字路で、側道に譲れの標識を付ける

### 施策

- 案の id: roads-1
- 施策: (2236, -950) の側道 segment 10391 と、(2220, -950) の側道 segment 29545 に「譲れ」の標識を付ける。`set_yield_sign` を使う
- 議決: 要らない

### 実行計画

- 実行可否: 確認済み
- 対象と操作順:
  1. `set_yield_sign(x=2236, z=-950, segment=10391, active=True)`
  2. `set_yield_sign(x=2220, z=-950, segment=29545, active=True)`
  3. 効き目が悪化(流れが下がる、側道が詰まる)したら、同じ引数で `active=False` にして戻す
- 設置条件の確認:
  - `junction_info`(2236, -950): 信号なし、canSetYield=true、segment 10391(bearing 0、cars=true、yield=false)
  - `junction_info`(2220, -950): 信号なし、canSetYield=true、segment 29545(bearing 180、cars=true、yield=false)
  - 東西の本線は 3334(2280〜2236)、36011(2236〜2220)、19196(2220〜2160)。どれも Basic Road
- 接続工事: 不要
- 予備候補: なし
- 中止する条件: 実行前の `junction_info` で、信号が付いている、または canSetYield が false になっていたら見送る

### 期待する効果

- 改善の見込み: 東西の本線は、4車線(Small 4 Lane Road)の間で Basic Road の3区間(約65m)に絞られ、手前の (2309, -925) で 61 台が止まっている。側道の車に譲らせると、本線を通る車が優先され、T字路で本線が止まる回数が減ると予想する
- 数値と期限: `traffic` の x=2309, z=-925, radius=300 で、flow 51%、blocked 102、blockedSpots の先頭 61。20日目までに、blocked が 102 より減り、先頭の 61 が減ることを期待する。量は見積もれない
- 確認方法: `traffic` を同じ引数(x=2309, z=-925, radius=300)で、見回り1・見回り2・月末に測る。あわせて側道(2236, -905)と(2220, -1000)の混み具合も見る
- 不確かな点: 側道の車が譲り続けて側道が詰まり、全体では変わらない可能性がある。本線の車の数が多すぎて、標識だけでは詰まりが解けない可能性がある。数値は見積もれない
- 試し: 試しとする。仮説は「側道に譲れを付けると、本線の通過が増え、東西路の流れが良くなる」。測る数は `traffic`(2309, -925, 半径300)の blocked と blockedSpots の先頭。基準は blocked 102、先頭 61、流れ 51%。編成方針の「分からないこと」(貨物駅 28755 の滞留)に直接は当たらないが、貨物駅の出口の道路の詰まりを確かめる材料になる

これは局の予測です。ゲームの効果の正解を取得しません。

- 調査: あり
- 問い: 東西路(z=-950)の本線は、どこで止まる車が多いのか、また貨物駅 28755 周辺の詰まりと同じ根か
- 見る道具と引数: `traffic`(x=2309, z=-925, radius=300)、`traffic`(x=3449, z=-1555, radius=300)、`vehicles_stuck`(kind=truck, limit=30)
- いつ見るか: 見回り1、見回り2、月末
- 何が分かれば次の手が決まるか:
  - 東西路の blocked が貨物駅の周りでも多い: 駅へ向かう道路の太さが原因とみて、翌月は貨物駅の出口の道路を太くする案を出す
  - 東西路だけが多く、駅の周りは少ない: 東西路の2つのT字路の信号・標識を詰めて直す案を出す
  - 標識で blocked が減った: 同じ手を、ほかの blockedSpots (-726, -736)、(2100, 309)に広げる案を出す

## 判断の根拠

流れ 51%(目標 60%)で、止まった車が多い場所は (2309, -925) の 61 台。ここは本線が 4 車線から Basic Road 3区間へ絞られる手前にあたる。4車線化は、9m の短い区間と交差点の角で断られ、実行できない。壊して引き直す案も側道にぶつかって断られた。そのため、費用 0 で戻せる標識の案を、試しとして1件だけ出した。電気・水・下水は 0 で、水・下水の容量にも余裕があるため、案を出さない。
