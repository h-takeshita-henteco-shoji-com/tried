# m01 港湾空港局の案

## 案1: 乗客の少ないバス路線の台数を減らす

### 施策

- 案の id: port-1
- 施策: 乗客に比べて台数が多い路線の予算を20ポイント下げ、道路を走るバスを減らす。道具は `set_transport_line_budget`
- 議決: 予算

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: `set_transport_line_budget(line, percent)` を次の順に呼ぶ。
  - 予算200から180へ: line=136(Bus Line 28、186台、乗客58)、line=139(Bus Line 38、101台、乗客20)、line=21(Bus Line 39、65台、乗客14)、line=127(Bus Line 37、57台、乗客19)、line=126(Bus Line 41、50台、乗客28)、line=199(Bus Line 34、52台、乗客36)
  - 予算100から80へ: line=200(Bus Line 11、36台、乗客6)、line=210(Bus Line 13、26台、乗客9)、line=83(Bus Line 24、21台、乗客9)、line=46(Bus Line 9、18台、乗客1)、line=107(Bus Line 5、15台、乗客11)、line=131(Bus Line 19、12台、乗客3)、line=234(Bus Line 4、9台、乗客2)
- 設置条件の確認: 建設はない。`list_transport_lines` で13路線の line 番号、現在の予算(200 または 100)、台数、乗客を確認した。全路線 complete=true、pathFailed=0。変更幅は ±20 の枠内。
- 接続工事: 不要
- 予備候補: なし
- 中止する条件: 実行前の `list_transport_lines` で、対象路線の予算が上の値と違う場合は、その路線を外す。乗客が今の10倍以上に増えた路線も外す。

### 期待する効果

- 改善の見込み: バスが道路を走る車の約25%を占める一方、バスの収入は週5,179で支出は22,051。乗客の少ない路線の台数を減らすと、道路の混雑と支出が少し減ると予想する。
- 数値と期限: 確認した今の値は、`traffic` の流れ51%、走行車7,557台、渋滞印2,499、バスの週支出22,051。対象13路線の台数は計約648台で、一律の割合で減らせば約75台減る見込み(予想)。流れの改善は数ポイント以内と見る。計画の目標60%には、この案だけでは届かない。30日後に確かめる。
- 確認方法: `list_transport_lines` で対象13路線の vehicles と passengersLastPeriod。`traffic` の flow と cars(街全体)。`economy_breakdown` の PublicTransportBus の expenses。
- 不確かな点: バスの減少が流れに効く量は見積もれない。台数の減りは、車庫が車を回収する速さで遅れる。乗客が減る恐れがあるが、対象は週の乗客が1桁から数十の路線に絞った。
- 試し: 試し。仮説は、乗客の少ない路線の台数を減らせば、道路の車が減り、流れが上がる。測る数は `traffic` の flow(基準51)と cars(基準7,557)、`economy_breakdown` のバスの週支出(基準22,051)。場所は街全体。編成方針の「分からないこと」には当たらない。

これは局の予測です。

  - 台数が日ごとに入れ替わり、bySeenStopped が1日未満のまま → 処理待ちの列。次月に駅の数を増やす案(Cargo Center、建設費60,000)を調べる

## 見たもの

- `cargo`: 止まったトラック802(道の上296、敷地の中506)。貨物駅28755で492。港1366で14。品物がない店228、原料がない工場24
- `list_policies`: 比較した政策は FreeTransport(無効、週0、ただし運賃収入が0になる)、HeavyTrafficBan(無効、週0)、EducationBoost(有効、週7,940)、BigBusiness(有効、週3,876)。交通と港に直接効く政策で、費用に見合うものはなかった
- `list_transport_lines`: バス約80路線と地下鉄1路線。バス Line 28 は186台で乗客58。Line 38 は101台で乗客20。地下鉄 Line 1 は乗客0
- `transport_reach`: 貨物駅28755と港1366は外とつながっている。貨物駅14580、16572、48243はつながっていない(すき間271m、725m、2,933m)
- `trade`: 輸入15,573、輸出1。道路の入口(5788, -8649)から197台が入っている
- `vehicles_stuck`: 建物28755関連589台。492台が WaitingSpace+Importing+InGrounds、経路は ready、位置は (3441, -1555)。いずれも1日未満(初回のため)

- `buildings_near`: 28755 は仕事なし、働き手54、使用中の車763。隣の貨物駅13893は車0、働き手48
- `transport_depots`: バスの車庫2つ。出している車は1,346台と570台
- `economy_breakdown`: PublicTransport の収入5,179、支出38,172。うちバスは収入5,179、支出22,051

## 判断の根拠

駅の渋滞は、敷地の中で492台が止まっているのに、周りの道路は blocked 0 でした。道路の詰まりではないと見えますが、原因は確かめきれていません。そのため施策にせず、調査を出します。案1は、バスが道路の車の約25%を占め、乗客が少ない路線に台数が集まっているという確認済みの事実に基づきます。道路の加工は、坂と衝突で試しの道具が断ったため案にしていません。
