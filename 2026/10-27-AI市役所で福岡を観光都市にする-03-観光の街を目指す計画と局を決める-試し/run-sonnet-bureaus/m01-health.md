## 案1: 西のごみの集中地に埋立地を1か所足す

### 施策

- 案の id: health-1
- 施策: 埋立地(Landfill Site)を (-520, -1905) に北向きで1棟置く。西のごみの印の集中地(-460〜-720, -1230〜-1585)の南に当たる。
- 議決: 要らない

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: `place_building(prefab="Landfill Site", x=-520, z=-1905, facing="north", pay=True)` を1回
- 設置条件の確認: `test_place_building` で ok=true、位置はそのまま (-520, -1905)、取り壊しは 0 棟、入口 (-520, -1873) から 5m に Basic Road(区間 18245)。電気・水・下水は要らない。`zone_map` で南の灰色の未指定地であることを確認した
- 接続工事: 不要(入口の前に既存の道路がある)
- 予備候補: (-520, -1815) 南向きは、既存の焼却場 33797 とぶつかり断られた。予備はなし
- 中止する条件: 実行前の `test_place_building` が ok でなくなったとき、または取り壊しが 0 でなくなったときは見送る

### 期待する効果

- 改善の見込み: ごみの印の 8 棟はすべて西の高密度住宅で、近くの処理施設は焼却場 33797 だけ(貯蔵 93%)。近くに受け入れ先を足せば、収集車の運び先が増え、印が減ると予想する。
- 数値と期限: `complaints` のごみの印は今 15 棟(西の集中地は 8 棟)。予想は 10 棟以下。月末(30日目)までに確かめる。数値は見積もれない
- 確認方法: `complaints` の Garbage と、`buildings_near`(x=-500, z=-1500, radius=500, problem="Garbage")の total を、今の 8 と比べる
- 不確かな点: 収集車が足りないのではなく、高密度住宅のごみの量が収集を上回っている可能性がある。その場合は効かない。近くの住宅に地面の汚れが出る恐れもある
- 試し: 仮説は「近くの受け入れ先が増えると、西の集中地の収集が間に合う」。測る数は `buildings_near` の Garbage の印の数(西の集中地の 8 棟)。基準は 8 棟。編成方針の分からないことには当たらない

### 費用

- 建設費: 4,000(`test_place_building` の cost)
- 週の維持費の増え分: 160(`list_building_types` の upkeepPerWeek)

### 戻せるか

戻せる。取り壊しは議決が要るが、建てた建物は4,000と小さい。

## 案2: 満杯で動かない埋立地 25590 を止める

### 施策

- 案の id: health-2
- 施策: 満杯の埋立地 25590 (3900, -575)を `set_building_active` で止める。収集車は 0 / 19 台で、何も受け入れていない。
- 議決: 要らない

### 実行計画

- 実行可否: 確認済み
- 対象と操作順: `set_building_active(id=25590, active=False)` を1回
- 設置条件の確認: `buildings_near`(x=0, z=0, radius=6000, service="Garbage")で、25590 は Landfill Site、100% 満杯(8,000,000 / 8,000,000)、使用中の収集車 0 台、働き手 19 人と確認した。汚染の `map_layer` で (3650〜3900, -300〜-600) 付近に 255 の高い値がある
- 接続工事: 不要
- 予備候補: なし
- 中止する条件: 実行前に 25590 の収集車の使用中が 0 台でなくなったとき、または満杯でなくなったときは見送る

### 期待する効果

- 改善の見込み: 汚染の印は東の (3881, -296) 付近に集中し、近くに満杯の埋立地がある。止めれば、動いている建物の汚染が減る見込みがある。ただし、たまったごみ自体が汚染を出し続けるかは分からない。
- 数値と期限: `complaints` の汚染の印は今 32 棟。予想は数値を見積もれない。月末(30日目)に確かめる
- 確認方法: `complaints` の Pollution の数と hotspot、`map_layer`(type="pollution", x=3800, z=-300, radius=600, n=9)の (3650, 0) 付近の値(今は 255)を、今の値と比べる
- 不確かな点: 満杯の埋立地の汚染が、止めても変わらない可能性がある。変わらなければ、止めるだけで維持費 160 と働き手 19 人が浮く。サービスは失わない(受け入れ 0 台)
- 試し: 仮説は「満杯で動かない埋立地を止めると、その周りの地面の汚染が減る」。測る数は `complaints` の Pollution と `map_layer` pollution。場所は (3800, -300) 半径 600。基準は印 32 棟、(3650, 0) 付近が 255。編成方針の分からないことには当たらない

### 費用

- 建設費: 0
- 週の維持費の増え分: -160(止めると維持費は0になる。`set_building_active` の説明)

### 戻せるか

戻せる。`set_building_active(id=25590, active=True)` で動かし直せる。

なし(1か月目)

## 判断の根拠

健康の平均 78 は目標 80 に近く、病院と葬祭の容量には余裕があり、死者の印は覆いが届いているため、建物を足す案は出さない。ごみの印 15 と汚染の印 32 が目標から遠いので、安く戻せる2案にした。両方とも効き目が分からないため、試しにして測る数を決めた。

案1は、印の 8 棟が西に固まり、近くの受け入れ先が少ないという事実に基づく。案2は、満杯で動かない埋立地を止める手で、サービスを失わずに汚染の変化を見る。原因の確証がない収集の詰まりは、調査で見回りごとに追う。

## 捨てたもの

- Recycling(政策): 週の費用は 0 だが、住宅の税収 -5% になる。住宅の収入 265,121 の 5% は約 13,000 で、予算編成要領の維持費の幅 4,000 と週の黒字 9,965 を超えるため
- 埋立地の `empty_building`: 中身がほかの埋立地に運ばれる。近くの施設は 61〜95% で、満杯が移るだけになる
- 焼却場(Combustion Plant、30,000、週 1,440)を足す案: 受け入れ先の不足か収集車の不足か分からない。調査の結果を見てから出す
- 病院・墓地を足す案: 容量と覆いに余裕があり、健康の平均は目標 80 まで 2 に近い
- PowerSaving、WaterSaving: 週の費用が 58,281 で、維持費の幅 4,000 を超えるため
- SmokingBan、PetBan: 週の費用は 0 だが、健康の平均への効き目の根拠がなく、測る数を決められない
